# MIA Study 1.5.1

2026-11-19 정식 배포

**과목 Word 출력에서 부족한 문제만 뽑거나, 부족한 순서대로 출력할 수 있습니다.** 출력 창의 과목 버튼 위에 선택 두 개가 생겼습니다. 기본값(전체 질문 · 노트 순서)으로는 이전과 같은 문서가 나옵니다.

- **출력 범위.** `전체 질문`(기본) 또는 `부족한 문제만`. 부족한 문제는 학습 전, 복습할 차례가 된 문제, 마지막 평가가 못 암기·애매인 문제, 자주 틀림(8번 이상 잊음) 중 하나라도 해당하는 문제입니다. 마지막 평가가 암기·너무 쉬움이고 복습일 전인 문제만 빠집니다. 하루 학습량 제한은 적용하지 않습니다. 과목 버튼의 문제 수는 고른 범위에 맞게 바뀝니다.
- **순서.** `노트 순서`(기본) 또는 `부족한 순서`. 자주 틀림(잊은 횟수 많은 순) → 못 암기 → 애매 → 복습할 차례 → 학습 전 → 나머지 순이며, 같은 묶음 안에서는 지금 기억 확률이 낮은 문제가 먼저입니다. 동점이면 노트 순서입니다.
- **Word 문서.** 기본이 아닌 조합이면 제목에 `(부족한 문제 · 부족한 순서)` 같은 표시, 제목 아래 `출력 기준 시각 · 부족한 문제 N개 / 전체 M개` 요약, 질문마다 상태 줄(예: `자주 틀림 · 마지막 평가 못 암기 · 잊은 횟수 9회 · 기억 확률 60%`)을 넣고, 파일 이름에 ` 부족한 문제`·` 부족한 순`을 붙입니다.
- 고른 값은 이 기기에 기억됩니다. 학습 기록·동기화 파일·Markdown 형식과 복습 일정 계산은 바뀌지 않았습니다.

기본 조합의 문서 내용(`word/document.xml`)이 이전과 같음을 확인했고, 부족 조합은 샘플 문서에서 제목·요약·순서·상태 줄을 확인했습니다. 출력 창은 휴대폰 390px·iPad·데스크톱 크기에서 가로 넘침이 없습니다. 전체 자동 검사 1,924개(통과 1,922, 실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. **실제 Obsidian과 Microsoft Word 앱에서 열어 보지는 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
