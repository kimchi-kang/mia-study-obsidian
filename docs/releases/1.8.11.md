# Major Study 1.8.11

2026-11-28 정식 배포

**화면 보완 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다(`main.js`·`styles.css` 변경).

## 바뀐 점
- 휴대폰 `문제` 탭의 `검색·필터·정렬`이 카드 안에 버튼이 하나 더 들어간 것처럼 어긋나 보이고 글자가 왼쪽 끝에 붙어 있던 것을 고쳤습니다. 이제 카드 한 장의 머리줄이고, 접으면 그 한 줄만 남으며 오른쪽에 `펼치기`·`접기`가 보입니다. 줄 어디를 눌러도 열고 닫힙니다.
- 학습 중 다른 문제로 넘어갈 때 이전 문제에서 펼쳐 둔 `핵심 개념 확인` 상태가 새 문제에 옮겨 가던 것을 고쳤습니다(1.8.10에서 생긴 문제).
- 데스크톱 학습 화면에서도 평가를 누를 때 "평가 저장 중…" 문구 때문에 아래 버튼이 들썩이지 않습니다.
- 설정 화면처럼 아래 버튼 줄이 없는 곳에서 휴대폰 키보드를 열면 입력칸을 화면 가운데로 옮겨, `키보드 닫기` 버튼에 가리지 않게 했습니다. 1.8.10에서 넣은 여백 규칙은 효과가 없고 학습 화면의 기존 여백을 오히려 줄여서 되돌렸습니다.

## 검증
- 전체 자동 검사 2,159개(통과 2,159, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 필터 카드 머리줄 화면 규칙 검사를 새로 넣었습니다.
- 레이아웃 하네스(브라우저)에서 필터 카드의 접힘·펼침 모양과 데스크톱 학습 화면의 평가 버튼 위치 고정을 확인했습니다.

## 미확인
- 실제 휴대폰에서 필터 카드 모양과 `키보드 닫기` 가림은 확인하지 못했습니다.
