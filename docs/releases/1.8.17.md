# Major Study 1.8.17

2026-11-29 정식 배포

**기능은 그대로 두고 화면을 정리한 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- **목표일 카드:** `편집`·`삭제`를 과목·키워드 카드처럼 제목 줄의 `⋯` 메뉴로 옮겼습니다. 카드에는 `위험 문제 학습`만 남습니다.
- **학습현황 과목 카드:** 0건인 상태(예: 학습 전 0, 애매 0)는 누를 수 없게 옅게 표시합니다. 숫자와 자리는 그대로입니다.
- **같은 기능은 같은 이름으로:** 학습현황 과목 카드의 `복습 시작`을 오늘 탭과 같은 `시험`으로, 문제 탭 상태 드롭다운의 `복습 예정`·`새 문제`를 위쪽 칩과 같은 `오늘 복습`·`학습 전`으로 바꿨습니다.
- **휴대폰 키워드 정렬 칸:** 폭을 가득 채웁니다.
- **모션 보완:** 탭에 들어갈 때 순서대로 나타나는 항목 중 9번째 이후가 위 항목보다 먼저 보이던 것을 고쳤습니다(화면에 보이는 것만 8번째와 함께 나타남). 정답 펼침의 핵심 개념 모션도 다른 모션과 같은 곡선·동작 줄이기 규칙으로 맞췄습니다.

- 전체 자동 검사 2,195개(통과 2,195, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다.
- 목표일 테스트 2곳은 편집·삭제를 버튼 대신 `⋯` 메뉴로 누르도록 바꿨습니다(기대 결과는 그대로). 레이아웃 하네스는 스크립트로 다시 만들었습니다.
