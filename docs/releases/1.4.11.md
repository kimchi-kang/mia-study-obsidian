# MIA Study 1.4.11

2026-11-10 정식 배포

**평가 버튼에 하루 이상의 고정 간격을 설정한 카드가 기한일에 빠짐없이 나오도록 고치고, 다른 기기에서 한 평가가 직전 평가 취소 때문에 흔적 없이 사라지지 않도록 보관합니다.**

- 학습 설정 → 고급의 `평가 버튼 고정 간격`에 1일 이상을 지정한 경우에만 해당합니다. 이런 카드는 기한일(하루 시작 시각 기본 04:00부터) 하루 동안 출제됩니다. 이전에는 09:05에 `암기 = 3일`로 평가한 새 문제가 3일 뒤 09:00에 나오지 않고 하루 밀렸고, 학습 화면이 끝나지 않은 채 며칠씩 `다음 복습 대기 중`에 머물렀습니다. 저장된 값(상태, 예약 시각, 간격, 기억 값, 기록)은 바뀌지 않으며 기존 카드도 변환 없이 새 규칙을 따릅니다.
- 기기 두 대를 쓸 때만 해당합니다. 기기 A에서 평가한 것을 기기 B가 받아 다시 평가한 뒤 A가 자기 평가를 취소하면, 이전에는 동기화 후 B의 평가가 흔적 없이 사라졌습니다. 이제도 A의 취소가 우선하지만 B의 기록은 대시보드의 `보관된 평가 확인`에 남습니다. 부작용이 있습니다. B가 A의 평가를 받은 뒤 A가 그것을 취소하면, B가 평가하지 않았더라도 취소된 상태가 함께 보관되어 대시보드에 `기기 간 평가가 달랐던 문제` 안내가 표시됩니다. 기기 한 대만 쓰면 보관되는 것은 없습니다.
- 기본 설정의 복습 일정은 바뀌지 않습니다. 고정 간격을 쓰지 않는 12가지 시나리오(문제 250개 × 150일)에서 모든 출제 결정과 저장 상태를 수정 전후로 비교해 완전히 일치함을 확인했습니다.

저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,633개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 회귀 검사를 추가했고 수정 전 코드에서 실패하는 것을 확인했습니다. 실제 Obsidian 앱과 모바일 실기기에서는 따로 확인하지 않았습니다.
