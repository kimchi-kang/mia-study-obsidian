# MIA Study 1.5.5

2026-11-19 정식 배포

**외부 코드 리뷰에서 남은 정리 항목을 모두 고쳤습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **Word 출력.** `![[성공률 50%.png]]`처럼 이름에 `%`가 든 이미지가 빠지던 문제를 고쳤습니다. `$100에서 $200로` 같은 문장을 수식으로 잘못 읽어 서식이 깨지고 수식 경고가 뜨던 문제도 고쳤습니다. Obsidian과 같은 규칙(여는 `$` 뒤·닫는 `$` 앞에 공백이 없고, 닫는 `$` 바로 뒤가 숫자가 아닐 때만 수식)을 따르며, `\$`는 수식 경계로 보지 않습니다.
- **키워드 의미 노트 만들기.** 학습 중 키워드 의미 창의 `의미 노트 만들기`가 다른 기능과 같은 경로 검사·충돌 검사를 거칩니다. 같은 노트가 이미 있으면 그 노트를 엽니다.
- **FSRS 최적화 중단.** 학습 설정 창을 ×·ESC·바깥 클릭으로 닫거나 설정 탭을 벗어나면 진행 중인 최적화를 멈춥니다. 이전에는 화면을 닫아도 계산이 끝까지 돌았습니다(설정은 바뀌지 않았습니다).
- **중복 문제 ID 경고.** 같은 파일 안의 중복은 `같은 파일 안에서 중복된 문제 ID`로 한 번만 알려 줍니다. 이전에는 같은 경고가 여러 번 쌓이고 "여러 파일에서"라고 잘못 표시됐습니다.
- **꼬리질문 50개 한도 안내.** 양방향 연결 때 상대 문제가 이미 꼬리질문 50개라 반대 방향 연결을 넣지 못하면 어느 문제인지 알려 줍니다. 기존 링크는 지우지 않습니다.
- **폴더 입력.** 설정에서 키워드 노트 폴더나 문제 폴더에 쓸 수 없는 경로를 넣으면 기본값으로 바꾸지 않고 이전 값을 유지하며 이유를 알려 줍니다.
- **도움말 문구.** 학습 설정 도움말에 남아 있던 "최적화·타이머·자동 진행은 지원하지 않습니다"를 실제 기능에 맞게 고쳤습니다.
- **충돌 보관 기록 창.** 보관 기록·설정 사본을 하나 지워도 창이 닫히지 않고 그 항목만 목록에서 빠집니다.

전체 자동 검사 2,006개(통과 2,004, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 바뀐 설정·충돌 창은 휴대폰·iPad·데스크톱 크기 40개 조합에서 가로 넘침이 없습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
