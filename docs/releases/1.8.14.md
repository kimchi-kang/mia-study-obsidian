# Major Study 1.8.14

2026-11-28 정식 배포

**남은 점검 지적을 정리한 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- 휴대폰에서 문제 상세 창이 원래 설계대로 화면을 꽉 채웁니다. 다른 규칙이 높이를 내용 크기로 줄이고 있었습니다. 결과 창과 편집 창은 지금처럼 내용 크기를 유지합니다.
- Word 출력 창도 휴대폰에서 다른 창처럼 안전 영역 여백, 높이 상한, 창 안 스크롤을 적용합니다. 과목이 많아도 화면 밖으로 넘치지 않습니다.
- 범용 동기화 폴더로 바꿀 때, 기존 저장이 끝난 뒤에 저장소를 바꾸고 전환 중에 들어온 저장은 전환이 끝날 때까지 기다리게 했습니다. 전환 순간에 진행 중이던 저장이 공유 폴더에 쓰이면서 다른 기기 기록을 덮을 수 있던 틈을 막았습니다. 버튼을 두 번 눌러도 전환은 한 번만 합니다.
- 문제 상세를 불러오는 사이 다른 탭으로 옮기면, 이미 화면에서 빠진 패널에 내용을 그리지 않습니다.
- 학습 설정·보기 설정 창을 저장 중에 먼저 닫아도 닫힘 처리를 한 번만 합니다.

## 검증
- 전체 자동 검사 2,175개(통과 2,175, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 새 검사 4개를 넣었습니다: 상세 창 높이 규칙, Word 출력 창 규칙, 저장 대기열 순서, 창 이중 닫힘.
- 기존 테스트 기대값은 바꾸지 않았습니다. CSS 보존 스냅샷만 이번 CSS 변경에 맞춰 갱신했습니다.

## 미확인
- 실제 휴대폰에서 상세 창·Word 출력 창 모양은 확인하지 못했습니다.
- 동기화 전환 경합은 코드 대조와 자동 검사로만 확인했습니다.
