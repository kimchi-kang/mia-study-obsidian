# MIA Study 1.4.7

2026-11-09 정식 배포

**키워드를 병합하거나 삭제한 뒤 질문에 끊어진 키워드 링크가 남던 문제를 고쳤습니다.**

- Obsidian에서 키워드 노트 이름을 바꾸면 링크가 짧은 형식(`[[가우스 법칙]]`)으로 다시 써질 수 있습니다. 이전에는 이런 링크를 같은 키워드로 알아보지 못해, 키워드를 병합하거나 삭제한 뒤에도 질문에 끊어진 링크가 남았습니다. 이제 병합하면 병합 대상 키워드를 가리키고, 삭제하면 함께 지워집니다. 제목이 붙은 링크(`[[가우스 법칙#의미]]`)와 대소문자만 다른 링크도 같습니다.
- 질문에 병합 원본 키워드와 병합 대상 키워드가 함께 연결돼 있으면, 병합 뒤 대상 키워드 링크가 두 개 남던 문제를 고쳤습니다. 이제 한 개만 남습니다.
- 한글 키워드에서 링크 글자와 노트 파일 이름의 유니코드 형식(완성형·자모 분리형)이 다르면, 삭제 확인 창에 연결 질문이 0개로 나오고 병합·삭제 뒤에도 링크가 남던 문제를 고쳤습니다.
- 키워드 이름만 바꿀 때는 이전과 같이 Obsidian이 갱신한 링크(제목과 사용자가 붙인 표시 이름 포함)를 그대로 둡니다. 병합한 키워드를 가리키지 않는 다른 질문의 링크, 다른 폴더에 있는 같은 이름의 노트와 그 링크도 바꾸지 않습니다.
- 질문이 많은 보관함에서 키워드 삭제 확인 창이 조금 더 빨리 열립니다.

내부 구조도 정리했습니다. 노트 파일을 고치는 기능과 읽기 전용 화면을 각각 별도 파일로 나눴으며, 학습 알고리즘·저장 형식·동기화 방식은 바뀌지 않았습니다. 병합할 때 링크의 제목과 사용자 표시 이름이 기본 형식으로 바뀌는 동작은 이전과 같습니다.

전체 자동 검사 1,521개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 같은 소스를 격리된 보관함의 데스크톱 Obsidian 1.15.0에서 1.4.6과 비교해, 과목·질문·키워드 관리, 연결 편집, Word 출력, 모든 화면, 정답 보기·평가·직전 평가 취소·이어하기와 위 키워드 시나리오를 확인했습니다. 질문 1,200개에서 키워드 삭제 확인 창 처리 시간 중앙값은 1.4.6 9.05ms, 1.4.7 7.95ms였습니다. 모바일 실기기에서는 따로 확인하지 않았습니다.
