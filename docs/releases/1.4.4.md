# MIA Study 1.4.4

2026-11-09 정식 배포

- 이름에 쉼표가 있는 키워드(예: `RC, RL 회로`)가 연결된 문제를 편집하면 키워드 링크가 여러 조각으로 잘려 저장되던 문제를 수정했습니다.
- 과목 폴더에 `문제은행.md` 외의 문제 파일이 있을 때, 문제를 추가·수정·이동·삭제하면 과목 노트가 그 파일의 문제만으로 다시 만들어지던 문제를 수정했습니다. 과목 노트는 과목 폴더의 모든 문제 파일을 `문제은행.md`부터 차례로 반영합니다.
- `[[가우스 법칙|가우스]]`처럼 표시 이름이 다른 키워드의 의미가 링크가 가리키지 않는 노트에 저장되던 문제를 수정했습니다. 이제 링크 대상 노트에 저장합니다. 예전 방식으로 저장된 노트는 자동으로 옮기지 않습니다.
- 정답에 `> [!question]` 줄이 있거나 질문 줄이 `[!question]`·`[!mia]`로 시작하면 한 문제가 둘로 나뉘어 인식되던 문제를 저장 전에 막고 안내합니다. 코드 블록 안의 예시와 다른 콜아웃은 그대로 허용합니다.

학습 알고리즘·저장 형식·동기화 방식은 바뀌지 않았습니다. 전체 검증(자동 검사 1,477개, 실패·생략 0, 타입 검사·프로덕션 빌드)을 통과했습니다. 이번 수정은 자동 검사로만 확인했으며, 실제 Obsidian 앱·모바일 실기기·두 기기 동기화에서는 따로 검증하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
