# MIA Study 1.5.8

2026-11-20 정식 배포

**밤에 눈부심을 줄이는 적색 야간 모드를 넣었습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **첫 화면에서 바로 켜기.** `오늘`·`학습현황`·`문제`·`키워드` 화면 상단의 `학습 설정`·`보기 설정` 옆 `야간` 버튼으로 켜고 끕니다. 켜져 있으면 버튼이 반전색으로 보입니다. 학습 중 화면은 휴대폰 상단 줄 칸이 정해져 있어 버튼을 두지 않았고, 대신 명령을 쓰면 됩니다.
- **명령.** 명령 팔레트의 `적색 야간 모드 전환`으로 MIA 화면을 열지 않고도 켜고 끌 수 있습니다. 모바일 툴바에 등록할 수 있고, 버튼과 같은 상태를 써서 열린 MIA 화면의 버튼도 바로 바뀝니다.
- **적용 범위.** 기본은 Obsidian 전체(상단·하단 막대, 사이드바, 노트, 다른 플러그인 화면, 창)입니다. `보기 설정 → 야간 모드 → 야간 모드를 Obsidian 전체에 적용`을 끄면 MIA 화면에만 적용합니다. 켜 둔 상태는 다음에 Obsidian을 열 때 MIA 화면을 열지 않아도 바로 적용되고, 플러그인을 끄면 원래대로 돌아옵니다. 설정은 기기마다 따로 저장합니다.
- **보이는 방식.** 화면 위에 터치·스크롤을 그대로 통과시키는 막 두 장을 씌웁니다. 아래 장은 화면을 흑백으로, 위 장은 빨강만 남겨 파란 글자나 빨간 버튼 위 글자도 밝기 차이로 읽힙니다. 밝은 테마는 야간 동안만 Obsidian 기본 어두운 테마 색을 쓰며, Obsidian의 테마 설정 자체는 바꾸지 않습니다. 본문·흐린 글자는 배경 대비 약 4.5:1이 되게 밝혔으니, 화면 밝기는 휴대폰 밝기로 낮추세요.
- **한계.** 휴대폰 상태 표시줄·키보드·시스템 알림은 앱이 바꿀 수 없어 빨강이 되지 않습니다. 색을 직접 지정한 커뮤니티 테마는 밝은 테마에서 완전히 어두워지지 않을 수 있습니다.

전체 자동 검사 2,031개(통과 2,029, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰 360·375px 폭에서 첫 화면 상단 버튼이 한 줄에 들어가고 가로 넘침이 없습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
