# Major Study 1.8.7

2026-11-28 정식 배포

**1.8.3~1.8.6에 들어간 화면 기능을 외부에서 검토받고, 코드로 확인된 문제를 고친 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다(`main.js`·`styles.css` 변경).

## 바뀐 점
- 휴대폰에서 탭을 옮기는 동안 `오늘` 칸이 0.2초쯤 왼쪽으로 튀었다가 돌아오던 것을 고쳤습니다.
- 짧은 시간에 화면이 여러 번 다시 그려질 때(예: `오늘`로 돌아가며 이어하기 정보를 다시 읽을 때) 탭 선택 표시가 겹치거나 중간에 끊기던 것을 고쳤습니다. 이제 움직이던 자리에서 이어 갑니다.
- 화면이 큰 휴대폰에서 머리줄 버튼(사이드바·⋯·≡)의 모양과 Obsidian 막대 숨김이 빠질 수 있던 것을 고쳤습니다. 버튼 크기를 다른 버튼과 같은 44px로 키웠습니다.
- 키보드나 VoiceOver·TalkBack으로 ⋯·≡ 버튼을 누르면 메뉴가 화면 왼쪽 위 구석에 뜨던 것을 고쳤습니다. 이제 버튼 아래에 뜹니다. 쓸 수 있는 리본 명령이 하나도 없으면 ≡ 버튼을 만들지 않습니다.
- 정답이 펼쳐진 뒤에 정답 칸 가장자리의 초점 테두리가 잘릴 수 있던 것을 고쳤습니다.
- 플러그인을 끄거나 다시 불러오는 순간이 겹치면 휴대폰 하단 막대가 계속 숨겨질 수 있던 것을 막았습니다.

## 검증
- 전체 자동 검사 2,149개(통과 2,149, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 탭 모션, 하단 막대 숨김 판단, 관련 화면 규칙에 대한 자동 검사 11개를 새로 넣었습니다.
- 레이아웃 하네스(브라우저, 휴대폰 폭 375px)에서 44px 버튼 세 개가 한 줄에 들어가는 것과, 탭 이동 중에도 `오늘` 칸이 움직이지 않는 것을 확인했습니다.

- 키보드·화면 읽기 프로그램으로 연 메뉴 위치는 자동 검사로만 확인했습니다.
