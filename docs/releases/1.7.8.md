## 바뀐 점
- 긴 코드·표·수식을 트랙패드로 가로 스크롤하다 왼쪽 끝에 닿았을 때, 남은 관성 때문에 화면이 뒤로 넘어가던 일이 없어졌습니다. 스크롤 영역에서 시작한 쓸기는 손을 떼고 관성이 멈출 때까지 뒤로가기로 보지 않습니다.
- 위아래로 흔들며 쓸 때 세로 움직임이 서로 지워져 뒤로가기로 잘못 판단되지 않게 했습니다.
- `키워드` 카드 이름에서 Space 키는 일반 버튼처럼 손을 뗄 때 의미 창을 엽니다(Enter는 누를 때).
- `오늘` 화면 과목 이름 줄을 누를 때 눌림 그림자가 과목명 글자에 붙지 않게 여백을 줬습니다(글자 위치는 그대로).

전체 자동 검사 2,091개(통과 2,089, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰·iPad·데스크톱 화면 측정에서 가로 넘침이 없습니다. **실제 맥 트랙패드로 긴 코드 블록을 쓸어 보는 확인은 하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
