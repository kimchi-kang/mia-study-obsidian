# MIA Study 1.5.7

2026-11-20 정식 배포

**설정에서 버튼 하나로 업데이트를 확인할 수 있습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- MIA 설정 맨 위에 `업데이트 확인` 버튼을 넣었습니다. 설명에 현재 버전이 함께 나옵니다.
- 누르면 BRAT의 `Plugins: Check for updates to all beta plugins and UPDATE` 명령을 대신 실행합니다. 실제 다운로드와 설치는 BRAT이 맡고 결과도 BRAT이 알려 줍니다. MIA가 스스로 파일을 내려받아 덮어쓰지 않으므로, 동기화 도중 파일이 반쯤 바뀌는 위험이 없습니다.
- BRAT이 설치되지 않았거나 꺼져 있으면 안내만 띄웁니다. 이때는 설치 안내의 수동 업데이트를 따르세요.
- BRAT 설정의 시작 시 자동 업데이트를 켜 두면 Obsidian을 새로 열 때마다 새 버전을 받습니다. 휴대폰·iPad는 앱을 오래 켜 두어 재시작이 드물 수 있으니, 바로 받고 싶을 때 이 버튼을 쓰세요.

전체 자동 검사 2,012개(통과 2,010, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
