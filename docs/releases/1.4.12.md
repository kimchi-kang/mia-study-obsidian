# MIA Study 1.4.12

2026-11-11 정식 배포

**동기화 앱이 만든 충돌 복사본과 일부만 도착한 동기화 폴더를 알려 주고, 기기 안 임시 저장이 실패해도 평가가 보관함 파일에 저장되도록 고쳤습니다.**

- 같은 문제 ID가 둘 이상의 파일에 있으면(보통 동기화 앱이 만든 충돌 복사본) 대시보드에 경고 카드가 나타나 해당 파일과 숨겨진 문제 수를 알려 줍니다. 진단 정보에도 다른 파일 이름이 표시됩니다. 어떤 문제를 숨길지 정하는 규칙은 바뀌지 않았습니다.
- 동기화 파일(`MIA Study Sync/*.md`)을 더 너그럽게 읽습니다. CRLF 줄바꿈, 맨 앞의 BOM, 마지막 줄바꿈 누락, 끝의 빈 줄이 더 있어도 읽을 수 없는 파일로 취급하지 않습니다. 잘리거나 내용이 바뀐 파일은 이전처럼 거절합니다. 기록되는 바이트는 바뀌지 않았습니다.
- 새 기기에 동기화 폴더가 일부만 도착해 폴더·파일은 있지만 표지 파일이 없으면, 시작할 때 60초 동안 알림을 띄우고 기기 간 동기화 설정에 평가가 이 기기에만 저장되고 있다는 경고를 표시합니다.
- 기기 안 임시 사본(localStorage)을 쓸 수 없어도 평가를 막지 않고 보관함 파일에 저장하며, 한 번만 경고합니다. 저장 뒤 임시 사본을 지우지 못하는 경우도 무시합니다.

저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,685개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 실제 Obsidian 앱과 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
