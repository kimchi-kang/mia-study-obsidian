# MIA Study 1.6.0

2026-11-20 정식 배포

**플러그인 화면 디자인을 어두운 소프트 뉴모피즘으로 바꿨습니다.** 동작, 저장 형식, 복습 일정 계산은 바뀌지 않았습니다.

- **새 모양.** 굵은 검은 테두리·원색 면·각진 모서리 대신, 바탕과 카드를 같은 짙은 회청색으로 두고 그림자만으로 표면이 솟거나 파이게 보입니다. 누를 수 있는 버튼·카드는 솟아 있고, 입력칸·진행 막대·눌린 상태·선택된 칩은 파여 있습니다. 하단 탭은 파인 막대 안에 선택된 칸만 솟습니다.
- **항상 어두운 화면.** Obsidian이 밝은 테마여도 MIA 화면·창·설정 탭은 같은 어두운 팔레트로 보입니다. 밝은 버전은 따로 두지 않습니다.
- **차분한 색.** 주요 행동 버튼만 파란 면입니다. 평가 버튼 4개(못 암기·애매·암기·너무 쉬움)는 적갈색·황토·청록·파랑으로 구분합니다. 목록·카드의 `삭제`는 평소 빨간 글자로 두고 누를 때만 빨간 면이 되며, 정말 지울지 묻는 확인 창의 삭제는 빨간 면 그대로입니다.
- **글꼴.** 외부 글꼴 없이 기기 기본 한글 글꼴(Pretendard·Apple SD Gothic Neo·Noto Sans KR 순)을 씁니다.
- **읽기 쉬움.** 글자 대비는 기본 11:1, 흐린 글자 6.6:1, 버튼 위 글자 4.5:1 이상이고 키보드 포커스 표시는 선명한 파란 외곽선입니다. 적색 야간 모드에서도 글자 대비 4.5:1 이상을 유지합니다.
- **배치 유지.** 휴대폰 학습 화면의 한 줄 상단 막대·질문과 정답이 한 화면에 들어가는 배치, 44px 터치 영역, 기기 안전 영역은 그대로입니다.

README와 소개 페이지의 화면 사진은 아직 이전 디자인입니다. 전체 자동 검사 2,035개(통과 2,033, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰 360·390px, iPad, 데스크톱에서 가로 넘침이 없습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
