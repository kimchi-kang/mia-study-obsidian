# MIA Study 1.3.9 — 자료 보존·저장 재시도와 복구 집계 수정

2026-11-06 정식 릴리스. 1.3.7 이후의 1.3.8·1.3.9 수정을 함께 포함합니다. 1.3.8은 소스 업데이트였으며 별도 정식 릴리스를 만들지 않았습니다.

- 답변만 편집하거나 키워드 순서를 바꿀 때 수정하지 않은 키워드 의미를 덮어쓰지 않습니다. 여러 줄 의미와 코드 블록을 보존하고 여러 키워드 입력에서 초과 줄을 조용히 버리지 않습니다.
- 새 질문의 원본 저장 뒤 화면·과목 노트 갱신이 실패해도 같은 ID로 재시도해 중복 생성을 막습니다.
- 과목 이동 후 갱신 실패에도 이동 경로·상대 링크를 보존하고 이전 과목의 인덱스와 요약까지 복구합니다.
- 키워드 의미의 코드 속 제목을 관리 구역 경계로 오인하지 않습니다. 닫히지 않은 코드 블록과 관리 구역을 분리하는 입력은 저장 전에 막습니다.
- 평가 저장 실패 후 미완료 사본을 재시도하고 이어할 때 저장된 평가를 중복 계산하지 않으면서 완료 화면 집계도 복구합니다. workspace 복원에도 적용하며 세션 이전의 오래된 기록은 새 집계에 넣지 않습니다.

학습 알고리즘·FSRS 계산·예약·저장 형식·동기화 선택 정책은 변경하지 않습니다.
