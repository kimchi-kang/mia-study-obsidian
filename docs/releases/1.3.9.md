# MIA Study 1.3.9 — 복구 후 세션 집계 수정

2026-11-05. 실제 사용자 흐름 검증 중 발견한 완료 집계 누락을 수정한 로컬 버전입니다. GitHub main은 1.3.8, 정식 릴리스와 사용자 설치는 1.3.7을 유지합니다. 이번 작업에서는 원격 업로드·릴리스·사용자 설치 갱신을 하지 않습니다.

- 평가 저장 실패 후 미완료 사본을 재시도하고 이어할 때, 저장된 평가는 중복 계산하지 않으면서 완료 화면의 평가 집계도 복구합니다.
- 같은 경계가 있는 앱 작업공간 복원에도 적용합니다. 세션 시작 전의 오래된 기록은 집계에 새로 넣지 않습니다.
- 복구한 기록에 안전하지 않은 평가 취소·재평가 기준을 만들지 않습니다. FSRS 계산·예약·저장 형식·동기화 정책은 변경하지 않습니다.
