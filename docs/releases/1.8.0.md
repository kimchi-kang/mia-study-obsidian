# Major Study 1.8.0

2026-11-24 정식 배포

**Obsidian 설정의 Major Study 탭을 정리했습니다.** 학습 화면의 기능과 저장 형식, 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- 설정 탭(Obsidian 설정 → 커뮤니티 플러그인 → Major Study)을 세 묶음으로 나눴습니다.
  - **보관함 폴더**: `문제 폴더`와 `키워드 노트 폴더`를 한곳에 모았습니다. 지금처럼 입력을 마치면 바로 저장됩니다.
  - **학습 설정 · 기기 동기화**: 전에는 학습 화면의 `학습 설정` 창 내용 전체가 설정 탭 한가운데에 한 번 더 펼쳐져 있었습니다. 이제 하루 새 문제·복습 수, 목표 기억률, 최대 복습 간격, 동기화 상태를 요약해 보여 주고, `학습 설정 열기`를 누르면 학습 화면과 같은 창이 열립니다. 저장과 `내 기기 간 동기화`는 그 창 안에서 합니다. 동기화 폴더가 아직 다 도착하지 않았다는 경고는 설정 탭에도 그대로 보입니다.
  - **플러그인 정보**: `업데이트 확인`을 맨 아래로 옮겼습니다.
- 설정 탭의 `암기 모드 순서`를 뺐습니다. 같은 값을 학습 화면의 `보기 설정` → `암기 모드`에서 바꿀 수 있습니다. 이미 고른 순서는 그대로 유지됩니다.
- 설정 탭과 학습 화면에서 학습 설정 창이 동시에 두 개 열리지 않습니다. Obsidian 설정 창을 닫으면 설정 탭에서 연 학습 설정 창도 닫히고, 진행 중이던 매개변수 최적화는 저장 없이 멈춥니다.

## 검증
- 전체 자동 검사 2,128개(통과 2,128, 실패 0)와 타입 검사·배포 빌드를 통과했습니다. UTC·C 로케일 환경에서는 통과 2,126, 생략 2입니다.
- 설정 탭이 학습 설정을 직접 품는다고 가정한 기존 자동 검사 5곳은, 설정 탭에서 `학습 설정 열기`로 연 창을 대상으로 같은 내용을 확인하도록 옮겼습니다(기본값 불러오기, 저장 실패 후 입력 유지와 다시 저장, 고급 설정 화면, 요약 표시, 설정 창을 닫을 때 최적화 중단).

## 미확인
- 실제 Obsidian 데스크톱·휴대폰·태블릿에서 설정 창 위에 학습 설정 창이 겹쳐 열리는 모습과, 휴대폰 키보드가 올라왔을 때 입력칸 위치는 자동 검사로 확인하지 못했습니다.
