# MIA Study 1.3.11 — 학습 일정과 재실행 복원 수정

2026-11-06 정식 배포. 1.3.9 이후 일정 감사 수정과 실제 앱에서 발견한 재실행 복원 수정을 포함합니다.

- 학습일 시작 시각이 DST 전환으로 존재하지 않을 때 전날 경계를 잘못 계산하던 문제를 수정했습니다. 당일 학습 반복이 복습 상한 때문에 제외될 수 있었습니다.
- 긴 학습 단계의 실제 예약이 최대 간격을 넘지 않도록 했습니다. 1584분/최대1일 조건에서 표시와 저장을 모두1440분으로 제한합니다.
- 오래 열린 평가 버튼의 간격이 시간 경과로 달라졌다면 저장 전에 새 간격을 보여 주고 재평가를 안내합니다. 표시와 다른 예약을 조용히 저장하지 않습니다.
- 상세 화면 평가에서도 직전 평가보다 뒤로 간 기기 시각을 거부하여 기록을 보존합니다.
- 이력의 FSRS 계산 기준 시각을 ‘당시 예정’으로 오인하게 하던 문구를 ‘계산 기준’으로 고쳤습니다.
- 같은 학습 화면을 Obsidian 작업 공간에서 다시 열 때 읽던 위치·핵심 개념 펼침·건너뛴 ID·원래 학습 대상을 복원합니다. 첫 문제 인덱스가 로드되기 전에도 건너뜀을 보존해 같은 세션에 다시 끼어들지 않습니다. 다른 큐의 읽기 위치는 가져오지 않습니다.

전체 **76파일·1372검사, 실패/생략0**, 타입 검사·배포 빌드 통과. 실제 macOS27.2/Obsidian1.15.0에서 실제1분 기한 도래·재출제·한 번 평가·예약 저장, 등록·편집·설정·복구·Word 출력·정상 플러그인 재로드·QA 보관함 창 재실행을 확인했습니다. 최종1.3.11 재실행 후 시험2/2·건너뜀1과 읽던 위치가 유지됐고 평가1회 후 정상 완료했습니다.

FSRS5.4.1·가중치·저장 형식·동기화 병합 정책은 변경하지 않았습니다. 모바일 실기기/OS 키보드·실제 두 기기 클라우드 전달·전체 앱 프로세스 재시작·OS 잠자기 복귀는 미검증입니다. 사용자 보관함은 수동 교체하지 않았습니다.

설치 ZIP에는 main.js·styles.css·manifest.json 세 파일만 들어 있습니다. 개별 설치 파일, SHA256SUMS, BUILD-INFO.json도 함께 제공합니다. 기존 세 배포 파일을 백업하고 같은 버전의 세 파일을 함께 교체하세요. data.json·ui-state.json·문제·복구 사본은 보존하세요.
