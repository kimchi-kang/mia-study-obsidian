# MIA Study 1.7.10

2026-11-23 정식 배포

**화면을 가볍게 정리했습니다.** 되풀이되던 숫자와 버튼을 덜어내고, 관리 버튼은 필요할 때만 열리게 했습니다. 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- `문제` 목록
  - 행마다 있던 `학습·상세·편집·연결·삭제` 버튼을 없앴습니다. 행이나 제목을 누르면 상세가 열리고(넓은 화면은 오른쪽, 휴대폰은 상세 창), 학습·편집·연결·삭제는 상세에서 합니다. 키보드는 제목에서 Enter(누를 때)·Space(뗄 때)로 엽니다.
  - 상태 점 옆에 `취약`·`오늘 복습`·`학습 전`·`학습함` 글자 태그가 붙습니다. 적색 야간 모드에서도 색 없이 구분됩니다.
- `오늘` 화면
  - `오늘 출제…` 줄은 하루 상한 때문에 일부만 출제될 때만 보입니다.
  - 암기 모드 설명과 기기 간 동기화 안내는 `통계와 출제량 안내` 접힘 안으로 옮겼습니다.
  - `기록 새로고침`은 날짜 줄 오른쪽 끝에 작게 둡니다.
  - 과목 카드는 복습이 많은 과목부터 보여 줍니다(같으면 이름순). 카드에는 `시험·암기`만 두고 `이름 수정·삭제`는 `⋯` 메뉴로 옮겼습니다.
- `키워드` 카드: 학습 버튼만 남기고 `편집·삭제`는 `⋯` 메뉴로 옮겼습니다.
- 학습 화면
  - 휴대폰·태블릿 상단바가 아이콘 한 줄입니다: `←`(학습 나가기) · 진행 표시 · `⚙`(학습 설정) · `Aa`(보기 설정) · `☾`(야간). **학습 중에도 적색 야간 모드를 바로 켜고 끌 수 있습니다.**
  - 휴대폰은 학습 중 하단 탭을 숨겨 평가 버튼과 문제가 더 넓어집니다. 나갈 때는 `←`를 누르세요.
  - 태블릿·데스크톱 상단의 이전·다음 버튼을 숨겼습니다(하단 이전·다음 버튼과 ← → 키는 그대로).
  - `이어볼 문제` 오른쪽 칸이 기기 종류가 아니라 화면 폭(960px 이상)으로 정해져, 가로 태블릿과 넓은 분할 화면에서도 옆에 열립니다.
- `학습현황`: 과목 카드가 iPad 세로 화면에서 2열로 나옵니다.

전체 자동 검사 2,126개(통과 2,124, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰 360·390px, 태블릿 768·1024·1194px, 데스크톱 등 화면 측정에서 가로 넘침이 없습니다. **실제 Obsidian에서 상단 아이콘 모양, `⋯` 메뉴, 휴대폰 가로 화면, 태블릿 분할 화면은 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
