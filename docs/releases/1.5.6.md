# MIA Study 1.5.6

2026-11-19 정식 배포

**노트 없는 키워드의 뜻을 저장할 때 노트 위치가 링크와 어긋나던 작은 경우를 고쳤습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- 1.5.4부터 질문에만 연결되고 노트 파일이 없는 키워드도 `키워드` 화면에서 뜻을 저장해 노트를 만들 수 있습니다. 그런데 질문의 링크가 기본 키워드 폴더가 아닌 다른 폴더를 직접 가리키면(예: 마크다운으로 직접 쓴 `[[자료/개념|개념]]`), 노트를 링크가 가리키는 `자료/개념.md`가 아니라 기본 폴더(`MIA/키워드/개념.md`)에 만들었습니다. 그러면 질문의 링크는 여전히 노트를 찾지 못해 키워드 카드가 계속 "노트 없음"으로 보이고 학습 중 뜻 보기에도 나오지 않았습니다.
- 이제 링크에 폴더가 적혀 있으면 **링크가 가리키는 위치에** 노트를 만듭니다. 링크의 `#제목` 부분은 파일 이름에 넣지 않습니다. 폴더 없는 짧은 링크(`[[개념]]`)는 이전처럼 설정한 키워드 폴더에 만듭니다.
- 플러그인 화면으로 만든 질문·키워드는 항상 기본 폴더 링크라 이 경우에 해당하지 않습니다. 데이터가 지워지거나 덮어써지는 문제는 아니었습니다.

전체 자동 검사 2,007개(통과 2,005, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
