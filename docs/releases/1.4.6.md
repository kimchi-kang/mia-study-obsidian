# MIA Study 1.4.6

2026-11-09 정식 배포

**복습이 기한일보다 하루씩 늦게 출제되던 문제를 고쳤습니다.** 이제 Anki처럼 정규 복습은 기한일 단위로 출제합니다.

- 이전에는 정규 복습도 예약된 정확한 시각이 지나야 출제했습니다. 예를 들어 09:05에 "1일 후"로 평가한 문제는 다음 날 09:00에 공부를 시작하면 5분 전이라 나오지 않고, 그다음 날로 밀렸습니다. 매일 비슷한 시간에 공부하면 모든 복습이 하루씩 늦어졌습니다(60일 시뮬레이션에서 매일 09:00 공부 시 141건 중 141건).
- 이제 간격이 1일 이상인 정규 복습은 기한일의 하루 시작 시각(학습 설정, 기본 04:00)부터 출제합니다. 시험 출제 목록, 대시보드의 오늘 복습 수, 문제 목록의 복습 기한 필터가 같은 기준을 사용합니다.
- 1분·10분 같은 학습·재학습 단계와 하루 미만의 고정 간격은 지금처럼 정확한 예약 시각에 출제합니다.
- 예약 시각·간격·FSRS 기억 값은 바꾸지 않았습니다. 기존 학습 기록은 그대로 사용합니다.
- Anki와 같이, 하루 시작 시각 전(새벽)에 평가한 문제는 전날 공부로 계산합니다.

새 검사는 실제 학습 화면으로 40문제를 45일 동안 세 가지 공부 시간대로 학습하며, 기한이 된 문제 누락, 새 문제 한도, 학습 단계 재출제, 평가 저장 결과의 FSRS 일치, 복습 지연 여부를 확인합니다. 이전 규칙에서는 모든 경우가 실패하고 1.4.6에서는 모두 통과합니다. 전체 자동 검사 1,486개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 실제 Obsidian 앱·모바일 실기기에서는 따로 확인하지 않았습니다.
