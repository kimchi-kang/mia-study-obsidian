# Major Study 1.8.3

2026-11-28 정식 배포

**화면 움직임과 휴대폰 화면 정리 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- 상단 탭(`오늘`·`학습현황`·`문제`·`키워드`)을 옮기면 솟아 있는 선택 표시가 이전 탭 자리에서 새 탭 자리로 미끄러지듯 이동합니다. 휴대폰 하단 탭 막대도 같습니다.
- 학습 중 `정답 보기`(또는 Space)를 누르면 모범 답안이 위에서 아래로 펼쳐지고, `핵심 개념 확인`이 뒤이어 나타납니다. 정답을 연 뒤 화면이 다시 그려질 때는 반복하지 않습니다.
- 운영체제의 동작 줄이기 설정을 켜면 두 움직임 모두 나오지 않습니다.
- 휴대폰에서 Major Study가 앞에 있는 동안 Obsidian 상단 막대(사이드바·제목·더 보기)와 하단 막대(뒤로·앞으로·검색·새 탭·탭·메뉴)를 숨겨 화면을 더 넓게 씁니다. 다른 노트로 가면 막대가 다시 나타납니다.
- 대신 휴대폰 `오늘` 화면 머리줄에 사이드바, 더 보기(⋯), 메뉴(≡) 버튼을 둡니다. 메뉴(≡)는 하단 막대의 메뉴와 같은 리본 명령 목록을 엽니다. 이 줄에서는 `FSRS-6` 표시와 버전 번호를 뺐습니다.
- 태블릿과 데스크톱 화면은 탭·정답 움직임 말고는 그대로입니다.

## 검증
- 전체 자동 검사 2,138개(통과 2,138, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다.
- 레이아웃 하네스(브라우저)에서 탭 이동 중간 장면, 정답 펼침 중간 장면, 휴대폰 폭(375px) 머리줄의 버튼 배치를 확인했습니다.
- 실제 휴대폰(iPhone)에서 상단·하단 막대가 숨겨지고 `오늘` 화면 머리줄에 버튼이 나오는 것, 더 보기(⋯) 메뉴가 열리는 것을 확인했습니다.

## 미확인
- 실제 휴대폰에서 탭 움직임, 정답 펼침, 사이드바 버튼은 따로 확인하지 못했습니다.
- 메뉴(≡) 버튼은 마지막으로 고친 방식(리본 명령 목록을 직접 여는 방식)을 실제 휴대폰에서 확인하지 못했습니다. 하단 막대 메뉴에 `빠른 실행 항목`을 지정해 두었더라도, 이 버튼은 항상 목록을 엽니다.
- 막대를 숨긴 뒤 상태 표시줄·홈 표시줄 주변 여백은 iPhone 한 기종에서만 봤고, Android와 다른 iPhone 크기는 확인하지 못했습니다.
- 메뉴(≡) 버튼과 막대 숨김은 Obsidian 내부 구조를 이용합니다. 이후 Obsidian 업데이트로 구조가 바뀌면 메뉴 버튼이 보이지 않을 수 있습니다(오류 없이 버튼만 빠짐).
