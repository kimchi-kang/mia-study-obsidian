# MIA Study 1.4.19

2026-11-14 정식 배포

**Anki식 `미리 학습`과 내 복습 기록으로 FSRS 매개변수를 맞추는 최적화 기능을 넣고, 설정 화면의 토글·컨트롤 배치를 모든 기기에서 바로잡았습니다. 빠르게 연속으로 누를 때 같은 창이 두 번 열리던 문제도 고쳤습니다. 복습 기록 형식은 바뀌지 않았고 설정 저장에는 필드가 하나 늘었습니다.**

- **미리 학습(Learn ahead).** 세션에 더 보여 줄 카드가 없을 때, 당일 안에 다시 나올 학습 중 카드가 `미리 학습 시간`(분) 안에 기한이 오면 기다리지 않고 바로 보여 줍니다. 새 설정 `learnAheadMinutes`의 기본값은 20분이며 0~1440분 범위입니다. 0으로 두면 이전 동작(기한이 될 때까지 대기)과 같습니다. 건너뛴 카드 중 현재 순서보다 뒤에 있는 것은 그대로 유지합니다.
- **FSRS 매개변수 최적화.** 학습 설정의 `내 기록으로 최적화` 버튼이 내 복습 기록으로 FSRS-6 매개변수를 계산합니다. 진행 표시와 취소가 있고, 기존 값과 새 값의 log loss·RMSE를 나란히 보여 줍니다. 결과가 더 나쁘면 적용하지 않으며, 더 좋아도 `학습 설정 저장`을 눌러야 적용됩니다. 이미 잡힌 기한일은 다시 계산하지 않습니다. 순수 TypeScript로 구현했고(사전 학습 + Adam) 선택 기능이라 누르지 않으면 아무것도 바뀌지 않습니다. 테스트에서 공식 구현(`@open-spaced-repetition/binding`, fsrs-rs)과 비교해 log loss 0.390111 대 0.390099로 거의 같았습니다. 이 패키지는 개발 의존성이며 배포 `main.js`에는 들어가지 않습니다.
- **설정 컨트롤 정렬과 기본 토글.** Obsidian 토글의 크기·테두리 계산을 덮어쓰던 CSS(3px 테두리, 토글 변수, `::before`/`::after` 보정)를 없앴습니다. 이 CSS가 iPad에서 토글 손잡이를 트랙 밖으로 밀어내고 있었습니다. 이제 토글은 Obsidian·테마 기본 모양을 따릅니다. 드롭다운은 같은 너비로 맞춰 오른쪽(모달에서는 가운데)에 정렬하고, 컨트롤 영역은 터치 영역 44px을 확보합니다. 컨테이너 폭이 420px 미만이면 컨트롤이 설명 아래 전체 폭으로 내려가며 토글은 한 줄을 유지합니다. 태블릿에서 화면 모양 설정 창은 최대 480px입니다.
- **중복 창 방지.** 같은 버튼을 빠르게 두 번 눌러도 대화상자가 두 개 열리지 않습니다.

저장 방식: 설정 저장에 `learnAheadMinutes` 필드가 하나 늘었습니다. 값이 없으면 20분으로 읽으므로 기존 설정은 그대로 동작합니다. 복습 기록(`data.json`의 학습 데이터) 형식과 FSRS 일정 계산은 바뀌지 않았습니다.

`main.js`와 `styles.css`가 바뀌었습니다. 전체 자동 검사 1,770개(실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. 설정 화면 배치는 브라우저 하네스에서 390·820·1024px 폭으로 확인했습니다. **실제 iPad·휴대폰에서는 확인하지 않았고, 사용자 지정 테마에서의 모양도 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
