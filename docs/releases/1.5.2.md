# MIA Study 1.5.2

2026-11-19 정식 배포

**외부 코드 리뷰에서 확인된 문제를 고쳤습니다.** 복습 기록 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **기기 간 충돌 기록 정리.** 두 기기에서 같은 문제를 다르게 평가하거나 설정을 다르게 바꿔 생긴 보관 기록을 이제 지울 수 있습니다. `학습현황`의 `보관된 평가 확인`에서 문제별 `이 보관 기록 지우기`·`보관 기록 모두 지우기`, `보관된 설정 확인`에서 사본별 `이 보관 사본 지우기`(모두 확인 한 번). 지금 쓰는 평가 기록은 바뀌지 않습니다. 지운 기록은 다른 기기와 동기화해도 되살아나지 않도록 학습 기록 파일에 선택 필드 `conflictDismissals`로 기억합니다(옛 버전도 이 필드를 무시하고 그대로 읽음). 문제를 삭제하면 그 문제의 보관 기록도 함께 정리합니다. 이전에는 충돌이 한 번 생기면 경고가 사라지지 않았습니다.
- **FSRS 최적화 안내.** 기록이 부족할 때 `전체 N건 중 최적화에 쓸 수 있는 기록 M건, 최소 8건 필요`로 두 숫자를 나눠 보여 줍니다. 이전에는 전체 건수만 보여 "기록이 많은데 왜 부족하지?"처럼 보였습니다.
- **오늘·학습현황 자동 새로고침.** 30초마다 화면 전체를 다시 그리던 것을, 표시 값(복습·새 문제 수, 학습일, 이어하기 등)이 바뀔 때만 다시 그리도록 바꿨습니다. 스크롤과 포커스가 튀지 않습니다.
- **Word 출력 순서.** 자주 틀림(8번 이상 잊음)이라도 지금 잘 기억하는 문제(복습일 전, 마지막 평가 암기·너무 쉬움, 기억 확률이 목표 기억률 이상)는 맨 앞·부족한 문제에서 빠집니다. 상태 줄의 `자주 틀림`·`잊은 횟수` 표시와 문제 목록의 배지는 그대로입니다.
- **연관 문제 추천.** 현재 문제의 보조 키워드가 다른 문제의 핵심 키워드와 겹치는 경우도 보조 일치로 셉니다(같은 키워드는 한 번만).
- **답변 타이머.** 정답을 보기 전에 보기 설정·학습 설정·키워드 의미 같은 창을 열어 둔 동안은 떠올린 시간이 흐르지 않습니다.
- **자동 검사(CI).** GitHub에 올릴 때마다 전체 검사가 자동으로 돌도록 했습니다.

전체 자동 검사 1,954개(통과 1,952, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 전체 검사가 통과했습니다. 충돌 창은 휴대폰·iPad·데스크톱 크기에서 가로 넘침이 없습니다. **실제 두 기기 동기화와 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
