## 바뀐 점

  - 창 열림: 휴대폰은 아래 52px에서, 데스크톱은 16px·0.96배에서 시작합니다.
  - 탭 전환: 본문이 좌우 28px(대시보드↔학습은 위아래 16px)에서 들어옵니다.
  - 학습 카드는 32px에서 들어오고, 정답 펼침·평가 버튼 줄·진행 바·접는 칸도 조금 더 길고 크게 움직입니다.
- **눌림감:** 주요 버튼과 평가 버튼은 더 눌리고(0.96배), 문제 행·과목 카드·키워드·통계 카드도 누를 때 살짝 들어갑니다(탭 버튼 제외).
- **탭에 들어갈 때:** 카드와 행 앞쪽 8개가 짧은 시간차를 두고 차례로 나타납니다.
- **문제 목록:** 다음 페이지는 오른쪽에서, 이전 페이지는 왼쪽에서 들어오고, 필터·정렬을 바꾸면 살짝 올라옵니다. 검색어를 입력하는 중에는 움직이지 않습니다.
- **저장 표시:** 평가 저장 중 문구와 "평가 저장됨" 배너가 처음 나타날 때만 부드럽게 나타나고, 배너는 8초 뒤 자리를 유지한 채 서서히 사라집니다.
- **문제 상세 패널(데스크톱):** 바깥 상자는 그대로 두고 제목·본문·버튼 줄만 떠오릅니다.
- 동작 줄이기를 켜 두면 위 움직임은 모두 꺼지고, 문제 목록 페이지를 넘길 때의 스크롤도 바로 이동합니다.
