# MIA Study 1.6.1

2026-11-20 정식 배포

**1.6.0 새 디자인의 작은 어색함 두 가지를 고쳤습니다.** 저장 형식, 동작, 복습 일정 계산은 바뀌지 않았고 `styles.css`만 바뀌었습니다.

- **입력칸 왼쪽 여백.** 문제 목록의 검색·필터 칸, 키워드 검색 칸, 선택 상자 등 파인 입력칸에서 글자와 안내 문구가 왼쪽 가장자리에 붙어 보이던 것을 고쳤습니다. 이제 왼쪽에 14px 안쪽 여백이 있습니다.
- **빈 페이지 넘김 막대 숨김.** 문제가 한 쪽에 다 들어가 페이지 넘김 막대에 내용이 없을 때, 목록 아래쪽에 그림자 얼룩처럼 보이던 빈 막대를 숨겼습니다.

함께 GitHub 소개 페이지와 README를 1.6.0 디자인으로 갱신했습니다. 화면 사진은 실제 플러그인 화면 코드에 가상 데모 데이터(수학 기초·세계 지리·요리 과학)를 표시해 새로 찍었고, 소개 페이지는 외부 글꼴을 더 이상 불러오지 않습니다.

전체 자동 검사 2,035개(통과 2,033, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
