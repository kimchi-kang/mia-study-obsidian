# MIA Study 1.4.23

2026-11-16 정식 배포

**학습 화면이 화면 폭을 거의 다 쓰고, 짧은 문답은 스크롤 없이 한 화면에 보입니다.** 저장 형식과 학습 알고리즘은 바뀌지 않았습니다.

- **좌우 여백 최소화.** iPad·휴대폰의 학습 화면 폭 상한을 없애고, 좌우에는 작은 여백(8~16px)과 기기 안전 영역(노치, Stage Manager·Split View 창 위치)만 둡니다. 데스크톱은 아주 넓은 모니터에서 줄이 너무 길어지지 않도록 상한을 1080px에서 1360px로 올렸습니다.
- **빈 옆 칸 제거.** iPad에서 카드 오른쪽에 비어 있던 이어볼 문제 칸을 없앴습니다. 추천은 카드 아래에 나오고, 옆 칸은 넓은 데스크톱에서 추천이 실제로 있을 때만 씁니다.
- **위아래 여백 축소.** `시험 모드 · n/전체` 진행 상자가 대시보드 과목 카드의 여백을 물려받아 커지던 문제를 고치고(약 69px → 44px), 카드·정답 상자·평가 버튼 주변 여백을 줄였습니다. 버튼과 문구는 그대로이고 터치 영역 44px은 유지합니다.

측정(브라우저에서 실제 학습 화면을 렌더한 하네스, 질문 1줄·답 3줄): iPad 가로 1366·1194, 세로 834, Split View 678, iPhone 세로 390, 데스크톱 1440·1920에서 짧은 문답이 스크롤 없이 보이고, 태블릿·휴대폰 카드 폭은 화면의 95~97%입니다. 높이 390px인 iPhone 가로에서는 여전히 스크롤이 필요합니다.

검토: Codex(gpt-6.1-sol)가 구현·검사하고, Claude가 기기 크기별로 측정해 데스크톱·가로 휴대폰 여백을 추가로 맞췄습니다.

`styles.css`가 바뀌었습니다. 전체 자동 검사 1,807개(통과 1,805, 실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. **실제 Obsidian의 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
