# MIA Study 1.7.6

2026-11-22 정식 배포

**실제 Obsidian 화면 검사에서 찾은 문제를 고쳤습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- `문제` 화면에서 문제 상세를 연 채로 검색·필터를 바꿔 그 문제가 결과에서 빠지면, 오른쪽 상세를 비웁니다. 전에는 목록에 없는 문제의 평가·삭제 버튼이 남아 다른 문제를 고칠 위험이 있었습니다.
- Obsidian **밝은 테마**에서 MIA 설정 탭의 카드가 흰색으로 나오고 설명 글자가 흐리게 보이던 것을 고쳐, 테마와 관계없이 MIA의 어두운 카드와 글자색을 씁니다.
- 적색 야간 모드를 **MIA 화면에만** 적용했을 때 MIA 창을 열면 뒤쪽 화면 전체가 밝은 빨강으로 덮이던 것을 고쳐, 창 뒤를 검정으로 가립니다.
- 적색 야간 모드에서 평가 버튼 글자 대비가 4.5:1 아래로 떨어지던 것을 고쳤습니다(평가 버튼 바탕을 더 어둡게).
- 질문·키워드 편집 창 입력칸의 포커스 테두리가 창 가장자리에서 잘리지 않게 입력칸 안쪽에 그립니다.
- 학습 결과 창에서 `직전 평가 취소` 버튼과 통계 카드 사이를 띄웠습니다.
- `키워드` 화면에서 카드 하나의 `연결 문제 보기`를 펼쳐도 같은 줄의 다른 카드가 함께 길어지지 않습니다.
- 휴대폰 폭에서 흔들리는 개념 Top 5 수치의 `애매`가 두 줄로 끊기거나, 목표일 카드의 `학습 전`과 개수가 떨어지던 줄바꿈을 고쳤습니다.
- `오늘` 화면 과목 카드에 파란 막대가 무엇을 세는지 알 수 있게 `학습 6/12` 같은 칩을 붙였습니다.
- 보기 설정·학습 설정·이어볼 문제 창의 스위치와 설정 탭의 폴더 입력칸에 화면 읽기 프로그램용 이름을 붙였습니다.
