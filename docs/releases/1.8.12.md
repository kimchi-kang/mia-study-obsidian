# Major Study 1.8.12

2026-11-28 정식 배포

**코드 전체 점검에서 확인된 문제를 고친 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다(`main.js`·`styles.css` 변경).

## 바뀐 점
- 휴대폰 `문제` 목록이 여러 페이지일 때 페이지 넘김 버튼이 하단 탭 막대 뒤에 가려지던 것을 고쳤습니다. 이제 막대 위에 떠 있습니다.
- 학습 설정의 평가 버튼별 고정 간격 칸에 `1e`처럼 잘못된 숫자를 넣으면 기존 간격이 경고 없이 지워지던 것을 고쳤습니다. 이제 오류로 알려 주고 기존 값을 지킵니다.
- 문제 노트 안에 ```코드```처럼 한 줄로 쓴 코드가 있으면 그 아래 문제가 모두 목록에서 사라지던 것을 고쳤습니다.
- 별칭으로 표시된 키워드를 원래 노트 이름으로 바꾸면 키워드 노트가 자기 자신과 병합되어 휴지통으로 가던 것을 고쳤습니다. 이제 뜻만 저장합니다.
- 학습 화면에서 `다음 순서에 추가` 등을 누른 뒤 Space·1~4 같은 단축키가 먹지 않던 것을 고쳤습니다.
- 다른 기기 시계가 빨라 직전 평가가 미래 시각으로 동기화된 문제에서 평가 버튼 미리보기가 멈추던 것을 고쳤습니다(평가는 기기 시간이 맞을 때까지 지금처럼 막습니다). 손상된 기록의 기억률은 오류 대신 "알 수 없음"으로 처리합니다.
- 두 기기의 설정이 갈라졌을 때 옛 버전 형식의 설정이 사용자가 바꾼 설정을 이겨 되돌아가던 것을 고쳤습니다. 옛 설정은 충돌 목록에 남아 되돌릴 수 있습니다.
- `##` 제목으로 쓴 문제를 다른 과목으로 옮기면 그 과목에 문제를 추가할 때 실패할 수 있던 것을 고쳤습니다. 옮길 때 문제은행의 `###`에 맞추고 안쪽 제목도 같은 만큼 옮깁니다.

## 검증
- 전체 자동 검사 2,169개(통과 2,169, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 코드 줄 판별, 시계 차이 미리보기, 손상 기록, 설정 충돌, 문제 이동 제목 수준, 페이지 넘김 위치 검사 10개를 새로 넣었습니다.
- 설정 충돌 테스트 하나는 옛 동작을 전제로 한 중간 단계를 새 동작에 맞게 바꿨습니다(최종 확인 내용은 그대로).
