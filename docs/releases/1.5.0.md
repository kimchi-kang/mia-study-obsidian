# MIA Study 1.5.0

2026-11-19 정식 배포

**시험 모드 이름을 `시험(일반복습)모드`로 바꿨습니다.** Anki의 일반 복습(질문 → 정답 보기 → 평가 → 다음 복습일 변경)과 같은 방식이라는 것이 이름에서 드러나도록 했습니다. 동작·저장 형식·복습 일정 계산은 바뀌지 않았습니다.

- **바뀐 곳.** 학습 화면 머리줄의 모드 표시, `오늘` 화면의 `시험(일반복습)모드 시작` 버튼, 보기 설정·학습 설정의 설명, 단축키 안내, README·소개 페이지·설치 안내.
- **휴대폰.** 학습 머리줄은 폭이 좁아 `모드`를 숨기고 `시험(일반복습)`으로 표시합니다. 라벨 좌우 여백을 8px에서 6px로 줄여 375px 이상 폭에서는 잘리지 않습니다. 360px 이하에서는 이전처럼 모드 글자 끝이 `…`로 줄어들고, 문제 위치(`1 / 10`)는 항상 보입니다.
- **암기 모드.** 이름과 동작 모두 그대로입니다. 평가 없이 질문과 정답을 넘겨 보며 복습일은 바뀌지 않습니다. 취약한 문제만 일정 걱정 없이 보려면 `문제` → `▲ 취약` → `검색 결과 암기`를 쓰세요.

레이아웃 측정용 예시 데이터의 과목명을 중립 이름으로 바꿨습니다. 학습 화면 900개 사례(5경로 이상 × 9크기 × 라이트·다크)에서 높이 증가와 가로 넘침이 없음을 측정했습니다. 전체 자동 검사 1,908개(통과 1,906, 실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. **실제 Obsidian의 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
