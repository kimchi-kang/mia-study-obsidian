# MIA Study 1.4.14

2026-11-11 정식 배포

**과목 카드·학습현황 과목 카드·키워드 카드의 버튼과 숫자를 정리해 한눈에 보이도록 했습니다. 버튼은 하나도 빠지지 않았고 기능·버튼 이름·저장 방식은 바뀌지 않았습니다.**

- 대시보드 과목 카드: `시험`(채운 버튼)과 `암기`(테두리 버튼)를 한 줄에, 그 아래 얇은 선 밑에 `이름 수정 | 삭제`를 작은 글자 버튼으로 모았습니다. 버튼이 두 줄로 어긋나지 않습니다.
- 학습현황 과목 카드: 숫자 상자 6개를 얇은 선으로 나눈 3×2 목록으로 바꾸고, 학습 전·오늘 복습·못 암기·애매·암기·너무 쉬움에 작은 색 도형을 붙였습니다. `복습 시작`과 `전체 문제`를 한 줄에 둡니다.
- 키워드 카드: `N문제 · 핵심 · 보조` 줄이 중간에 끊기지 않고, `연결 문제 시험`·`연결 문제 암기`를 한 줄에, `연결 질문 보기` 아래에 `키워드 수정 | 키워드 삭제`를 모았습니다. 카드 높이가 줄었습니다.
- 밝은·어두운 테마와 좁은 화면을 모두 지원하며, 휴대폰에서는 작은 버튼도 44px 이상의 터치 영역을 유지합니다.

`styles.css`만 바뀌었고 저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,685개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 데스크톱 Obsidian의 밝은·어두운 테마와 휴대폰 폭(390px)을 확인하고 시험·이름 수정·연결 질문 보기·복습 시작 버튼을 눌러 보았습니다. 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
