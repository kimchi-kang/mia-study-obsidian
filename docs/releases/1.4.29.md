# MIA Study 1.4.29

2026-11-17 정식 배포

**Anki의 자주 틀리는 카드(leech) 표시와 자동 진행을 넣었습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **자주 틀림.** 8번 이상 잊은 문제(FSRS `lapses` 8 이상, Anki 기본 기준)를 `문제` 목록 제목 옆에 `자주 틀림` 배지로 표시합니다. `복습 상태` 필터에 `자주 틀림`을 추가했고, 문제 상세의 `복습 기록` 줄에 `잊은 횟수 N회`를 보여 줍니다. 시험 모드에서 평가로 8번째 잊게 되는 순간 한 번 알림을 띄웁니다. Anki처럼 카드를 자동으로 정지하지는 않습니다.
- **자동 진행.** `보기 설정` → `자동 진행`(기기별, 모두 기본 꺼짐). `질문 시간`(5~60초)이 지나면 정답을 자동으로 보여 주고, `정답 시간`(3~30초)이 지나면 `정답 후 동작`(`건너뛰기` 기본 — 평가 없음, 또는 `못 암기로 평가`)을 하고 다음 문제로 넘어갑니다. 시험 모드만, 카드 머리줄의 `자동 7` 표시를 누르면 일시정지·재개합니다. 앱이 숨겨지거나 창(키워드 의미·편집 등)이 열려 있거나 평가 저장 중에는 멈춥니다. 자동 진행의 일시정지는 답변 타이머(떠올린 시간) 기록에 영향을 주지 않습니다.

보기 설정에 키 3개(`autoQuestionSeconds`, `autoAnswerSeconds`, `autoAnswerAction`)를 저장합니다. 없으면 꺼짐으로 읽습니다. 학습 기록·동기화 파일·Markdown 형식은 그대로입니다. 기능이 꺼진 상태의 학습 화면은 1.4.28과 계산 스타일·크기가 같음을 288개 사례에서 확인했고, 새 배지·자동 표시는 iPad·iPhone·데스크톱 크기에서 높이 증가와 가로 넘침이 없음을 측정했습니다. 전체 자동 검사 1,908개(통과 1,906, 실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. **실제 Obsidian의 iPad·휴대폰과 화면 낭독기에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
