# MIA Study 1.4.20

2026-11-14 정식 배포

**암기 모드를 평가 없는 읽기 전용으로 바꿔 복습 일정은 시험 모드만 바꾸게 했고, 새로 넣은 컨트롤과 암기 화면의 모양을 바우하우스 스타일로 되돌렸습니다. 저장 형식은 바뀌지 않았습니다.**

- **암기 모드는 읽기 전용.** `오늘`의 `전체 암기`, 과목의 `암기`, 키워드, 질문 목록, 질문 상세의 `암기 모드로 보기`가 모두 질문과 정답만 보여 줍니다. 1~4 평가 버튼, 직전 평가 취소, 키워드·후속 링크 패널, 결과 창이 없고 평가와 복습 기한일을 기록하지 않습니다. 아직 기한이 안 된 문제도 포함하며 하루 상한은 적용하지 않습니다. 순서는 `암기 모드 순서` 설정(순서대로/랜덤)을 따릅니다. 이어하기는 암기 세션에도 저장되고, 이전 버전에서 저장된 암기 세션은 읽기 전용으로 복원하며 거기에 남은 평가 요약은 무시합니다. 끝까지 보면 `끝까지 봤습니다` 카드가 나옵니다. 포커스가 버튼에 있을 때 Space로 누르는 동작은 그대로입니다. 시험 모드는 바뀌지 않았습니다.
- **동작 변경 안내.** 이제 암기 모드에서는 평가가 기록되지 않습니다. 복습 일정을 갱신하려면 시험 모드를 사용하세요. 이전에 암기 모드로 남긴 기록은 그대로 보존하며 고치거나 지우지 않습니다.
- **디자인 통일.** 토글은 Obsidian의 스위치 크기·손잡이 계산을 건드리지 않고 MIA 모양(3px 잉크 테두리를 box-shadow로, 꺼짐은 패널색·켜짐은 파랑)을 되찾았습니다. 그래서 1.4.19에서 고친 iPad 손잡이 어긋남은 그대로 고쳐진 상태입니다. 암기 화면과 끝 카드는 시험 모드의 카드·버튼을 그대로 쓰고 이전/다음은 두 칸 줄로 놓습니다. 오늘 화면의 안내 상자, 미리 학습 입력칸, 최적화 버튼은 3px 잉크 테두리·각진 모서리·44px 높이를 씁니다. MIA 색상 밖의 대화상자(후속 링크 창)에서는 컨트롤이 Obsidian 값으로 돌아가 보입니다.
- **테스트 시간 제한.** 설치 도구 왕복 테스트가 전체 병렬 실행에서 vitest 기본 5초를 넘겨 가끔 실패하던 것(1.4.19 배포 때 확인)을 20초로 늘려 고쳤습니다. 플러그인 동작과는 무관합니다.

저장 방식: 바뀌지 않았습니다. 설정과 복습 기록(`data.json`) 형식, FSRS 일정 계산은 그대로이며 이어하기 저장만 암기 세션에도 쓰입니다.

`main.js`와 `styles.css`가 바뀌었습니다. 전체 자동 검사 1,786개(통과 1,784, 실패 0, 생략 2)와 타입 검사·빌드를 통과했습니다. 화면은 브라우저 하네스에서 390·820·1024px 폭으로 확인했습니다. **실제 Obsidian의 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
