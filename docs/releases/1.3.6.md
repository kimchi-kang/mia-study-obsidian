# MIA Study 1.3.6 — 학습 설정과 내 설정 관리 개선

## 주요 변경

- 기존 간편 설정에서 공부량·새 문제 반복·틀린 문제 반복·장기 복습 목표를 구분하고, 자세한 설명과 적용 시점을 확인할 수 있습니다. 고급 설정도 같은 저장값을 사용합니다.
- 공부량 각 항목, 단계 그룹, 복습 목표만 따로 기본값으로 복원할 수 있습니다. 저장 전에는 적용하지 않습니다.
- 정확한 분으로 표현되는 소수 시간·일 입력을 보존합니다. 예: 1.1일은 1,584분입니다. 분 미만 나머지를 반올림하지 않고 오류 이유를 표시합니다.
- 평가 버튼의 90분을 2시간으로, 1,584분을 1일로 표시하던 반올림 오류를 수정했습니다. 장기 간격의 월·년 근삿값에는 ‘약’을 붙입니다. FSRS 학습 알고리즘은 유지합니다.
- 자주 쓰는 다섯 값의 조합을 내 설정으로 저장·불러오기·이름 변경·삭제할 수 있습니다. 같은 이름은 번호로 구분하고, 이름은 기존 값이 채워진 입력칸에서 직접 변경·취소합니다. 이름 변경·삭제만으로 현재 학습값은 바뀌지 않습니다.
- 프리셋과 내 설정의 변경 전후 값을 표시하고 범위 밖 고급값·학습 기록·예약일은 보존합니다. 기존 저장 직렬화·외부 변경 감지·충돌 보관·실패 복구를 사용합니다.
- 문제 목록은 한 페이지 50개로 표시하고 이전 페이지의 Markdown 렌더 자원을 해제합니다. 전체 검색·학습 대상은 유지합니다.
- 진행 중인 이어하기에 선택적 세션 요약을 보존합니다. 저장되지 않은 과거 결과를 추정하거나 완료된 세션 결과를 장기 보관하는 기능은 아닙니다.
- 필수 합성 보관함 감사까지 실행하는 `npm run verify:full`을 추가했습니다.

## 호환성과 검증

기존 설정과 복습 기록을 읽으며 내 설정과 이어하기 요약은 선택 필드로 저장합니다. 업데이트할 때 문제 노트, `data.json`, `ui-state.json`, `MIA Study Sync/`를 교체하지 마세요. Obsidian 최소 지원 표기는 1.8.7을 유지합니다.

버전 번호 변경 전 동일 기능 코드에서 전체 검사 1,283개(실패 0·건너뜀 0), 타입 검사·프로덕션 빌드가 통과했습니다. 실제 Mac Obsidian 1.14.5의 별도 합성 보관함에서 설정 저장·취소·내 설정 관리·앱 새로고침 후 유지·기존 기록 보존을 확인했습니다. 실제 평가 후 간격 90·120·2,880·1,584분이 저장값과 일치했습니다.

280·390·768픽셀의 밝은/어두운 테마와 키보드 조작은 화면 크기 모의 검증입니다. 실제 모바일 터치·가상 키보드와 실제 다기기 전송은 미검증입니다. 기억력이나 시험 정답률을 보장하는 설정은 아닙니다.

현재는 소스 버전 변경이며 1.3.6 원격 릴리스·설치 패키지는 아직 게시하지 않았습니다.
