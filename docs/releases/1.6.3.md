# MIA Study 1.6.3

2026-11-20 정식 배포

**적색 야간 모드의 빈틈을 메웠습니다.** 저장 형식, 학습 동작, 복습 일정 계산은 바뀌지 않았습니다.

- **MIA 창도 적색으로.** `보기 설정`에서 `야간 모드를 Obsidian 전체에 적용`을 끄고(MIA 화면만) 야간을 켜면, 이전에는 학습 설정·보기 설정·질문 추가/편집·문제 상세·Word 출력 같은 창이 평소 색으로 떴습니다. 이 창들은 MIA 화면 밖 맨 위층에 열리기 때문입니다. 이제 MIA 창과 MIA 설정 탭에도 같은 야간 색과 적색 덮개를 씌웁니다.
- **켜짐 표시.** 1.6.0 디자인 교체 때 `야간` 버튼의 켜짐 표시가 눌린 그림자만 남아 검정 바탕에서 거의 구분되지 않았습니다. 켜져 있으면 버튼이 파란 면으로 보입니다.
- **데스크톱 별도 창.** MIA 탭을 별도 창으로 떼어 내도 Obsidian 전체 야간 모드가 그 창에 함께 적용됩니다.
- **저장소 오류에도 멈추지 않음.** 기기 저장소가 가득 차는 등으로 야간 설정을 저장하지 못하면 오류로 멈추지 않고 "야간 모드 설정 저장 실패"를 알린 뒤 상태를 그대로 둡니다. 읽지 못하면 야간 꺼짐으로 시작합니다.

전체 자동 검사 2,041개(통과 2,039, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
