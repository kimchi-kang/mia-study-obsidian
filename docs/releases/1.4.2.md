# MIA Study 1.4.2 · 로컬 후보

- 키보드가 열린 낮은 화면이나 큰 글자에서 저장 버튼 영역이 입력을 가리면, 버튼이 본문과 함께 스크롤되도록 했습니다. 공간이 충분할 때는 하단 고정 배치를 유지합니다.
- 긴 단어가 포함된 문제가 좁은 목록을 밀어 상세·편집·삭제 버튼을 가리지 않도록 했습니다.
- 긴 검색어 표시를 줄바꿈해 좁은 화면에서도 검색 조건을 읽고 눌러 해제할 수 있습니다.

학습 계산, 저장 정책과 설정의 의미는 그대로입니다. 76파일·1,395개 자동 검사, 타입 검사·빌드를 통과했습니다. [브라우저 모바일 모의 검증과 전후 화면](../qa/1.4.2-mobile/README.md). 실제 모바일 Obsidian과 OS 키보드는 미검증입니다. 사용자 설치와 공개 배포는 갱신하지 않았습니다.
