**그림자를 다듬은 디자인 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다(`styles.css`만 변경).

## 바뀐 점
- 완전 검정 바탕에서 버튼·카드의 왼쪽 위로 뿌옇게 번지던 흰 그림자를 없앴습니다. 바탕이 검정이라 오른쪽 아래 검정 그림자는 보이지 않고 밝은 그림자만 남아 번져 보였기 때문입니다.
- 누를 수 있는 버튼과 카드는 윗변 안쪽의 가는 빛, 옅은 윤곽, 아래쪽 그림자로 떠 보입니다. 입력칸·진행 막대·눌린 버튼은 안쪽 그림자로 파여 보여, 누를 수 있는 것과 아닌 것의 구분은 그대로입니다.
- 버튼 면을 카드보다 반 단계 밝게(`#191B21`) 해서 그림자가 약해도 카드와 구분됩니다. 선택된 탭, 탭 이동 표시, 키보드 닫기 버튼도 같은 색입니다.
- 적색 야간 모드에서도 같은 방식으로, 더 옅은 빛을 씁니다.

## 검증
- 전체 자동 검사 2,149개(통과 2,149, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다.
- 디자인 검사를 새 규칙으로 바꿨습니다: 바깥으로 퍼지는 빛이 다시 생기지 않는지, 솟음과 파임이 구분되는지, 버튼 면이 카드보다 밝은지, 버튼 위 글자 대비가 4.5:1 이상인지(적색 야간 포함).
- 레이아웃 하네스(브라우저)에서 휴대폰 `오늘`·학습 화면, 데스크톱 `오늘` 화면, 적색 야간 모드를 확인했습니다.
