**키워드를 누르면 뜨는 창이 키워드 이름과 의미만 보여 줍니다.** 저장 형식과 학습 알고리즘은 바뀌지 않았습니다.

- **의미만 보기.** 전에는 키워드 노트 전체를 Obsidian 문서처럼 보여 줘 제목이 두 번 나오고 `연결` 문제 목록까지 길게 나왔습니다. 이제 키워드 이름을 제목으로, 노트의 `## 의미` 내용만 학습 화면의 `모범 답안` 상자와 같은 바우하우스 스타일로 보여 줍니다. 버튼은 `닫기`와 `키워드 노트 열기`입니다.
- 의미가 비어 있으면 편집에서 적으라는 안내를, `## 의미` 구역이 없는 직접 만든 노트는 제목 줄을 뺀 본문을 보여 줍니다. 노트가 없거나 이미지 같은 파일을 가리키는 경우는 이전과 같습니다.

`main.js`·`styles.css`가 바뀌었습니다. 전체 자동 검사 1,816개(통과 1,814, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, 회귀 검사 2개를 추가했습니다. 창 모양은 iPad·휴대폰 크기의 모의 페이지에서 확인했습니다. **실제 Obsidian의 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
