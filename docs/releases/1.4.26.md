# MIA Study 1.4.26

2026-11-17 정식 배포

**시험 모드에 Anki식 답변 타이머를 넣었습니다.** 복습 일정 계산은 바뀌지 않았습니다.

- **떠올린 시간 표시.** 시험 모드에서 문제가 나오면 카드 머리줄(과목·유형 줄)에 `0:12`처럼 시간이 흐르고, 정답을 보면 멈춥니다. 새 줄을 늘리지 않아 짧은 문답은 여전히 스크롤 없이 보입니다.
- 앱을 내려 두거나 화면이 숨겨진 동안은 세지 않습니다. 최대 60초까지 세고 넘으면 `1:00+`로 표시합니다. 암기 모드와 이미 평가한 카드를 다시 볼 때, 평가 취소 뒤 정답이 열린 채 다시 보일 때는 나오지 않습니다.
- **기록.** 평가할 때 걸린 시간을 복습 기록에 `answer_ms`(밀리초, 최대 60000)로 함께 저장합니다. FSRS 복습 일정과 `내 기록으로 최적화`에는 쓰지 않습니다. 이 값이 없는 기존 기록도 그대로 읽고, 기기 간 동기화 병합에서도 유지됩니다.
- **보기 설정 → `답변 타이머`.** 기본 켜짐, 기기별 설정입니다. 끄면 화면에서만 숨기고 기록은 계속합니다.
- **통계.** 학습 완료 창에 `평균 떠올린 시간`, 문제 상세의 복습 기록 줄에 `떠올린 시간`이 나옵니다.

`main.js`·`styles.css`가 바뀌었습니다. 전체 자동 검사 1,841개(통과 1,839, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, 새 검사 22개를 추가했습니다. 학습 화면 레이아웃 측정(iPad·iPhone 세로·데스크톱)에서 회귀가 없었습니다. **실제 Obsidian의 iPad·휴대폰에서는 확인하지 않았습니다.** 1.4.25 이하 버전이 이 기록을 다시 저장하면 `answer_ms`가 빠질 수 있으니 모든 기기를 함께 업데이트하세요.
