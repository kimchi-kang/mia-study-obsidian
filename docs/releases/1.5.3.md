# MIA Study 1.5.3

2026-11-19 정식 배포

**데이터를 덮어쓰거나 작업이 멈출 수 있던 버그 3개를 먼저 고쳤습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **키워드 노트 덮어쓰기 수정.** 질문 추가·편집 창에서 키워드 의미를 한 칸에 한 줄씩 몰아 쓰던 방식을 **키워드마다 따로 입력하는 칸**으로 바꿨습니다(칸 이름 = 키워드 이름, 여러 줄 가능). 이전에는 어떤 키워드의 의미가 여러 줄이면 줄과 키워드가 어긋나, 의미를 조금만 고쳐도 저장이 막히거나 다른 키워드 노트가 엉뚱한 줄로 덮어써질 수 있었습니다. 이제 **직접 고친 칸만** 저장하고, 손대지 않은 키워드 노트는 건드리지 않습니다. 새로 연결한 키워드에 이미 노트가 있으면 그 의미를 칸에 불러옵니다. 키워드 순서를 바꾸거나 지워도 입력한 의미는 해당 키워드를 따라갑니다.
- **끊어진 꼬리질문 링크로 작업이 멈추던 문제 수정.** 다른 질문에 이미 없어진 질문을 가리키는 꼬리질문 링크가 있으면 질문 삭제·수정·이동이나 과목 삭제·이름 변경이 "연결할 질문이 변경 또는 삭제되었습니다"로 실패했습니다. 이제 이미 끊어져 있던 링크는 원문 그대로 두고 작업을 계속합니다. 과목 삭제는 연결 점검을 **폴더를 휴지통으로 옮기기 전에** 마쳐, 점검 단계에서 막히면 폴더를 옮기지 않습니다.
- **학습 중 보기 설정이 현재 카드에 바로 반영.** 학습 도중 `보기 설정`에서 자동 진행을 끄거나 시간·정답 후 동작·답변 타이머 표시를 바꾸면 현재 카드에 즉시 적용합니다. 이전에는 자동 진행을 꺼도 현재 카드의 카운트다운이 이어져 정답 공개·건너뛰기·`못 암기` 평가가 실행될 수 있었습니다. 떠올린 시간 기록은 이어서 셉니다.

외부 코드 리뷰에서 나온 나머지 항목(노트 없는 키워드 편집, 순서대로 암기 순서 등)은 다음 버전에서 고칩니다. 전체 자동 검사 1,970개(통과 1,968, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 질문 편집 창은 키워드 1·3·8개일 때 휴대폰·iPad·데스크톱 크기에서 가로 넘침이 없습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
