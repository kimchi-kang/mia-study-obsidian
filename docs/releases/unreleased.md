# 다음 릴리스 변경 사항

현재까지의 학습·편집·다기기 저장 보완은 [1.3.5](1.3.5.md)에 포함합니다. 다음 변경은 기존 1.3.5 공개 이후의 설치 후보에 포함되며, 출시 버전은 아직 확정하지 않았습니다. 후보의 manifest 버전은 1.3.5를 유지하므로 `BUILD-INFO.json`과 체크섬으로 구분합니다.

- 문제 목록 페이지를 50개로 제한하고 검색·페이지 변경 시 이전 Markdown 렌더 자원을 해제합니다. 전체 검색·필터·학습 대상은 유지합니다. [성능 검증](../../PERFORMANCE-QA.md)
- 설정 계보·충돌 보존 명세에 맞게 기존 테스트 기대값과 회귀 검사를 보강했습니다. 제품 저장 동작과 FSRS 알고리즘은 추가 변경하지 않았습니다. [검사 정리](../../REMAINING-TESTS-QA.md)
- `npm ci` 후 `npm run verify:full`로 합성 보관함 준비·필수 감사 실행·전체 테스트·타입 검사·프로덕션 빌드를 수행합니다. 준비 실패나 감사 건너뜀은 성공으로 처리하지 않습니다. 합성 데이터 통과가 사용자 보관함 전체의 호환성 보장은 아닙니다.

수동 설치는 대상 보관함을 닫고 ZIP의 `main.js`, `styles.css`, `manifest.json`만 `.obsidian/plugins/mia-study/`에 넣은 뒤 MIA Study를 활성화합니다. 업데이트 시 학습 데이터·설정·이어하기 파일은 교체하지 않습니다. 후보는 먼저 별도 테스트 보관함에서 확인하세요.

실제 모바일·iCloud/Obsidian Sync 두 기기 검증의 남은 범위는 [점검표](../../MOBILE-SYNC-CHECK.md)를 따릅니다.

실제 모바일·실제 다기기 동기화는 미검증입니다. 앱이 읽기 전에 모든 사본이 사라진 원격 기록은 복구할 수 없고, 갈라진 평가 이력을 자동 합산하지 않습니다. 후보 검증은 모든 외부 동기화의 무손실 보장이 아닙니다.

- 이어하기 파일에 선택적 세션 요약(시작 시각·평가 집계)을 보존해 재실행 후 결과와 소요 시간이 초기화되지 않도록 수정했습니다. 기존 이어하기 파일은 그대로 읽으며, 저장되지 않았던 과거 요약은 추정하지 않습니다. 평가 원본·FSRS 계산·출제 정책은 유지하고 안전을 위해 평가 취소용 과거 기준값은 복원하지 않습니다.

- 학습 설정 추가 점검에서 소수 일 단위의 정밀도 오류와 평가 간격 표시 반올림을 수정했습니다. 개별 값·단계 그룹·복습 목표만 기본값으로 복원하고, 내 설정 이름을 직접 편집·취소하며 같은 이름의 조합을 구분할 수 있습니다. 마지막 코드 변경 후 전체 검사 1,283개(건너뜀 0), 타입 검사·빌드를 통과했습니다. 최종본은 실제 Obsidian 1.14.5의 합성 보관함에서도 주요 설정 흐름·네 평가의 예약 간격·앱 새로고침 후 유지·기존 기록 보존을 확인했습니다. 모바일 화면 크기 검증은 실기기 터치·키보드 검증과 구분합니다.
