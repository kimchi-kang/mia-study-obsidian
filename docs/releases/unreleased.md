# 다음 공개 배포용 누적 변경 내역 — 1.3.5 → 1.3.7

**2026-11-04 준비 문서 / 게시하지 않음.** 공개 최신 릴리스는 1.3.5입니다. 아래는 소스·로컬 설치 1.3.7에 이미 구현된 변경이며, 1.3.7 태그·정식 패키지·릴리스 공개를 뜻하지 않습니다. [현재 상태](../../STATUS.md)

## 학습 설정과 내 설정 관리 · 1.3.6 포함

- 간편/고급 설정에서 공부량·학습/재학습 단계·복습 목표와 적용 시점을 설명하고 변경 전후 값을 표시합니다.
- 개별 공부량·단계·목표만 기본값으로 복원하고 저장 전에는 적용하지 않습니다. 정확한 분으로 표현되는 소수 시간/일을 보존합니다.
- 90분·1,584분 등을 과도하게 반올림하던 평가 간격 표시를 수정하고 장기 월/년 근삿값에 ‘약’을 붙입니다.
- 내 설정 저장·불러오기·이름 변경·삭제, 문제 목록 50개 단위 표시와 렌더 자원 해제, 진행 중 이어하기의 선택적 세션 요약을 보완합니다.
- 필수 합성 보관함 감사와 실패·생략 0 확인을 포함한 전체 검사 명령을 제공합니다.

## 입력·저장·화면 제어 UI · 1.3.7 포함

- 잘못된 설정 입력 옆 오류를 유지하고 정상 교정 시 정리합니다.
- 저장 중/실패와 입력 보존 상태를 저장 버튼 근처에 표시하고 재시도 경로를 유지합니다.
- 설정/평가 충돌·미완료 저장·삭제 확인창의 버튼·초점·스크롤을 보완합니다.
- 배경 화면 갱신 후에도 설정을 닫으면 해당 버튼으로 초점을 돌려줍니다.
- 창 너비 변경 후 초점 입력이 고정 저장 영역에 가려지지 않도록 위치와 하단 여유를 조정합니다.

[1.3.7 상세 이력](1.3.7.md). 이 UI 패치는 학습 알고리즘·저장 구조·동기화 정책을 변경하지 않습니다.

## 검증·호환성과 배포 전 남은 일

2026-11-03 1.3.7 전체 검사 1,289개(실패·생략 0), 타입 검사·빌드 통과. 실제 macOS Obsidian 1.15.0의 요청된 데스크톱 UI 검증과 사용자 보관함 정상 재로드 완료. [검증 요약](../qa/1.3.7/README.md)

모바일 실기기·OS 키보드·실제 두 기기 iCloud/Obsidian Sync는 **미검증**이며 Mac 두 환경의 공유 파일 대체 검증도 **부분 완료**입니다. 모의 화면·공유 로컬 파일을 실기기 통과로 표현하지 않습니다. [대체 검증](../qa/1.3.7/paired-desktop.md)

최소 Obsidian 표기는 1.8.7이며 해당 최소 버전에서의 실제 실행을 새로 확인한 것은 아닙니다. 업데이트는 같은 빌드의 main.js·styles.css·manifest.json만 교체하며 문제 노트·학습 기록·설정·이어하기·복구 사본을 보존합니다. 오래된 데이터로 덮거나 이전 버전과 혼합하지 않습니다. [설치·복구](../../INSTALL.md)

향후 배포 승인 후 릴리스 범위·제약을 확정하고 정식 패키지/체크섬을 생성·검증해야 합니다. 이번에는 제품 빌드·설치·원격 푸시·태그·릴리스·Pages 게시를 수행하지 않습니다.
