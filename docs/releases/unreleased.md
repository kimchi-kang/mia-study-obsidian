# MIA Study — 학습·설정·다기기 저장 보완 (미출시)

작업본의 화면·manifest 버전은 **1.3.5**입니다. 이전 로컬 후보 ZIP 이후의 다기기 보호 수정도 소스와 main.js에 포함합니다. 이전 ZIP은 갱신하지 않았으며, GitHub 소스 반영과 정식 릴리스 게시는 구분합니다.

## 포함한 변경

- 학습 설정에서 현재 단계에 맞는 ‘애매’ 반복 간격을 안내합니다. 기본 1분·10분일 때 6분이며, 다른 단계나 고정 간격에서는 안내도 달라집니다.
- 24시간 이상인 단계가 선택되면 복습 상태로 전환됨을 설정과 조작 도움말에 안내합니다. 알고리즘은 교체하지 않았습니다.
- 대시보드·학습현황에 접을 수 있는 ‘통계와 출제량 안내’를 추가해 달력 날짜의 문제 수, 전체 기한 도래 수, 학습일의 예산을 구별합니다.
- 저장 중 외부 파일 도착 알림이 오면 유효한 평가 기록을 먼저 관찰해 두고 저장 완료 뒤 기존 충돌 규칙으로 반영합니다. 알림의 재읽기가 뒤로 밀려 도착 기록을 놓치던 오류를 수정했습니다.
- 외부 기기에서 문제 폴더 설정이 바뀌었을 때 설정만 갱신되고 이전 문제 목록이 남던 오류를 수정했습니다. 기록 새로고침·앱 복귀·외부 설정 알림에서 필요한 경우 다시 읽습니다.
- 이전 작업본의 날짜 경계 학습/재학습 한도 수정, 간편/고급 설정, 세션 중 문제 편집·기록 보존, 저장 중 조작 방지와 편집창 수명주기 수정도 포함합니다.
- 기존 1.3.5 준비 작업의 첫 질문 바로 등록, 저장 상태·실패 안내, 기존 키워드 의미 보존, 하루 한도 도달 안내와 배포 패키지 검증을 포함합니다.

- 설정 변경 계보와 충돌 사본을 보관합니다. 편집 시작값을 아는 경우 서로 다른 항목만 함께 적용하고, 같은 항목 충돌은 현재값을 유지하며 입력한 설정도 보관합니다.
- 기준을 모르는 오프라인 설정 분기는 추측으로 합치지 않습니다. 시작 화면의 ‘보관된 설정 확인’에서 비교하고 전체 사본을 선택할 수 있으며, 선택 전 설정도 보존합니다.
- 호스트 저장 전에 기기 내 미완료 요청 사본을 남깁니다. 실패·재실행 후 ‘미완료 저장 확인’에서 원본을 확인하고 재시도할 수 있습니다. 재시도는 평가를 다시 계산하거나 이력을 합산하지 않습니다.
- 설정 탭의 연속 입력을 직렬화해 이전 로컬 입력이 원격 충돌로 오인되지 않게 합니다.

## 검증 범위와 남은 확인

격리 파일·저장 지연·외부 변경·오래된 세션·프로세스 종료를 자동 검사합니다. 화면 크기 검사는 좁은 화면/스마트폰/펼친 폴드에서의 레이아웃 검사이며 모바일 OS의 키보드·백그라운드 종료·실제 iCloud 전달 검사가 아닙니다. 실제 Obsidian의 후보 ZIP 설치·평가·저장·재실행 결과와 체크섬은 같은 후보 폴더의 검증 기록을 따릅니다.

평가 충돌은 현재의 마지막 수정 판정으로 활성 기록을 선택하고 다른 이력을 별도로 보관합니다. 확인 창에는 이력을 읽는 기능이 있으며 자동 합산이나 수동 ‘이 기록으로 복원’ 기능은 없습니다. 질문 원문의 동시 편집은 오래된 원본 검사를 통과하지 못하면 저장을 거부합니다. 설정과 이어하기는 평가 충돌과 다른 규칙을 사용합니다.

원격 파일을 읽기도 전에 다른 쓰기가 덮어쓰는 동시 전달을 원자적으로 잠그는 동기화 엔진은 없습니다. 최신 파일과 기기 내 복구 사본을 읽어 확인할 수 있는 범위에서 보호합니다. 실제 다기기 동시 평가의 안전성을 보장하는 정식 배포 승인은 별도입니다.

모바일 실기기, iCloud/Obsidian Sync의 실제 두 기기 전달, Windows/Linux 및 최소 지원 Obsidian 1.8.7은 미검증입니다. 후보 배포 준비와 모든 환경의 검증 완료는 구분합니다. 업데이트는 기존 data.json·ui-state.json·문제은행을 유지한 채 main.js·manifest.json·styles.css 세 파일만 교체합니다.

관련 검사 **400개**, 타입 검사·프로덕션 빌드와 실제 macOS Obsidian의 외부 변경 반영·저장 실패·재실행·미완료 복구·연속 설정 입력을 확인했습니다. [최신 검증 보고서](../../MULTI-DEVICE-SYNC-QA.md)와 [실기기 점검표](../../MOBILE-SYNC-CHECK.md)를 참고하세요.

저장 형식은 기존 version1에 선택 항목 settingsSync를 추가합니다. 모든 기기에 같은 수정 빌드가 필요합니다. 구버전은 새 보관 정보를 버릴 수 있습니다. 앱이 읽지 못한 채 모든 사본이 사라진 원격 기록은 복구할 수 없으며, 개별 평가 사건을 식별하는 이벤트 원장이나 분산 잠금은 제공하지 않습니다.
