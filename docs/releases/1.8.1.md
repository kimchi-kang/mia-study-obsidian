# Major Study 1.8.1

2026-11-24 정식 배포

**1.8.0에서 바뀐 설정 탭을 보완한 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- 설정 탭에서 연 `학습 설정` 창에서 `범용 동기화 폴더 사용`을 누른 뒤, 학습 설정은 저장하지 않고 `취소`·`×`·ESC로 닫아도 설정 탭의 동기화 요약과 "아직 모두 도착하지 않았습니다" 경고가 바로 바뀝니다. 전에는 설정 탭을 나갔다 들어와야 바뀌었습니다.
- `학습 설정` 창을 닫으면 키보드 초점이 설정 탭의 `학습 설정 열기` 버튼으로 돌아옵니다.
- 설정 저장 실패 알림의 앞머리를 `MIA`에서 `Major Study`로 맞췄습니다.
- 1.8.0 이후 쓰이지 않게 된 화면 규칙 1개를 `styles.css`에서 지웠습니다(화면 변화 없음).
- 설치 안내와 소개 페이지의 최신 배포 날짜를 바로잡았습니다.

## 검증
- 전체 자동 검사 2,133개(통과 2,133, 실패 0)와 타입 검사·배포 빌드를 통과했습니다. UTC·C 로케일 환경에서는 통과 2,131, 생략 2입니다.
- 새 자동 검사 5개: 동기화를 켠 뒤 저장 없이 닫을 때 요약·경고 갱신, 설정 창을 닫을 때 숨겨지는 탭을 다시 그리지 않음, `×`·ESC·`취소`로 닫은 뒤 초점 복원. 이 중 4개는 수정 전 코드에서 실패하는 것을 확인했습니다.
- CSS 보존 검사의 비교 자료(`tests/fixtures/slim-preserved-css.json`)에서, 지운 규칙 1개만 함께 뺐습니다.
