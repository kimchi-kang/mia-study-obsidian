# MIA Study 1.4.16

2026-11-12 정식 배포

**화면 배치를 다시 짰습니다. 탭이 4개로 줄고, 질문 목록은 오른쪽 상세 패널을 쓰며, 학습 화면은 평가 버튼이 커졌습니다. 저장 방식과 학습 알고리즘은 바뀌지 않았습니다.**

- **탭 4개.** `오늘`(이전 `대시보드`) · `학습현황` · `문제` · `키워드`입니다. `취약 문제` 탭은 없앴고 기능은 두 곳으로 옮겼습니다. `오늘`에는 취약 문제 띠(`취약 문제 시험` / `목록 보기`)가, `문제`에는 긴급도 순으로 정렬되는 `▲ 취약` 필터 칩이 있습니다. `오늘`의 `개선 필요`를 누르면 긴급도 순 취약 목록이 열리고, 이 목록은 300개 상한 대신 50개씩 나눠 보여 줍니다.
- **오늘.** `복습`과 `새 문제` 블록이 커졌고, 시작 패널에 `시험 모드 시작`, `전체 암기 모드`, `기록 새로고침`, `이어하기`가 모였습니다.
- **문제.** 행이 `학습`·`상세`·`편집`·`연결` 열로 정렬되고 `삭제`는 맨 오른쪽 빨간 글자입니다. 행을 누르면 넓은 화면에서는 오른쪽 패널에, 좁은 화면에서는 대화창에 상세가 열립니다. 상태 칩은 `전체` / `오늘 복습` / `학습 전` / `▲ 취약`입니다.
- **이름 통일.** `질문 수정`·`문제 편집`·`키워드 수정`은 `편집`, `연결 관리`는 `연결`, `키워드 삭제`는 `삭제`로 바꿨습니다.
- **학습 화면.** 색이 있는 큰 평가 버튼에 다음 간격과 1–4 키 표시를 붙였고 Space·U 키 안내를 넣었습니다. 넓은 화면에서는 `이어볼 문제`가 오른쪽 열에 놓입니다. 배너의 중복된 `직전 평가 취소` 버튼은 없앴습니다(U 키는 그대로 동작).
- **휴대폰(640px 이하).** 하단 탭 바(키보드가 열려 있거나 집중 모드에서는 숨김), 44px 터치 영역, 상세 창의 2×2 평가 버튼과 고정 동작 바를 넣었습니다.
- **고친 점.** `상세`를 빠르게 두 번 눌러도 창이 하나만 열립니다. 패널은 동작 뒤에도 포커스와 스크롤을 유지하고 다른 창의 포커스를 빼앗지 않습니다. 행과 키워드 버튼에 화면 낭독용 이름을 붙였습니다.

`main.js`와 `styles.css`가 바뀌었고 저장 형식과 학습 알고리즘은 바뀌지 않았습니다. 전체 자동 검사 1,712개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 데스크톱 Obsidian의 밝은·어두운 테마를 여러 폭으로, 휴대폰 폭(390px)을 확인했습니다. 모바일 실기기에서는 따로 확인하지 않았으며, 휴대폰 전체 화면 상세(`.is-phone`)는 CSS 대용으로만 확인했습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)
