# MIA Study 1.4.9

2026-11-10 정식 배포

**복습 간격 계산과 이어하기를 Anki 기준에 맞게 고치고, 저장 순서와 과목 노트 갱신을 다듬었습니다.**

- 복습 간격을 계산할 때 하루가 바뀌는 시각을 하루 시작 시각(기본 04:00, 기기 시간)으로 맞췄습니다. 이전에는 계산 라이브러리가 UTC 날짜를 써서 한국 시간 오전 9시에 날짜가 바뀌었습니다. 예를 들어 23:00에 본 문제를 다음 날 08:00에 다시 보면 같은 날 복습으로 처리되어 다음 간격이 짧아졌습니다(예시 카드에서 20일 → 17일). 이제 1일이 지난 것으로 계산합니다. 같은 학습일 안의 반복(예: 05:00 → 08:00)은 지금처럼 같은 날로 봅니다. 기존 기록은 다시 계산하지 않고 다음 평가부터 적용됩니다.
- 시험 모드에서 이어하기를 하거나 다른 기기의 기록을 새로 불러오면, 아직 풀지 않은 문제 중 이 학습을 시작한 뒤 다른 기기에서 이미 평가한 문제를 목록에서 뺍니다. 같은 문제를 기한 전에 한 번 더 평가하는 일을 막습니다. 암기 모드는 바꾸지 않습니다.
- `오늘 평가` 숫자와 문제 목록의 `오늘` 필터도 하루 시작 시각 기준으로 셉니다. 자정부터 새벽 4시 사이의 평가는 전날로 셉니다.
- 문제를 저장할 때 문제를 먼저 쓰고 키워드 뜻을 나중에 씁니다. 문제 저장이 실패하면 키워드 노트는 바뀌지 않으며, 키워드 뜻 저장만 실패하면 그 사실을 알려 줍니다.
- 다른 과목으로 옮긴 뒤 원래 과목 노트 갱신을 재시도할 때, `문제은행.md`뿐 아니라 과목 폴더의 모든 문제 파일을 반영합니다.
- Obsidian을 시작할 때 내용이 그대로인 과목 노트는 다시 쓰지 않습니다. 여러 기기의 불필요한 동기화를 줄입니다.
- 평가할 때마다 복습 계산기를 새로 만들던 것을 복습 설정이 바뀔 때만 만들도록 줄였습니다.

저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,536개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 새로 추가한 회귀 검사 10개는 수정 전 코드에서 실패하는 것을 확인했고, 40문제를 45일 동안 학습하는 시뮬레이션도 통과합니다. 실제 Obsidian 앱과 모바일 실기기에서는 따로 확인하지 않았습니다.
