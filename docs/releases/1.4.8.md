# MIA Study 1.4.8

2026-11-10 정식 배포

**대시보드·학습현황·문제 목록·학습 화면과 설정 창의 디자인을 새로 정리했습니다.** 기능, 버튼 이름, 저장 방식은 그대로입니다.

- 대시보드 위쪽에 오늘 출제할 복습 수와 새 문제 수를 큰 숫자로 보여 줍니다. 날짜는 하루 시작 시각(기본 04:00)을 따르므로 새벽에는 전날 날짜로 표시됩니다.
- 통계 칸에 항목별 색을 넣었습니다. 복습은 강조색, 새 문제는 파랑, 개선 필요는 빨강, 오늘 평가는 초록입니다.
- 과목 카드에 학습한 문제 비율 막대와 복습·새 문제 배지를 넣었고, 이름 수정·삭제를 시험·암기와 떨어뜨렸습니다.
- 학습현황에 최근 평가 비율 막대와 과목별 진행 막대를 넣었습니다.
- 문제 목록은 줄마다 `학습` 버튼만 강조하고 나머지 버튼은 조용하게 표시합니다.
- 학습 화면의 문제를 별도 카드에 올리고, 넓은 화면에서는 `문제 편집`을 카드 오른쪽 위로 옮겼습니다. 평가 버튼 이름도 평가별 색으로 표시합니다.
- 학습 설정: 간편·고급 전환을 한 줄 전환 버튼으로 바꾸고, 간편 설정 네 항목에 번호를 달았습니다. 고급 설정의 묶음은 카드로 나눴습니다.
- 학습 설정의 저장 버튼 줄이 창 맨 아래에 고정되어, 스크롤할 때 버튼 줄 아래로 내용이 비치지 않습니다. 이를 위해 `내 기기 간 동기화` 안내를 버튼 줄 위로 옮겼습니다.
- 보기 설정은 `학습 화면 · 암기 모드 · 터치 조작` 세 묶음으로 나눴습니다. 이 때문에 `답안 배치`가 `집중 모드` 바로 아래로 옮겨졌습니다.
- 설정 창의 모서리 곡률을 창 18px · 박스 14px · 버튼과 입력칸 10px로 통일했습니다.

학습 알고리즘·저장 형식·동기화 방식은 바뀌지 않았습니다. 전체 자동 검사 1,521개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 실제 Obsidian CSS를 쓰는 브라우저 시뮬레이터에서 데스크톱(1280px)·휴대폰(390px) 폭과 밝은·어두운 테마의 바뀐 화면을 확인했고, 가로 넘침과 44px 미만 버튼은 없었습니다. 실제 Obsidian 앱과 모바일 실기기에서는 따로 확인하지 않았습니다.
