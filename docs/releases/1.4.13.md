# MIA Study 1.4.13

2026-11-11 정식 배포

**MIA 화면을 소개 페이지와 같은 바우하우스 스타일로 새로 꾸몄습니다. 기능·버튼 이름·저장 방식·학습 알고리즘은 바뀌지 않았습니다.**

- 빨강·노랑·파랑 원색과 검정·오프화이트, 두꺼운 테두리, 각진 모서리, 굵은 제목으로 대시보드·학습현황·문제·취약 문제·키워드·학습 화면과 MIA 설정 창을 다시 그렸습니다. 그라데이션과 흐린 그림자는 뺐습니다.
- 평가 버튼 색을 정리했습니다: 못 암기 빨강, 애매 노랑, 암기 검정(어두운 테마에서는 오프화이트), 너무 쉬움 파랑.
- 대시보드의 오늘 복습·새 문제 수를 파랑·노랑 블록으로, 통계 칸과 섹션 제목을 원·사각형·삼각형 표시로 구분합니다.
- 밝은·어두운 테마를 모두 지원합니다. 색은 MIA 화면과 MIA 창 안에만 적용되어 Obsidian의 다른 화면은 그대로입니다.
- 휴대폰의 2×2 평가 버튼, 키보드 대응, 44px 이상 터치 영역 등 반응형 배치는 그대로입니다. 제목 글꼴은 기기에 있는 굵은 한글 글꼴을 쓰며 인터넷에서 글꼴을 받지 않습니다.

`styles.css`만 바뀌었고 저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,685개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 데스크톱 Obsidian의 밝은·어두운 테마와 휴대폰 폭(390px)을 확인했습니다. 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
