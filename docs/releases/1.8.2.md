# Major Study 1.8.2

2026-11-25 정식 배포

**속도 개선 릴리스입니다.** 화면에 보이는 결과(복습 순서, 목록 순서, 숫자)와 저장 형식, 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- 학습 화면을 열어 둔 동안 30초마다 하는 기기 간 기록 확인이 가벼워졌습니다. 기록 파일과 현재 기록이 그대로면 비교·병합을 건너뜁니다. 문제 3천 개 기준으로 한 번에 약 85ms 걸리던 것이 약 18ms가 됩니다. 다른 기기에서 온 기록, 이 기기에서 방금 한 평가, 저장 실패가 있으면 전처럼 전부 확인합니다.
- `오늘`·`학습현황` 화면의 과목 카드가 학습을 시작할 수 있는지 판단할 때, 오늘 학습량을 과목마다 다시 세지 않고 한 번만 셉니다(문제 3천 개, 과목 12개 기준 약 33ms → 4ms).
- `문제` 목록의 기본 정렬(`복습 순`)이 빨라졌습니다. 검색어를 칠 때마다 다시 정렬하던 시간이 문제 3천 개 기준 약 37ms에서 2.5ms로 줄었습니다. 다른 정렬도 같은 방식으로 정리했습니다.

## 검증
- 전체 자동 검사 2,137개(통과 2,137, 실패 0)와 타입 검사·배포 빌드를 통과했습니다. UTC·C 로케일 환경에서는 통과 2,135, 생략 2입니다.
- 새 자동 검사 4개: 기록 파일 원본이 바뀌면 다시 확인, 읽기 오류 뒤 다시 확인, 이 기기에서 평가·설정을 바꾼 뒤 기록 파일이 예전 내용으로 돌아가도 변경을 지키고 다시 저장. 마지막 2개는 확인을 건너뛰는 조건을 일부러 망가뜨린 코드에서 실패하는 것을 확인했습니다.
- 배포 전에 이전 버전(1.8.1)의 기록 저장 코드와 새 코드를 같은 무작위 상황 2,000개(각 60단계: 다른 기기 기록, 기록 파일 되돌림, 평가·삭제·설정 변경, 저장 실패, 동시 실행 등)에 돌려, 매 단계 기록 파일·메모리 기록·저장 횟수·알림·오류가 같음을 확인했습니다.
- 복습 순서와 목록 순서는 이전 코드와 정렬·필터·검색 조합 1,000가지 이상, 학습 관리 설정 6가지에서 같음을 확인했습니다.
- 속도 수치는 합성 자료(문제 1천·3천·1만 개, 최근 180일 복습 이력)로 Mac(Apple M3)에서 잰 값입니다.
