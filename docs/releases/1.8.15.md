# Major Study 1.8.15

2026-11-28 정식 배포

**화면·창 전환 모션을 다듬은 릴리스입니다.** 저장 형식, 복습 일정 계산, 기존 기능 동작은 바뀌지 않았습니다.

## 바뀐 점
- **창 열림:** MIA 창이 열릴 때 살짝 떠오르며 나타납니다(휴대폰은 아래에서 올라옴). 배경도 서서히 어두워집니다. 닫힘은 그대로이고, 키보드가 열려도 다시 재생되지 않습니다.
- **탭 전환:** 오른쪽 탭으로 옮기면 본문이 오른쪽에서, 왼쪽 탭이면 왼쪽에서 들어옵니다. 대시보드와 학습 화면 사이는 지금처럼 아래에서 떠오릅니다.
- **학습 카드:** 다음 문제는 오른쪽에서, 이전 문제·되돌리기는 왼쪽에서 들어옵니다. 진행 바는 카드가 바뀔 때만 부드럽게 채워지고, 정답을 펼칠 때 평가 버튼 줄이 살짝 늦게 올라옵니다.
- **다시 그릴 때는 재생하지 않음:** 같은 카드를 다시 그릴 때(정답 보기, 편집 뒤 복귀, 1분 타이머, 동기화)와 학습 화면에 처음 들어올 때는 카드 모션이 나오지 않습니다.
- **문제 상세 패널(데스크톱):** 다른 문제를 열 때만 내용이 살짝 떠오릅니다.
- **접는 칸:** 직접 눌러 열 때만 내용이 펼쳐지듯 나타납니다. 다시 그리며 열림 상태를 되살릴 때는 움직이지 않습니다.
- **버튼 눌림감:** 주요 버튼과 평가 버튼을 누르면 살짝 들어갑니다(탭 버튼 제외).
- 기기에서 동작 줄이기를 켜 두면 위 움직임은 모두 꺼집니다.

## 검증
- 전체 자동 검사 2,182개(통과 2,182, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 기존 테스트 기대값은 바꾸지 않았습니다.
- 브라우저 하네스(휴대폰 폭 390px)에서 학습 카드·평가 버튼 줄·창 열림 모션을 프레임별로 멈춰, 끝난 뒤 위치 변형이 남지 않고 하단 평가 줄이 움직이지 않는 것을 확인했습니다.
