# MIA Study 1.4.18

2026-11-12 정식 배포

**외부 Codex 검토에서 나온 지적을 두 번째 검토로 확인해 고친 소규모 수정입니다. 취약 필터를 끈 뒤 정렬이 남던 문제, 상태 칩의 키보드 초점, 휴대폰 학습 화면에서 긴 과목 이름이 잘리던 문제를 바로잡았습니다. 저장 방식과 학습 알고리즘은 바뀌지 않았습니다.**

- **취약 필터 해제 뒤 정렬.** `상태: 취약 문제 ×` 칩이나 `필터 전체 해제`로 취약 필터를 끄면 일반 정렬로 돌아옵니다. 1.4.16부터는 필터를 꺼도 긴급도 순서가 그대로 남았습니다.
- **상태 칩 키보드 초점.** `전체` · `오늘 복습` · `학습 전` · `▲ 취약` 칩을 매번 새로 만들지 않고 한 번만 만들어, 키보드로 고른 칩이 초점을 잃지 않습니다. `×` 칩, `필터 전체 해제`, 쪽 이동 뒤에는 초점이 알맞은 곳으로 옮겨 갑니다.
- **휴대폰 학습 화면의 과목·유형.** 긴 과목·유형 이름이 `…`로 잘리지 않고 `질문` 라벨 줄 오른쪽에서 두 줄 이상으로 접힙니다. 질문 제목은 그 아래 전체 폭에서 시작해 이름 옆으로 감기지 않으며, `편집` 버튼과도 겹치지 않습니다. 이름이 짧으면 제목 위치는 이전과 같습니다.
- **CSS 계약 테스트.** 휴대폰 전용 규칙이 보호 대상 학습 버튼과 컨트롤을 숨기거나 줄임표로 자르지 못하게 하는 테스트(`tests/css-phone-visibility.test.ts`, postcss)를 추가했습니다. postcss는 개발 의존성으로 명시했습니다.

`main.js`와 `styles.css`가 바뀌었고 저장 형식과 학습 알고리즘은 바뀌지 않았습니다. 전체 자동 검사 1,727개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 320·390·430px 폭의 밝은·어두운 테마로 확인했습니다. 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
