# MIA Study 1.3.7 — 학습 설정과 마지막 UI 보완

1.3.5 공개판 이후의 1.3.6 기능 개선과 1.3.7 UI 보완을 함께 배포합니다. 최소 Obsidian 버전은 **1.8.7**입니다.

## 주요 변경

- 학습 설정의 공부량·학습/재학습 단계·복습 목표와 적용 시점, 변경 전후 값을 명확하게 표시합니다. 항목별 기본값 복원과 내 설정 저장·불러오기·이름 변경·삭제를 보완합니다.
- 정확한 분으로 표현되는 소수 시간/일 입력을 유지하고, 90분·1,584분 등을 과도하게 반올림하던 간격 표시를 수정합니다.
- 문제 목록을 50개 단위로 표시하고 렌더 자원을 해제하며, 진행 중 이어하기의 선택적 세션 요약을 보존합니다.
- 잘못된 설정 입력 바로 옆에 오류를 유지하고 정상 교정 시 정리합니다.
- 저장 버튼 근처에 저장 중·실패 상태와 입력 유지 안내를 표시하고 재시도 경로를 유지합니다.
- 설정/평가 충돌·미완료 저장·삭제 확인창의 버튼·초점·스크롤을 보완합니다.
- 배경 갱신 후에도 설정을 닫으면 현재 화면의 해당 버튼으로 초점을 돌려줍니다.
- 창 너비 변경 후 초점 입력과 고정 저장 영역이 겹치지 않도록 위치와 하단 여유를 조정합니다.

1.3.7 UI 패치는 학습 알고리즘·저장 구조·동기화 정책을 변경하지 않습니다. 1.3.6의 상세 기능 이력은 [버전 기록](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/docs/releases/1.3.6.md)을 확인하세요.

## 검증 범위

2026-11-03 전체 검사 **1,289개**, 실패·생략 0, 타입 검사·프로덕션 빌드 통과. 실제 macOS Obsidian 1.15.0에서 요청된 데스크톱 UI·세션 복귀·재로드 후 이어하기와 평가 중복 없음을 확인했습니다. 사용자 보관함 정상 재로드 후 1.3.7·이어하기 17/84와 당시 비교한 736개 파일 불변을 확인했습니다.

모바일 실기기·OS 키보드·실제 두 기기 iCloud/Obsidian Sync 전달은 **미검증**입니다. 같은 Mac의 공유 파일 두 환경 검증은 부분 완료이며 실제 클라우드 전송으로 세지 않습니다. 최소 지원 표기가 Obsidian 1.8.7에서의 새 실기기 검증을 뜻하지 않습니다.

## 설치·업데이트

`mia-study-1.3.7.zip`을 풀고 **main.js·styles.css·manifest.json 세 파일만** 대상 보관함의 `.obsidian/plugins/mia-study/`에 넣습니다. ZIP에는 이 세 파일만 들어 있습니다. 개별 파일도 같은 릴리스에서 제공합니다.

기존 세 배포 파일을 백업하고 문제 노트·data.json·ui-state.json·MIA Study Sync·기기 로컬 복구 사본은 보존합니다. 데이터 초기화나 플러그인 폴더 전체 삭제는 필요하지 않습니다. 여러 기기는 같은 버전으로 맞추고 파일 수신 후 정상 재로드하여 제목 옆 **v1.3.7**을 확인합니다. 설치 파일 교체와 실행 중 코드 반영은 별도 단계입니다.

[설치·복구 안내](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md). 배포 파일은 SHA256SUMS와 BUILD-INFO.json으로 검증할 수 있습니다.
