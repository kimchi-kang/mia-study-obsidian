# MIA Study 1.3.7 — 마지막 UI 보완

2026-11-04 기준 **개발·로컬 설치 완료 / 공개 릴리스 미게시**. GitHub main에는 기능 커밋 `dc2328f`가 있으며 공개 최신은 1.3.5입니다. [현재 상태](../../STATUS.md) · [1.3.5 이후 누적 배포 노트](unreleased.md)

- 잘못된 학습 설정 입력 옆에 오류 이유를 유지하고 접근성 설명으로 연결합니다. 값 수정이나 프리셋 변경 시 안내를 정리합니다.
- 저장 버튼 근처에 저장 중·실패 상태와 입력 유지 안내를 표시합니다. 저장 중에는 조작을 비활성화하고 실패 후 재시도를 허용합니다.
- 설정 충돌·평가 충돌·미완료 저장·삭제 확인창에 공통 모달 스타일을 적용해 좁고 낮은 화면의 조작과 스크롤을 보완합니다.
- 학습·보기 설정을 닫으면 갱신된 현재 화면의 설정 버튼으로 초점을 돌려줍니다. 같은 화면을 다시 그릴 때도 설정 버튼 초점을 유지합니다.
- 화면 너비 변경 후 초점 입력을 다시 노출하고 고정 저장 영역의 실제 높이를 반영합니다.

학습 알고리즘·저장 구조·동기화 정책과 설정의 의미·적용 시점은 변경하지 않습니다. 기존 10월 29일 UI 수정과 행동 검사를 보존한 패치 버전입니다. 최소 Obsidian 버전은 1.8.7입니다.

업데이트는 `main.js`, `styles.css`, `manifest.json`만 교체합니다. 문제 노트·학습 기록·설정·이어하기·복구 사본은 교체하지 않습니다. 2026-11-03 후속 실제 앱 검증에서 사용자 보관함 MIA 정상 재로드와 1.3.7 기본 화면을 확인했습니다. 모바일 실기기·OS 키보드·실제 두 기기 전송은 여전히 미검증입니다. 디스크 설치 일치와 현재 실행 상태는 별도 증거로 판단합니다.

기능 커밋은 GitHub main에 반영됐지만 1.3.7 태그·공개 릴리스는 없습니다. 이번 문서 정리의 로컬 커밋도 원격 푸시·게시하지 않습니다.
