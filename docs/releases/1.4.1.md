# 1.4.1 — 학습 설정 입력 오류와 좁은 화면 보정

2026-11-07. 로컬 검증 후보이며 공개 릴리스가 아닙니다. 1.4.0의 Anki 스타일 설정을 유지합니다.

- 잘못된 입력의 오류가 다른 항목을 편집하면 사라지던 문제를 수정했습니다. 해당 값을 올바르게 고치거나 초기화할 때 오류를 해제합니다.
- 목표 기억률의 백분율/기존 비율 중 실제로 편집한 입력에 오류와 키보드 초점을 표시합니다. 백분율 안내를 우선합니다.
- 입력 옆 오류가 오른쪽에서 잘리는 현상과, 좁은 간편 설정에서 오류가 입력칸을 밀어 거의 보이지 않게 만들던 현상을 수정했습니다.
- 학습 알고리즘·기본값·설정 적용 범위·기존 예약과 저장 형식은 변경하지 않았습니다.

76개 파일·1,393개 검사(실패/생략 0), 타입 검사·빌드 통과. 실제 macOS Obsidian 1.15.0의 기존 격리 보관함에서 같은 조건의 재현·수정 후 검증, 설정 저장 실패/복구, 학습/평가 취소/재로드를 확인했습니다. 모바일 실기기·OS 키보드는 미검증입니다.

[상세 결과와 수정 전후 화면](../qa/1.4.1-ui/README.md). 사용자 설치본은 1.3.11 그대로이며 교체하지 않았습니다. 원격 푸시·태그·릴리스 공개도 하지 않았습니다.
