# MIA Study 1.4.10

2026-11-10 정식 배포

**문제·키워드·과목 노트가 잘못 저장되거나 엉뚱한 파일을 건드리지 않도록 입력 검사와 저장 보호를 강화하고, 실패했을 때의 안내를 늘렸습니다.**

- 코드 블록이 닫히지 않은 답안은 저장할 때 거절합니다. 이전에는 같은 문제은행의 이후 문제가 모두 목록에서 사라졌습니다.
- 문제 편집기에서 `[ ] # | ^`가 들어간 키워드 이름과 대상이 빈 링크를 거절합니다. 이전에는 저장한 링크가 깨졌습니다.
- 답안 제목 검사가 문제 자신의 제목 단계를 따릅니다. 이전에는 `####` 문제를 편집하면 답안이 중간에서 잘릴 수 있었습니다.
- 제목 단계가 섞여 한 문제의 범위 안에 다른 문제가 들어 있으면, 그 문제를 삭제하거나 답안을 바꾸는 것을 거절합니다. 이전에는 앞 문제를 삭제하면 뒤 문제도 함께 지워졌습니다. 문제 추가는 파일에 쓰기 전에 먼저 검사하므로, 추가에 실패해도 문제은행에 숨은 블록이 남지 않습니다.
- 키워드 뜻을 문제 파일이나 자동 생성 과목 노트에 쓰지 않습니다. `[[전속]]` 같은 짧은 링크의 뜻은 읽어 온 같은 노트에 저장합니다. 이미지나 PDF로 연결되는 링크는 거절합니다.
- 키워드 폴더 아래에 보이는 문제 파일이나 자동 생성 과목 노트를 키워드로 병합·이름 변경·삭제할 수 없습니다. 이전에는 병합하면 그 파일이 휴지통으로 옮겨졌습니다.
- `이어보기` ID는 링크 대상에서만 읽고, 화면에 표시되는 제목에서는 읽지 않습니다.
- 관리 폴더 밖에 있는 문제를 편집하거나 삭제해도 빈 과목 폴더와 빈 과목 노트를 만들지 않습니다. `문제 폴더` 설정이 비어 있으면 관리 폴더 아래의 과목 이름을 올바르게 인식합니다.
- `편집`, `연결`, `질문 추가` 버튼이 실패하면 아무 반응 없이 끝나지 않고 안내를 보여 줍니다.
- `문제 폴더`와 `키워드 노트 폴더` 설정은 글자를 칠 때마다가 아니라 입력을 확정할 때 저장하고, 입력란에는 실제로 저장된 값을 보여 줍니다.
- 문제 하나에서 `학습`을 눌렀는데 지금 학습할 수 없으면 이유(기한 전, 하루 새 문제 한도, 하루 복습 한도)를 알려 주고, 평가 없이 볼 수 있는 `암기 모드로 보기`를 제안합니다. 복습 예약 방식은 바뀌지 않았습니다.

저장 형식은 바뀌지 않았습니다. 전체 자동 검사 1,612개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 모든 수정에 회귀 검사를 추가했고 수정 전 코드에서 실패하는 것을 확인했습니다. 실제 Obsidian 앱과 모바일 실기기에서는 따로 확인하지 않았습니다.
