## 1.3.3 학습 본문 간소화

## 1.3.0 범용 기기 동기화

`학습 설정` 창 아래의 `내 기기 간 동기화 → 범용 동기화 폴더 사용`을 선택하면, 학습 기록과 이어하기를 일반 보관함의 `MIA Study Sync/` 폴더에 Markdown 파일로 저장한다. 숨김 `.obsidian` 폴더를 전송하지 않는 동기화 도구에서도 일반 노트와 함께 전달할 수 있게 하기 위한 선택 모드다. 기존 iCloud 사용 방식은 기본으로 유지되며 자동 전환하지 않는다.

1. 모든 기기에 같은 최신 MIA를 설치한다.
2. 한 기기에서 `범용 동기화 폴더 사용`을 선택한다. 기존 복습 기록과 이어하기를 복사·병합하고 원래 파일은 보존한다. 이 기기에서는 바로 새 저장 위치를 사용한다.
3. 문제 노트와 `MIA Study Sync/` 폴더 전체를 같은 동기화 대상으로 전달한다.
4. 다른 기기에서 파일 수신이 끝난 뒤 MIA를 다시 시작한다. 공유 폴더를 자동으로 인식한다.

기록·학습 설정·이어하기는 공유하고 보기 설정은 기기별로 유지한다. 이 폴더의 파일은 자동 관리하므로 직접 편집하지 않는다. 이전 플러그인은 새 저장 위치를 알지 못하므로 함께 사용하는 모든 기기를 업데이트한다. 계정 연결·클라우드 전송을 MIA가 대신 수행하는 기능은 아니다. Windows·Android에서도 [Obsidian Sync](https://obsidian.md/help/sync-notes) 또는 [Remotely Save](https://github.com/remotely-save/remotely-save) 등으로 동일한 보관함을 동기화해야 한다. 한 보관함에는 전송 도구 하나를 사용한다.

자동 검사 1,074개 통과, 기존 조건부 검사 2개 제외. 일반 Markdown 파일만 전달하는 두 가상 기기에서 복습·설정·이어하기와 평가 취소를 검증했다. Windows·Android 실기기 전송을 검증한 결과는 아니다. [자세한 범위](../qa/archive/PORTABLE-SYNC-QA.md)

## 1.2.3 내 기기 간 학습 이어쓰기

복습 기록·학습 설정·이어하기 위치는 같은 보관함을 동기화하는 내 기기에서 함께 사용한다. 글자 크기·답안 배치 같은 보기 설정은 기기별로 유지한다. 시작 화면의 `기록 새로고침`은 보관함에 도착한 기록을 다시 읽는다. 시작 화면·학습현황을 열어 둔 동안에는 30초마다 도착한 기록을 확인한다. iCloud 등 보관함 동기화의 파일 전송 자체를 실행하거나 완료 여부를 보증하는 버튼은 아니다. 기기마다 같은 최신 MIA 버전을 사용해야 한다.

전체 자동 검사 1,058개 통과, 기존 조건부 검사 2개 제외. 가상 기기에서 변경한 복습 기록·학습량·이어하기를 함께 불러오는 것과, 앱을 연 뒤 늦게 도착한 파일을 자동 반영하는 것을 검증했다. [검증 범위](../qa/archive/DEVICE-SYNC-QA.md)

## 1.2.2 학습 설정 창

상단 `보기 설정` 옆의 `학습 설정` 버튼을 누르면 별도 창이 열린다. 첫 화면의 긴 설정 폼은 제거했다. 창에서 수정한 값은 `학습 설정 저장`으로 적용하고, 취소하거나 닫으면 버린다. 저장에 실패하면 창과 입력값을 유지해 다시 시도할 수 있다. Obsidian 설정에서도 같은 학습 설정을 변경할 수 있다.

전체 자동 검사 1,056개 통과, 기존 조건부 검사 2개 제외. 320px 브라우저에서 열기·취소·저장 실패·재시도·저장 후 닫힘, 실제 Mac에서 1.2.2 실행과 버튼·학습 설정 창 표시를 확인했다.

## 1.2.1 설정 화면 회귀 수정

Obsidian 설정에서 기존 문제 폴더·목표 기억률·최대 복습 간격이 사라지던 문제와, 기본값 불러오기 후 아래 설정까지 없어지던 문제를 수정했다. 학습 설정 저장 실패 시 다른 설정의 입력값까지 초기화하지 않으며, 좁은 설정 창에서도 간격 입력이 한 열로 배치된다. 전체 자동 검사 1,054개 통과, 기존 조건부 검사 2개 제외. [기능 점검 상세](../qa/archive/USABILITY-QA.md)

## 1.2.0 학습 설정과 보기 설정 개선

첫 화면의 `학습 설정`에서 하루 학습량과 다시 볼 간격을 바꾼다. 간격은 숫자와 `분 후·시간 후·일 후`로 입력하고, 단계 추가·삭제 또는 자동 계산을 선택한다. 출제 순서·하루 시작 시각·FSRS 가중치는 `세부 설정`을 펼쳐 변경한다. `기본값 불러오기`는 입력만 바꾸며, `학습 설정 저장`을 눌러야 적용된다.

보기 설정도 변경 후 `보기 설정 저장`을 눌러 적용한다. 취소하거나 닫으면 변경을 버린다. 켜짐·꺼짐 글자와 기본값 설명을 추가했고, 열 때 첫 조작 항목에 포커스를 주지 않는다. 기존 저장값은 유지한다. [실사용 점검 결과와 한계](../qa/archive/USABILITY-QA.md)

## 1.1.3 첫 화면 학습관리 설정

MIA를 열면 대시보드 상단의 학습 시작 버튼 바로 아래에 상세 학습관리 설정을 펼쳐 표시한다. 별도 Obsidian 설정으로 이동하지 않고 일일 상한·학습 단계·출제 순서·FSRS 매개변수를 수정한 뒤 `학습 설정 저장`을 누른다. 기존 Obsidian 설정과 같은 저장값과 검증을 사용한다. 자동 화면 갱신에도 저장 전 입력값을 유지하며, 저장 실패 시 입력을 보존하고 재시도할 수 있다.

실제 다용도 보관함에서 1.1.3 첫 화면 표시 확인. 320/390px 검증 환경에서 가로 넘침과 44px 미만 조작 요소 미발견. 첫 화면 직접 저장·갱신 중 입력 유지·실패 후 재시도 회귀 검사를 포함해 전체 1,042개 통과, 기존 조건부 검사 2개 제외. 타입 검사·배포 빌드 통과.

## 1.1.0 상세 학습관리

이 절은 1.1.0 도입 당시의 기능 설명입니다. [1.1.0 검증 결과](../qa/archive/STUDY-MANAGEMENT-QA.md) · [현재 버전 상태](../../STATUS.md)

MIA 첫 화면의 `학습 설정`에서 관리한다. Obsidian 설정 → MIA Study에서도 같은 설정을 변경할 수 있다. 학습관리 설정은 `학습 설정 저장`을 눌러 한 번에 적용한다. 기본값은 새 문제 20개/일, 복습 200회/일, 하루 시작 오전 4시, 학습 `1m 10m`, 재학습 `10m`이다. 설정이 없던 설치는 이 기본값으로 시작한다. 기존 저장 설정과 이미 예약된 복습일·평가 이력은 유지한다.

- 일일 상한은 전체 과목에서 공유하며 기기 현지 날짜를 기준으로 초기화한다. 당일 단기 학습·재학습 반복은 상한을 소모하지 않고, 날짜를 넘긴 학습은 복습에 포함한다. `새 문제는 복습 상한 무시`를 켜면 새 문제는 새 문제 상한만 적용한다.
- 새 문제 순서(목록/무작위), 새 문제와 복습 순서(먼저/나중/섞기), 복습 정렬(복습일/기억 확률/무작위/간격)을 선택한다. 기한이 된 당일 학습 단계는 우선 출제한다.
- 학습·재학습 간격은 숫자와 분·시간·일 단위로 추가한다. 자동으로 정하기를 선택하면 FSRS가 계산한다. Anki의 FSRS-6 가중치 21개를 붙여넣을 수 있고 복습일 분산도 선택할 수 있다. 기존 평가별 고정 간격은 이 계산보다 우선한다.
- 시험 모드에 상한을 적용한다. 암기 모드에는 일일 상한을 적용하지 않으며 기존 순서 선택을 유지한다. 이어하기는 이미 선택한 세션을 복원하고, 변경한 상한과 정렬은 새 세션부터 적용한다.
- 학습 단계는 ts-fsrs 5.4.1의 규칙을 따른다. 기본 두 번째 단계의 `애매`도 6분이며, 24시간 이상으로 설정한 단계는 복습 상태로 전환된다. Anki의 단계 동작과 동일하다고 가정하지 않는다. [현재 정책·예시와 검토 항목](../SCHEDULER-POLICIES.md)
- [Anki 공식 설명](https://docs.ankiweb.net/deck-options.html)을 기준으로 이식한 핵심 설정이다. 덱별 프리셋, 형제 카드 묻기, 오디오, 타이머, 자동 넘김, 쉬운 요일, 반복 실패 카드 관리, 가중치 자동 최적화와 SM-2 전용 설정은 제공하지 않는다. 날짜를 넘기는 단계도 Anki의 일 단위 변환 대신 실제 예약 시각을 사용한다.

학습 설정의 `기본값` 버튼은 표시된 항목만 복원한다. 단계와 복습 목표는 해당 세부 조정 안에서 따로 복원할 수 있으며, `학습 설정 저장` 전에는 적용되지 않는다. `내 설정`에서 저장한 조합의 이름 변경을 누르면 기존 이름을 직접 편집하고 취소할 수 있다. 같은 이름은 번호로 구분하며 이름 변경·삭제만으로 현재 학습값은 바뀌지 않는다. 간격은 정확한 분으로 표현되는 소수 시간·일도 입력할 수 있다(예: 1.1일=1,584분). 평가 버튼은 일·시간·분을 표시하고 월·년 근삿값에는 ‘약’을 붙인다.

## 0.9.5 학습 복귀와 기록 보호

- 평가 직후 8초 동안 저장·취소 안내를 표시하고 기존 평가 취소 버튼은 계속 유지한다. 마지막 문제는 완료 창에서도 취소할 수 있다. 높이가 낮은 가로 화면에서는 질문 공간을 위해 기존 취소 버튼을 강조한다.
- 질문·정답 상태와 답안 스크롤, 개념 펼침 상태를 이어하기에 저장한다. 앱 복귀 시 기록을 확인하며 검색 입력과 필터 펼침을 유지한다.
- 복습 파일을 저장 직전과 외부 변경·앱 복귀 때 읽고 문제별 수정 번호로 병합한다. 삭제·취소 표시와 기기 내 복구 사본으로 지연된 파일이 성공한 평가를 덮거나 취소 기록을 되살리는 위험을 줄인다.
- 같은 문제의 분기된 평가 이력은 섞지 않고 보관한다. 취소·초기화 뒤 늦게 도착한 이력도 현재 평가로 되살리지 않고 별도로 보관한다. 취소했던 평가 자체가 남을 수도 있으며, 삭제 표식만으로 다른 기기의 분기 이력과 구별할 수 없기 때문에 원본 보존을 우선한다. 시작 화면의 ‘보관된 평가 확인’에서 볼 수 있다. 마지막 수정 시각과 고유 번호로 결정하므로 기기 시계가 다르면 우선순위에 영향을 준다.
- 폰뿐 아니라 넓은 패드에서도 키보드 높이에 맞추며 ‘키보드 닫기’로 입력을 유지한다. 검색·평가·힌트에 접근성 이름과 상태를 제공하고 모바일 조작 영역은 44px 이상 확보한다.

## 0.9.4 화면 적응

모바일 안전 영역에서 보관함 창이 이미 확보한 여백을 빼고 부족한 만큼만 보완한다. 창 크기와 회전·분할 화면에 따라 여백과 질문 크기를 조정하며, 높이가 아주 낮으면 전체 화면을 스크롤해 질문 영역과 조작 버튼을 유지한다.

## 0.9.3 버튼 여백과 모바일 사이드바 스와이프

- PC·모바일의 텍스트 버튼에 기본 좌우 14px 여백을 적용한다. 넓은 화면의 평가 버튼은 24px, 좁은 화면은 16px로 두고 평가 버튼을 두 줄로 배치해 글씨 공간을 확보한다. 좁은 상단 메뉴는 10px 여백을 쓴다.
- 모바일 MIA 화면에 Obsidian이 인식하는 `data-ignore-swipe`를 적용해 이 화면에서 시작한 앱 사이드바 스와이프를 제외한다. MIA 자체 뒤로가기 제스처와 세로 스크롤은 유지한다. 설치된 Obsidian 1.14.4의 인식 코드로 적용/해제 대조 검증했으며, 실제 폰의 앱 버전과 OS 가장자리 동작은 별도 확인 대상이다.

## 0.9.2 터치 드래그 오평가 방지

- 평가 버튼을 누른 뒤 손가락을 다른 위치로 밀면 클릭으로 평가하지 않는다. 중간 이동 이벤트가 빠져도 손을 뗀 위치를 비교하고, 크게 이동했다 돌아온 동작·두 손가락·취소된 터치도 평가에서 제외한다. 일반 탭·마우스·키보드 평가는 유지한다.

## 0.9.1 제목으로 초기 화면 이동

- 상단 `MIA Study`를 누르면 초기 대시보드로 돌아간다. 진행 중인 학습은 이어하기로 복원한다. 제목은 키보드로도 누를 수 있는 버튼이며 터치 높이를 44px 이상 확보했다.

## 0.9.0 복습 기한과 무작위 출제

- 과목별·전체, 시험·암기 모드의 시작 기준을 통일했다. 복습 기한이 된 문제 → 새 문제 순으로 내고 각 그룹 안에서 Fisher–Yates 방식으로 섞는다. 아직 복습일이 안 된 문제는 제외한다.
- 순서는 시작할 때 한 번 정한다. 이전·다음, 화면 갱신, 이어하기는 저장한 순서를 유지하고 세션 중 재학습 예약과 꼬리질문 직접 추가는 기존처럼 동작한다.
- 오늘 복습과 새 문제가 모두 없으면 시험·암기 버튼을 함께 비활성화한다.

## 0.8.5 학습 중 문제 삭제

- 마지막 남은 문제가 삭제되어도 이전 문제의 재학습 예약을 확인한다. 예정 시각 전에는 대기하고 이미 시각이 지났으면 바로 재출제하여 잘못 완료되는 상황을 막는다.

## 0.8.4 꼬리질문과 평가 취소

- 평가 후 추가한 꼬리질문이 직전 평가 취소와 함께 사라지던 문제를 수정했다. 여러 문제를 연속 추가해도 선택한 순서를 유지하며 평가만 되돌린다.

## 0.8.3 재학습 이동 수정

- 이미 평가한 문제로 돌아가 답안을 확인한 뒤 다음으로 이동해도 예정된 재학습을 유지한다. 아직 평가하지 않은 문제를 건너뛰는 동작은 그대로 제공한다.
- 저장 실패 후 재평가·평가 취소 재시도, 재학습 졸업과 이어하기 종료를 추가 검증했다.

## 0.8.2 PC 단축키 검증

- 한글 키보드에서 U가 `ㅕ`로 전달돼 평가 취소가 작동하지 않던 문제를 수정했다. 물리적인 U키 위치를 함께 인식하며 입력 필드·한글 조합 중·키 반복·보조키 조합에서는 기존과 같이 실행하지 않는다.
- 별도 검증 보관함에서 시험 모드·힌트·Space 공개·숫자키 평가·버튼 취소·한글 U 취소·꼬리질문 미리보기 열기/닫기·큰 글자·넓은 창의 좌우 배치·재실행을 확인했다.

## 0.8.1 안정성 점검

- 복습 기록·설정 저장은 이전 저장 성공 후의 데이터를 기준으로 순서대로 처리한다. 실패한 변경이 다음 저장에 섞이거나 최신 변경이 과거 상태로 되돌아가는 문제를 막는다.
- 오래 걸린 노트 읽기가 최신 수정·삭제·이동·폴더 이름 변경 결과를 덮어쓰지 않게 했다. 인덱스 종료 후 남은 읽기 결과도 무시한다.
- 작업 공간에서 다른 학습 목록을 복원하면 이전 목록의 평가 기준·취소 기록을 초기화해 다른 문제의 이력이 섞이지 않게 한다.
- 질문 상세창의 늦은 렌더링은 닫힌 창에 버튼을 다시 만들지 않는다. 평가 저장 중에는 수정·삭제·학습 시작도 잠시 막는다.
- 복습 이력의 예정일은 해당 평가 직전의 값이므로 `당시 예정`으로 표시한다.

## 0.8.0 이어하기와 보기 설정

- 대시보드의 `마지막 학습`에서 문제·과목·위치·저장 시각을 보고 이어간다. 위치는 플러그인 폴더의 `ui-state.json`에 따로 저장하며 복습 기록 파일을 쓰지 않는다. 보관함 동기화가 끝난 뒤 앱 복귀·이어하기·기록 새로고침에서 파일을 다시 읽고, 열린 대시보드·학습현황에서도 30초마다 도착한 기록을 확인한다. 동시 사용의 충돌 병합이나 실시간 동기화는 제공하지 않는다.
- 이어볼 문제는 질문·모범 답안만 담은 미리보기로 연다. 닫을 때 원래 읽던 위치를 복구한다. 수정·연결·평가는 `전체 상세`에서 별도로 연다.
- 상단 `보기 설정`에서 글자 크기(작게/보통/크게), 정보량(간결하게/자세하게), 집중 모드, 답안 배치, 쓸어넘기기 켜기/끄기·민감도를 바꾼다. 설정은 Obsidian의 기기별·보관함별 로컬 저장소에 기억하므로 다른 기기에 영향을 주지 않는다. Obsidian 1.8.7 이상이 필요하다.
- 집중 모드는 상단 메뉴를 접지만 `보기 설정`과 `학습 나가기`를 남긴다. 나란히 보기는 넓은 창에서 질문·답안을 좌우로 보여주고 좁은 창에서는 자동으로 한 열로 전환한다.
- 정답을 공개하기 전에 `키워드 힌트`만 볼 수 있다. 힌트 사용이나 미리보기만으로 복습 평가를 저장하지 않는다.

## 0.7.0 기기별 조작

- 폰·패드: 화면 왼쪽 가장자리에서 중앙 방향으로 쓸면 학습을 시작한 화면으로 돌아간다. 문제 이동은 하단 이전·다음 버튼을 사용하며 이동만으로 평가를 저장하지 않는다. `보기 설정`에서 뒤로가기 제스처와 민감도를 조정할 수 있다.
- 세로·대각선 움직임, 작은 흔들림, 오래 누르기, 두 번째 손가락, 글자 선택, 왼쪽 가장자리 밖에서 시작한 움직임, 버튼·링크·수식·표·코드·그림 위에서는 뒤로가기를 실행하지 않는다. 저장 중이나 화면 전환 시 진행 중인 제스처를 취소한다.
- 가로 움직임은 손을 뗄 때만 확정하고 방향을 카드에 표시한다. 세로 스크롤과 두 손가락 확대는 브라우저에 맡긴다. [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events) 및 [touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action) 규칙을 사용한다.
- 맥·외장 키보드: Space 정답, 1–4 평가, ← → 이동에 U 직전 평가 취소를 추가했다. 트랙패드의 스크롤과 앱 자체 이동 제스처는 바꾸지 않는다.
- 폰: 하단 44px 이상 이동 버튼, 상단 이동 버튼을 줄인 메뉴, 안전영역 여백, 가로 화면에서 작은 메뉴를 제공한다. 패드는 실제 창 너비에 따라 한 열/두 열로 배치하고, 큰 터치 영역을 유지한다.
- `조작 안내`에서 기기별 조작을 확인할 수 있다. iPhone/iPad 실기기에서의 실제 손가락·회전·홈바 동작은 별도로 확인해야 한다.

## 0.6.0 집중 학습 화면

- 질문과 모범 답안을 구분한 카드, 학습 진행 막대, 색으로 구분한 하단 평가 바를 제공한다. 질문 본문이 제목과 같으면 중복 표시하지 않는다.
- 키워드는 핵심 개념 펼쳐 보기로 정리하고, 넓은 화면에서는 이어볼 문제를 오른쪽에 배치한다. 좁은 창에서는 한 열로 바뀐다.
- 학습 화면에 포커스가 있을 때 Space로 정답 보기, 1–4로 평가, 좌우 화살표로 문제 이동을 지원한다. 입력 중·한글 조합 중·키를 누르고 있는 동안에는 평가하지 않는다. 팝업에는 학습 화면 단축키를 적용하지 않는다.
- 다른 문제로 이동할 때 읽기 위치를 위로 되돌린다.

## 0.5.5 이어볼 문제

- 이어볼 문제의 제목은 학습 목록 포함 여부와 관계없이 상세창을 연다. 현재 학습 위치와 순서는 유지한다.
- 학습 추가 버튼을 분리하고, 이미 포함된 문제는 그 상태를 표시한다. 추가한 학습 순서는 앱 복원용 레이아웃에도 저장한다.
- 이전 평가를 살펴보는 중 새 문제를 추가하면 기존 평가 위치가 밀리지 않도록 학습 끝에 추가한다.

## 0.5.4 화면 동작 수정

- 평가·취소 저장 중에는 화면 이동이나 새 학습 시작을 잠시 막아 학습 순서를 보존한다.
- 학습 완료 팝업은 화면 이동·재시작·탭 닫기 시 취소한다.
- 학습 정보 편집에서 다른 과목의 이어볼 문제 경로를 실제 파일 경로로 유지한다.
- 질문 상세창에서 평가와 초기화의 중복 저장을 막고, 저장 실패 시 기존 버튼 상태를 복구한다.

## 0.5.3 복습 동작

- FSRS-6의 장기 간격에 날짜 분산(fuzz)을 적용한다. 문제 ID와 반복 횟수로 분산을 재현하므로 같은 시각·상태의 간격 미리보기와 실제 평가가 일치하며, 다시 실행해도 같은 문제의 분산값이 바뀌지 않는다.
- 예정 시각이 지난 학습·재학습을 먼저 표시하고, 정규 복습은 FSRS의 예상 기억 확률이 낮은 순서로 표시한다. 새 문제는 복습 뒤에 표시하며, 문제 목록의 `복습 우선`도 같은 기준을 쓴다.
- `기억 안정`은 학습 단계를 마친 정규 복습 상태이면서 현재 예상 기억 확률이 목표 기억률 이상인 문제만 집계한다. 방금 틀린 재학습 문제는 포함하지 않는다.
- 최대 복습 간격은 평가 간격을 분리하는 과정 뒤에도 지키며, 설정 변경이나 업데이트만으로 기존 예약일·복습 기록을 일괄 재작성하지 않는다.
- 앱 시작 시 질문을 읽는 동안 학습 위치를 유지하고, 복원된 학습 범위로 다시 학습할 수 있다.
