# MIA Study 1.7.9

2026-11-22 정식 배포

**학습현황에 지난 학습 기록이 생겼습니다.** 이미 쌓인 복습 기록만 읽으므로 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- `학습현황`의 목표일과 향후 30일 복습량 사이에 **학습 기록**이 생겼습니다. 흐름이 목표일 → 지난 기록 → 앞으로의 복습량 순서가 됩니다.
  - **잔디**: 최근 12주를 하루 한 칸(월요일 시작)으로 보여 주고, 그날 평가한 문제 수에 따라 4단계로 진해집니다. 위에 달 이름이 붙고 오늘 칸에는 테두리가 생깁니다. 칸을 누르면 격자 아래에 그날 문제 수와 떠올린 시간이 나옵니다.
  - **숫자**: 연속 학습일(지난 최장 기록이 더 길면 함께), 오늘·최근 7일 문제 수와 떠올린 시간.
  - **날짜별 학습량 보기**: 공부한 날만 최신순으로 펼쳐 봅니다.
  - 넓은 화면에서는 잔디를 왼쪽, 숫자를 오른쪽에 나란히 둡니다.
- `오늘` 화면 날짜 옆에 `연속 N일` 칩이 붙습니다.
- 기준: 하루는 학습 하루 경계(기본 04:00)로 나누고, 평가(못 암기·애매·암기·너무 쉬움)만 셉니다. 오늘 아직 안 했어도 어제까지 이어졌으면 연속 학습일은 유지됩니다. "떠올린 시간"은 정답을 보기 전까지 걸린 시간의 합이며, 예전 기록이나 타이머를 끈 기록에는 없을 수 있습니다.

전체 자동 검사 2,119개(통과 2,117, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰 360·390px, iPad 768·1024px, 데스크톱 화면 측정에서 가로 넘침이 없고, 적색 야간 모드에서도 잔디 4단계가 밝기로 구분됩니다. **실제 Obsidian과 휴대폰에서 화면, 잔디 칸 누르기는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
