# MIA Study 1.3.10 — 학습일 경계·예약 상한·평가 표시 수정 후보

> **후속 상태 · 2026-11-06:** 아래는 앞선 단계의 보존 기록입니다. 이후 실제 1.3.10 재검증과 1.3.11 재실행 수정 검증을 완료했습니다. [최종 보고서](../qa/1.3.11/README.md)를 우선하세요.

2026-11-06 로컬 후보. **미공개이며 실제 Obsidian 수정 후 재검증이 남아 있습니다.** 공개 1.3.9나 기존 사용자 설치 1.3.7을 교체하지 않습니다.

- DST에서 설정한 학습일 시작 시간이 존재하지 않을 때 전날 경계까지 잘못 밀리던 문제를 수정합니다. 당일 학습 반복의 한도 분류와 집계가 잘못될 수 있었습니다. 건너뛴 civil date도 처리합니다.
- 24시간을 넘는 학습 단계의 scheduled_days 내림 때문에 실제 예약이 최대 간격을 넘던 문제를 수정합니다. due의 실제 시간도 상한으로 제한합니다.
- 오래 열린 평가 화면의 예상 간격이 시간 경과로 달라졌다면 저장 전에 새 간격을 보여 주고 다시 평가하도록 안내합니다. 변경된 간격을 조용히 저장하거나 이력을 중복 추가하지 않습니다.
- 상세 화면 등 공유 평가 경로에서도 직전 평가보다 뒤로 간 기기 시각을 거부하여 이력을 보존합니다.
- 복습 이력에서 FSRS의 계산 기준 시각을 ‘당시 예정’으로 오인하게 하던 표시를 ‘계산 기준’으로 바로잡습니다.

FSRS 5.4.1과 가중치·저장 스키마·동기화 선택 정책은 유지합니다. 일일 선택의 현지 시간과 FSRS 경과일의 UTC 날짜 정의를 혼동하지 않습니다. 고정 세션의 대상 유지·24시간 이상 단계의 라이브러리 상태 전환을 새 정책으로 바꾸지 않습니다.

전체 **1,368개 검사, 실패·생략 0**, 타입 검사·빌드 통과. 실제 1.3.9에서 1분 대기→기한 후 재출제·한 번 평가까지 관찰했습니다. 1.3.10은 기존 테스트 보관함 디스크에 준비했으며 마지막 확인 실행은 1.3.9입니다. 화면 제어 제약으로 1.3.10의 실제 앱 재검증은 미완료입니다.
