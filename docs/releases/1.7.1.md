# MIA Study 1.7.1

2026-11-20 정식 배포

**화면을 다듬었습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

## 바뀐 점
- `오늘` 화면은 파란 버튼을 `시험(일반복습)모드 시작` 하나만 두고, `이어하기`·`질문 추가`·`취약 문제 시험`·과목 `시험`은 한 단계 낮은 버튼으로 바꿨습니다.
- 오늘 화면의 복습·새 문제 숫자 카드가 옆 패널 높이만큼 늘어나지 않습니다.
- 목표일 띠와 취약 문제 띠의 모양을 하나로 맞추고 왼쪽에 작은 색 점을 붙였습니다. 두 띠는 통계 아래에 나란히 놓입니다.
- 기억 안정 비율 링은 청록, 학습 진행 막대는 파랑으로 바꿨습니다. 학습현황 과목 칩 아이콘 색을 평가 색(못 암기·애매·암기·너무 쉬움)에 맞추고, 1열 칩이 왼쪽으로 밀리던 정렬을 고쳤습니다.
- 문제 목록에서 선택한 행 왼쪽에 파란 표시 막대가 생깁니다.
- 학습 화면 타이머 글자가 테두리에 붙지 않게 여백을 넣었습니다.
- 제목·안내 문구·버튼에서 한글 단어가 중간에 끊기지 않습니다. 질문·답안 본문의 긴 수식과 코드는 칸 안에서 가로로 스크롤됩니다.
- 링크 글자를 검정 바탕에서 더 잘 보이는 밝은 파랑으로 바꿨습니다.
- 향후 30일 복습량에 `최대 N문제 · 30일 합계 M문제`를 표시하고, 복습이 있는 날 막대는 최소 높이로 보이게, 목표일 막대는 파랑으로 강조했습니다.
- 휴대폰에서 `학습 설정 / 보기 설정 / 야간` 버튼이 한 줄을 3등분해 채우고, 맨 아래 문구가 하단 탭에 가리지 않게 여백을 늘렸습니다.
