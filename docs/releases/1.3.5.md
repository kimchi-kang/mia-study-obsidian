# MIA Study 1.3.5 — 학습·편집·다기기 저장 개선

## 주요 변경

- 간편·고급 학습 설정과 하루 한도 안내를 개선했습니다. 하루 경계를 넘긴 학습·재학습 문제가 복습 한도를 우회하던 오류를 수정했습니다.
- 학습 중 문제를 편집해도 기존 ID·평가 기록·복습 일정이 유지되도록 보완하고, 오래된 원본 덮어쓰기와 저장 중 중복 조작을 방지했습니다.
- 현재 설정에 맞는 ‘애매’ 반복 간격, 24시간 이상 학습 단계의 복습 전환, 대시보드 통계와 하루 예산의 차이를 안내합니다. FSRS-6 알고리즘은 변경하지 않았습니다.
- 외부 설정 변경 후 문제 목록을 다시 읽고, 저장 중 도착한 평가 기록을 놓치던 오류를 수정했습니다.
- 설정 변경 계보와 충돌 사본을 보관합니다. 편집 시작값을 아는 서로 다른 항목은 함께 적용하고, 같은 항목 충돌이나 불명확한 오프라인 분기는 ‘보관된 설정 확인’에서 비교·선택할 수 있습니다.
- 저장 실패·중단으로 완료 여부가 불확실한 요청은 기기 내 사본으로 보존합니다. ‘미완료 저장 확인’에서 재시도하며 평가를 다시 계산하거나 서로 다른 이력을 합산하지 않습니다.
- 빠른 설정 연속 입력을 직렬화하고, 첫 질문 등록·기존 키워드 의미 보존·실패 안내를 개선했습니다.
- 화면의 생성된 원문 출처 표시를 정리했습니다. 저장된 원문 내용은 유지합니다.

## 업데이트

`main.js`, `manifest.json`, `styles.css` 또는 `mia-study-1.3.5.zip`을 사용하세요. ZIP은 위 세 파일만 포함합니다. 기존 `data.json`, `ui-state.json`, 문제 노트와 MIA Study Sync 폴더는 교체하지 마세요. 자세한 방법은 [설치 안내](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)를 따릅니다.

기존 version1 데이터를 읽으며, 설정 계보를 위한 선택 항목이 추가됩니다. 모든 기기를 같은 1.3.5로 맞추세요. 구버전과 혼용하면 새 보관 정보가 유지되지 않을 수 있습니다. 미완료 저장이 있다면 앱 데이터 초기화 전에 사본을 보관하세요.

## 검증 범위

관련 테스트 **400개**, 타입 검사·프로덕션 빌드가 통과했습니다. 격리된 macOS Obsidian1.14.5에서 평가·저장·외부 변경 반영·앱 재실행·설정 사본 선택·미완료 저장 재시도·연속 설정 입력을 확인했습니다.

실제 iOS/Android, iCloud·Obsidian Sync의 두 기기 전달은 미검증입니다. 앱이 한 번도 읽지 못한 채 모든 사본이 사라진 원격 기록까지 복구할 수는 없습니다. 같은 문제의 갈라진 평가 이력은 보존하지만 자동 합산하지 않습니다. 모든 다기기 동시 쓰기의 무손실을 보장하는 릴리스는 아닙니다. Obsidian 최소 지원 표기는1.8.7을 유지하며 이번 검증은 해당 버전의 새 실기기 검증을 뜻하지 않습니다.
