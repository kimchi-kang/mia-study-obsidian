# MIA Study 1.3.5 — 첫 사용과 저장 흐름 개선

출시 버전: **1.3.5** (2026-10-27 확정). 1.3.4 이후의 호환 가능한 버그 수정과 작은 사용성 개선이며 데이터 형식 변경은 없습니다. 정식 설치 패키지를 로컬에 생성했으며 원격 릴리스는 아직 게시하지 않았습니다.

- 처음 사용할 때 빈 시작 화면에서 첫 질문 등록으로 바로 진입합니다. 과목을 따로 만드는 단계를 거치지 않고 과목 이름과 질문을 함께 등록할 수 있습니다.
- 질문 등록 중에는 진행 상태를 표시하고 중복 실행을 막습니다. 실패 원인을 창 안에 표시하며 입력을 유지해 다시 시도할 수 있습니다.
- 질문에 기존 키워드를 연결할 때 의미를 비워 두면 원래 의미를 보존합니다. 의미를 직접 입력하면 그 내용으로 갱신합니다.
- 하루 학습량에 도달한 경우 이유와 학습 설정으로 이동하는 동작을 안내합니다.
- 키워드 입력 오류를 처리하고, 이미 닫은 키워드 창이 늦은 작업 완료 후 다시 그려지는 문제를 수정했습니다.
- 버전 정보와 라이선스 포함 여부를 검사하고, 세 필수 파일만 ZIP으로 만드는 반복 가능한 배포 준비 절차를 추가했습니다.

## 설치·호환성

저장소 루트 또는 검증 패키지에 동봉된 `INSTALL.md`의 설치 및 안전한 업데이트 절차를 따릅니다. Obsidian 최소 지원 표기는 1.8.7이며 데스크톱·모바일 지원은 유지합니다. 이번 변경에 필수 데이터 변환·초기화·추가 백업 절차는 없습니다. 이전 설정·복습 기록·이어하기와 문제 노트를 보존해 업데이트합니다.

모바일 실기기, Windows·Linux, 최소 지원 앱 버전의 실제 실행과 BRAT의 원격 다운로드·자동 업데이트는 이번 로컬 배포 준비에서 확인하지 못했습니다. 최소 지원 표기는 유지하며, 미검증 환경의 실제 동작을 보장하는 추가 검증 결과는 아닙니다.

검증 중 첫 신규 보관함의 최초 재열기에서 비활성 상태를 한 번 관찰했습니다. 재활성화 후 재열기와 별도 빈 보관함의 최초 활성화·재열기는 정상이었고 원인은 확정하지 못했습니다. 공개 전 독립 수동 설치에서 활성화 유지 여부를 추가 확인하는 것을 권장합니다. 설정·복습·이어하기 데이터 손상은 확인되지 않았습니다.
