# Major Study 1.8.10

2026-11-28 정식 배포

**화면 깜빡임과 흔들림을 줄인 릴리스입니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다(`main.js`·`styles.css` 변경).

## 바뀐 점
- 상단 탭을 옮길 때 선택 표시가 미끄러지기 시작하거나 멈추는 순간 선택 탭이 잠깐 꺼졌다 켜지던 것을 고쳤습니다. `오늘` 탭으로 갈 때 바뀐 것이 없으면 화면을 두 번 그리지 않습니다.
- `정답 보기`를 누를 때 긴 문제를 내려 읽던 위치가 잠깐 맨 위로 튀었다 돌아오던 것을 줄였습니다.
- 휴대폰·태블릿 학습 화면에서 평가를 누르면 "평가 저장 중…" 문구 때문에 아래 평가 버튼들이 들썩이던 것을 고쳤습니다. 문구는 이제 화면 위쪽에 잠깐 떠 있습니다.
- 평가 뒤 8초가 지나 "평가 저장됨" 문구가 사라질 때 평가 버튼이 아래로 내려앉던 것을 고쳤습니다. 문구만 사라지고 버튼 위치는 그대로입니다.
- 다른 앱을 잠깐 보고 돌아오거나 알림창을 내렸다 올렸을 때, 바뀐 것이 없으면 `오늘`·`학습현황` 화면을 다시 그리지 않아 깜빡임과 펼친 패널 접힘이 없어졌습니다.
- 화면이 다시 그려져도 `날짜별 학습량/복습량 보기`, `지난 목표일`, `연결 문제 보기` 같은 펼친 패널이 열린 채로 남습니다.
- 데스크톱 `문제` 탭 오른쪽 상세 패널에서 다른 문제를 누를 때 "상세를 불러오는 중입니다…"가 번쩍이던 것을 고쳤습니다(오래 걸릴 때만 보입니다).
- 설정 화면처럼 아래 버튼 줄이 없는 곳에서 휴대폰 키보드를 열면, `키보드 닫기` 버튼이 입력칸을 가리지 않게 여백을 두었습니다.
- `보기 설정` 창의 아래 버튼 위에도 `학습 설정` 창처럼 흐려지는 경계를 넣었습니다.

## 검증
- 전체 자동 검사 2,159개(통과 2,159, 실패 0, 생략 0)와 타입 검사·배포 빌드를 통과했습니다. 앱 복귀 시 다시 그리지 않음, 탭 전환 효과, 저장 문구·저장됨 문구 배치, 보기 설정 경계, 키보드 여백 검사 5개를 새로 넣었습니다.
- 레이아웃 하네스(브라우저, 390px 휴대폰 폭)에서 "평가 저장 중…"이 떠도 평가 버튼 위치가 그대로인 것을 확인했습니다.

## 미확인
- 실제 휴대폰에서 앱 복귀 시 깜빡임, `키보드 닫기` 가림, 평가 버튼 고정은 확인하지 못했습니다.
