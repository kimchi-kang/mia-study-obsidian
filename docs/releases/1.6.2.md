# MIA Study 1.6.2

2026-11-20 정식 배포

**플러그인 화면 바탕을 완전 검정으로 바꿨습니다.** 저장 형식, 동작, 복습 일정 계산은 바뀌지 않았고 `styles.css`만 바뀌었습니다.

- **검정 바탕.** 화면 바탕이 회청색(#2B2F38)에서 완전 검정(#000000)이 됐습니다. OLED 휴대폰에서는 바탕 부분이 꺼진 화면처럼 보입니다.
- **떠 보이는 카드.** 검정보다 어두운 그림자는 만들 수 없어서, 카드·버튼만 아주 어두운 회색(#111216)으로 두고 좌상단의 은은한 빛과 검정 그림자로 살짝 떠 보이게 했습니다. 입력칸처럼 파인 곳은 그보다 더 어둡습니다(#0A0B0E).
- **글자 대비 유지.** 모든 글자와 버튼 위 글자는 바탕 대비 4.5:1 이상입니다. 적색 야간 모드 바탕도 검정으로 맞췄습니다.

README와 소개 페이지의 화면 사진은 1.6.0의 회청색 바탕으로 찍은 것입니다. 전체 자동 검사 2,035개(통과 2,033, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. **실제 Obsidian과 iPad·휴대폰에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
