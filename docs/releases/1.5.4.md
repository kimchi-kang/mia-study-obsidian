# MIA Study 1.5.4

**외부 코드 리뷰의 두 번째 묶음을 고쳤습니다.** 저장 형식과 복습 일정 계산은 바뀌지 않았습니다.

- **노트 없는 키워드 편집·삭제.** 질문에는 연결돼 있지만 키워드 노트 파일이 없는 키워드는 `키워드` 화면에서 편집·삭제가 항상 실패했습니다. 이제 편집하면 설정한 키워드 폴더에 노트를 만들고, 이름을 바꾸면 질문들의 연결도 새 이름으로 바꿉니다. 삭제하면 지울 노트가 없으므로 질문들의 연결만 정리하며, 확인 창에 노트가 없다고 표시합니다.
- **순서대로 암기가 목록 순서를 따름.** `보기 설정`의 암기 모드 순서가 `순서대로`일 때, `문제`에서 정렬한 결과로 `검색 결과 암기`를 누르면 이제 그 정렬 순서대로 나옵니다(키워드 화면의 `연결 문제 암기`도 같음). 시험(일반복습)모드는 이전처럼 학습 설정의 출제 순서를 따르며, 취약 문제 안내 문구를 실제 동작에 맞게 고쳤습니다.
- **학습 정보 편집 창의 꼬리질문 칸.** 노트 경로에 쉼표가 있는 링크가 쉼표에서 쪼개지던 문제와, 대상 질문을 찾지 못한 링크가 현재 파일 경로로 바뀌어 잘못된 곳을 가리키던 문제를 고쳤습니다. 아무것도 고치지 않고 저장하면 링크가 그대로 유지됩니다.
- **답변 타이머 멈춤.** 앱을 숨겼다 돌아올 때 다른 작업과 겹치면 떠올린 시간이 0:00에 멈춰 있을 수 있던 드문 경우를 고쳤습니다.
