# MIA Study 1.7.0

2026-11-20 정식 배포

**면접·시험 대비용 기능 두 가지를 넣었습니다.** 복습 일정 계산은 바뀌지 않았습니다.

## 목표일(면접·시험) 역산
- `학습현황` 맨 위 **목표일** 섹션에서 면접·시험 날짜를 여러 개(최대 20개) 등록합니다. 이름·날짜·범위 과목(비우면 전체)을 넣습니다.
- 목표일마다 **D-n**, 그날의 **예상 평균 기억률**, 그날 기억 확률이 목표 기억률(학습 설정, 기본 90%)보다 낮아질 **위험 문제 수**, 학습 전 문제 수를 보여 줍니다.
- `위험 문제 학습`을 누르면 그 문제들을 기억률이 낮은 순서로 시험합니다. **아직 복습일이 안 된 문제도 포함**하며, 평가는 평소 시험과 같은 방식으로 기록돼 다음 복습일이 다시 정해집니다.
- **향후 30일 복습량** 막대그래프에 목표일 위치를 표시합니다(하루 복습 상한을 적용하기 전 수치).
- `오늘` 화면 맨 위에 가장 가까운 목표일을 한 줄로 보여 줍니다. 예: `D-12 1차 면접 · 위험 문제 23개`.
- 지난 목표일은 접어서 따로 보관합니다.

## 키워드 취약 레이더
- `키워드` 화면 위에 **흔들리는 개념 Top 5**를 띄웁니다. 개념마다 연결 문제의 평균 기억률, 학습한 문제 수, 잊은 횟수, 최근 못 암기·애매 수를 보여 줍니다.
- `이 개념 학습`으로 그 개념에 연결된 문제만 기억률이 낮은 순서로 시험합니다(복습일 전 문제 포함). 개념 이름을 누르면 의미를 봅니다.
- 키워드 목록에 `취약 순` 정렬을 추가했습니다.

## 저장과 주의
- 목표일은 data.json 설정의 선택 항목(`targetDates`)으로 저장되어 기기 간에 동기화됩니다. 목표일이 없으면 data.json은 이전과 똑같습니다.
- **구버전 MIA가 설치된 기기에서 설정을 저장하면 목표일이 사라질 수 있습니다.** 모든 기기를 1.7.0으로 맞추세요.

전체 자동 검사 2,065개(통과 2,063, 실패 0, 생략 2)와 타입 검사·빌드를 통과했고, UTC·C 로케일 환경에서도 같습니다. 휴대폰 360·390px, iPad, 데스크톱과 적색 야간 모드에서 가로 넘침이 없습니다. **실제 Obsidian과 iPad·휴대폰(날짜 선택기 포함)에서는 확인하지 않았습니다.** [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
