# MIA Study 1.4.5

2026-11-09 정식 배포

화면 디자인을 정돈한 버전입니다. 기능·화면 구성·버튼 위치와 학습 알고리즘·저장 형식은 1.4.4와 같고, `styles.css`만 바뀌었습니다. 모든 색은 Obsidian 테마 변수에서 가져오므로 사용 중인 테마와 강조색이 그대로 적용됩니다.

- 상단 탭은 선택한 탭을 보라색으로 채우는 대신 떠 있는 버튼과 강조색 글자로 표시합니다. 학습 설정·보기 설정 버튼은 테두리만 남겼습니다.
- 대시보드: 시작 카드의 제목과 버튼을 키워 "시험 모드 시작"이 먼저 보이게 했습니다. 통계는 라벨과 큰 숫자를 왼쪽에 정렬한 타일로, 과목·질문·키워드 추가와 출력은 점선 타일로 바꿨습니다.
- 문제 목록: 행마다 "학습"만 강조하고 나머지 버튼은 테두리만 남겼습니다. 삭제는 빨간 배경 대신 빨간 글자와 테두리로 표시합니다. 문제·취약·키워드 화면의 본문은 헤더와 같은 폭으로 가운데 정렬합니다.
- 학습현황: 최근 평가 카드에 평가별 색을 입혔습니다.
- 학습 화면: 모범 답안을 왼쪽 강조색 막대가 있는 패널에 담았습니다. 평가 버튼은 옅은 색 배경과 아래쪽 색 선으로 바꾸고, 평가별 색 구분은 유지했습니다.
- 경고 상자는 왼쪽 색 막대로, 섹션 제목은 가는 구분선으로 정리했습니다.

자동 검사 1,477개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 실제 Obsidian CSS를 쓰는 브라우저 시뮬레이터에서 데스크톱(1200px)과 휴대폰(390px) 폭, 밝은·어두운 테마의 주요 화면을 확인했고 가로 넘침과 44px 미만 버튼은 없었습니다. 실제 Obsidian 앱·모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
