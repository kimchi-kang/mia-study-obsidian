# MIA Study 1.4.15

2026-11-11 정식 배포

**질문 상세 창의 `학습 전으로 초기화`가 실행 전에 한 번 더 확인하고, 상세 창의 버튼 배치를 정리했습니다. 저장 방식과 학습 알고리즘은 바뀌지 않았습니다.**

- `학습 전으로 초기화`를 누르면 확인 창이 먼저 열립니다. 지울 기록 수를 보여 주고, 되돌릴 수 없다고 안내하며, `취소`와 `초기화` 중에서 고르게 합니다.
- 상세 창 버튼을 정리했습니다. 평가 버튼에는 색 막대를 붙였고, `학습 전으로 초기화`는 얇은 선 아래의 작은 빨간 글자 버튼으로 옮겼습니다. `학습`·`질문 수정`·`연결 관리`를 한 묶음으로 두고 `삭제`는 따로 떼어 실수로 누르기 어렵게 했습니다.
- 휴대폰에서는 상세 창의 버튼이 44px 이상의 터치 영역을 유지합니다.

`main.js`와 `styles.css`가 바뀌었고 저장 형식과 학습 알고리즘은 바뀌지 않았습니다. 전체 자동 검사 1,686개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 데스크톱 Obsidian의 밝은·어두운 테마와 휴대폰 폭(390px)을 확인했습니다. 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
