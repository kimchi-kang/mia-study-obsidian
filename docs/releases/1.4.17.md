# MIA Study 1.4.17

2026-11-12 정식 배포

**실제 아이폰으로 써 본 결과를 반영해 휴대폰 화면을 손봤습니다. 학습 화면이 훨씬 컴팩트해졌고, 하단 탭 바와 전체 화면 상세 창의 여백을 바로잡았습니다. 저장 방식과 학습 알고리즘은 바뀌지 않았습니다.**

- **휴대폰 학습 화면(암기·시험).** 높은 머리글, 설정 줄, 모드 배너, 빈 진행 상자를 44px 막대 하나로 합쳤습니다. `학습 나가기` · 모드 · `n/전체` · `학습 설정` · `보기 설정`이 한 줄에 있고 현재 위치는 항상 보입니다. 과목은 카드 안으로 옮겼습니다. 진행은 4px 선으로 보여 줍니다. `편집`은 카드 모서리에 고정했고, 모범 답안 상자는 노란 왼쪽 선과 같은 줄의 `모범 답안` 라벨을 쓰는 납작한 형태이며 줄 간격은 1.6입니다. 평가 버튼은 네 개가 한 줄(높이 56px)에 간격과 함께 놓입니다. 밀어서 이동 안내는 `조작 안내`에 이미 있어 숨겼습니다. 390×624(아이폰에서 Obsidian 자체 막대를 뺀 높이)에서 질문이 413px이 아니라 100px에서 시작하고, 128자 답안이 모두 보입니다. 약 200자까지 들어가며 더 긴 답안은 카드 안에서 스크롤됩니다. 버튼은 하나도 없애지 않았습니다.
- **하단 탭 바.** 최대 폭 제한 때문에 왼쪽으로 치우치고 오른쪽이 비던 문제를 고쳤습니다. 320–640px과 가로 방향에서 전체 폭을 쓰고, 홈 표시줄 안전 영역을 비웁니다. 휴대폰(`data-device="phone"`)에서만 적용되며 좁은 데스크톱 창은 위쪽 탭을 그대로 씁니다.
- **휴대폰 전체 화면 상세 창.** 위·아래·좌·우 안전 영역 여백을 넣어 시계와 다이내믹 아일랜드를 가리지 않습니다. 빨간 `학습 전으로 초기화`는 따로 한 줄에 전부 보입니다. `dvh`를 지원하지 않는 환경을 위해 `100vh` 대체값을 넣었습니다.
- **그 밖에.** 집중 모드에서 아래 여백이 두 번 잡히던 것을 고쳤고, 휴대폰 규칙이 가로 방향(높이 500px 이하, 터치 입력)에도 적용됩니다. 화면 낭독기의 읽는 순서가 보이는 순서와 같아졌습니다.

`main.js`와 `styles.css`가 바뀌었고 저장 형식과 학습 알고리즘은 바뀌지 않았습니다. 전체 자동 검사 1,721개(실패·생략 0)와 타입 검사·빌드를 통과했습니다. 예시 문제로 만든 격리 보관함에서 휴대폰 크기와 안전 영역 여백을 흉내 내 확인했습니다. 모바일 실기기에서는 따로 확인하지 않았습니다. [설치와 복구](https://github.com/kimchi-kang/mia-study-obsidian/blob/main/INSTALL.md)

수동 업데이트는 기존 파일을 백업한 뒤 ZIP의 `main.js`, `styles.css`, `manifest.json`을 함께 교체하세요. 기존 학습 기록·설정·이어하기는 보관함에 유지합니다. 최소 Obsidian 버전은 1.8.7입니다.
