## 검증 중 수정한 문제

- **구형 충돌 사본 시작 실패**: 새 interday필드가 없는1.3.11사본을 엄격 동등 검사에서 손상으로 오인. 실제 플러그인 시작 오류·실패 회귀 확보 후, 없는 새 필드만 기존 의미mix로 보완. 명시한 잘못된 값은 계속거부, ID/계보/나머지 내용 보존·읽기만할때 쓰지않음. 실제 기존사본2개로 정상로드 재검증.
- **백분율 십진 변환**:92.3/100이0.9229999999999999로 저장되는 중간 후보 관찰. 두 자리 백분율의 십진 텍스트 변환으로0.923 저장,92.345/70/99회귀 추가. 기존 값은 자동변환하지 않고 사용자가 입력할 때만 적용. 실제92.3%재저장 및재로드0.923확인.
- **공유 고정 간격 초안 안내**: Hard고정값을 고치면 단계 안내도 즉시 반영하도록 갱신. 행 입력·공백 입력·저장값을 같은 초안으로 유지.

기존 FSRS5.4.1 단계/UTC경과일/현지학습일/최대상한 정책은 새 옵션 외에는 변경하지 않았습니다. 이전 일정 감사의 경계/한도/표시-저장 회귀도 최종 전체 검사에 포함됩니다.

## 보존·실패 분류·제한

QA최종에서 이전 리뷰 전체가 원본과 동일하고, 새 합성문제 하나에 실제Again/Good의 이력2회만 있습니다. 임시순서fixture와 원래 QA설정/기존프리셋은 원복했습니다. 검증한 충돌사본3개는 삭제하지 않았습니다. 기기별보기 설정 유지. QA실행 파일/데이터 백업은 `artifacts/anki-settings-2026-11-06/qa-before-140/`에 보존했습니다. 임시작업 수신 타이머·오류 관찰 리스너는 종료했습니다.

사용자 Anki프리셋 원문2개 지문과 카드/노트/이력 개수는 조사 전후 동일했습니다. 전체DB바이트/모든레코드내용까지 동일하다고 주장하지 않습니다. 원본 DB를 수정하지 않고 안정된 읽기 사본을 조회했습니다. 사용자 MIA디스크는 시작1.3.9→공개1.3.11로 외부 변경이 관찰됐고 원인은 미확정입니다. 직접 설치하지 않았으며 main/manifest2개만 바뀌고 **data.json·ui-state.json·styles.css는 시작 지문과 동일**합니다. 현재 실행 중인 사용자 플러그인의 로드 버전은 검사하지 않았습니다. 개발1.4.0은 QA에만 설치했습니다.

도구/검사 가정 오류는 제품 결함과 구분했습니다. Anki웹 접근성에서 일부 항목 누락/축척좌표 조작 실패가 있어 최신 상태/스크롤·지원된 메뉴/단축키로 조사하고 조건부 항목·프리셋 관리 의미는 공식 소스로 보완했습니다. 입력기 간섭을 분리한 뒤 옵션 진입 성공. Obsidian URL의 한글정규화 경로 실패는 기존 등록 보관함 이름으로 열어 해결했습니다. 일일한도3을 이미 소진했다고 가정한 자동화는 잘못되어 명시한0/20으로 수정했고, 검색시작 버튼 자체의 비활성과 실제 세션 대상 제외를 구분했습니다. 접힌안내의 innerText 누락을 ‘옛빌드’로 오인한 검사는 실제 펼침 후 확인했습니다. 순서fixture 정리 시 옛 resume시간 저장이 거부된 것은 최신위치보호이며, 원본 리뷰 원복 후 과거 QA세션 복원은 새 로컬 의도로 명시했습니다. 이 오류들을 제품 통과/실패로 섞지 않았습니다.

모바일실기기·OS키보드·터치·실제 두 기기/클라우드·장기성능은 미검증입니다. Anki와 MIA의 전체 알고리즘 동등성, 모든 설정 조합의 실기기 검증, 영구누락불가능은 주장하지 않습니다. 새로운배치의 전체조합/한도0·1·기존기본은 자동검사, 대표before/after는 실제앱 증거입니다. 사용자 Anki에서 SM-2전환/최적화/일괄재예약을 실행하지 않았고 미지원 기능을 구현한 것으로 표시하지 않습니다.
