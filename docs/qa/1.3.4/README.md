# MIA Study 1.3.4 정식 배포 · 2026-10-26

1.3.3 소스에서 검증한 반응형 수정을 정식 설치 파일에 포함했습니다. 플러그인 ID·최소 Obsidian 1.8.7은 유지합니다. 1.0.3 이후 학습량·학습 단계·보기 설정·기기 간 이어쓰기와 범용 동기화 폴더 기능도 포함합니다.

- 좁은 설정창의 간격 입력·단위·삭제 버튼을 가용 공간에 맞게 재배치합니다.
- 좁은 학습 화면의 탭 너비를 확보하고, 팝업 닫기 버튼은 최소 44×44px로 보강합니다.
- 배포 빌드와 타입 검사 통과. 전체 자동 검사 1,087개 통과, 보관함 전용 조건부 2개 제외.
- ZIP의 CRC, 파일 목록 및 내부 파일과 빌드 원본의 바이트 일치를 검사했습니다. 릴리스에 각 파일의 SHA-256을 제공합니다.
- [121개 너비와 휴대폰·폴드·태블릿 모의 검증 상세](../1.3.3-responsive/README.md). 이 화면 점검은 1.3.3 소스에서 수행했으며, 1.3.4는 동일한 제품 코드·CSS에 배포 버전 메타데이터만 올렸습니다. 실제 iOS·Android 기기와 OS 키보드 검증은 포함하지 않습니다.

## 설치

정식 릴리스의 ZIP에서 main.js·styles.css·manifest.json을 기존 플러그인 폴더에 교체합니다. 기존 data.json·ui-state.json과 학습 자료는 보존하세요. Obsidian을 다시 시작해 제목 옆 v1.3.4를 확인하세요. 기기 간 공유 시 모든 기기에 같은 버전을 사용하세요. MIA가 클라우드 전송을 대신 실행하는 것은 아닙니다.
