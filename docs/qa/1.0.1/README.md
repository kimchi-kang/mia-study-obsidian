# 1.0.1 수식 수정 검증 — 2026-10-25

- 질문 본문과 제목이 같을 때 학습 화면과 이어볼 문제 미리보기에서도 본문을 한 번 Markdown 렌더링한다. 수식만 있는 질문이 `$...$` 문자열로 남던 경로를 수정했다. 일반 질문은 제목 위치에 한 번만 표시한다.
- 자동 과목 노트에서 `$$` 수식의 줄 경계를 보존한다. 여러 줄 aligned 환경과 TeX `%` 주석 뒤의 식이 한 줄로 합쳐지는 문제를 수정했다. 원본 문제은행이나 기존 사용자 노트는 일괄 수정하지 않는다. 기존 자동 생성 노트는 과목 노트 동기화 후 적용된다.
- 회귀 검사 12개를 추가했다. 기본 자동 검사 1,015개 통과, 조건부 2개는 별도 1,000문제 더미 보관함에서 30초 제한으로 통과했다. 타입 검사와 production 빌드도 통과했다. 과목 노트 신규 검사 6개는 수정 전 4개 실패를 확인했다.
- 설치된 Obsidian 1.14.5의 MathJax 엔진·설정으로 수식만 있는 제목, 위첨자, 분수, 제곱근, aligned 여러 줄 답안과 미리보기를 확인했다. 브라우저 검증 호스트의 파일·설정·Markdown API는 대체 구현이다. 제품 번들은 배포 파일과 같다. MathJax 런타임은 로컬 검증에만 사용하며 재배포하지 않는다.
- 320×568, 390×844, 768×1024, 1280×900에서 수식 2개 렌더링, MathJax 오류 0, 페이지 가로 넘침 없음, 수집된 호스트 오류 0. 미리보기에도 수식 2개, 오류 0. [측정값](browser-results.json).
- 이 패치에서 실제 Mac Obsidian UI·실물 휴대폰·iOS/Android WebView·클라우드 동기화를 새로 검증하지 않았다. 기존 0.10.6의 네 버그 수정 및 Mac/모바일 검사 기록은 [이전 검증](../0.10.6/README.md)에 남긴다.
- Word 출력은 기존처럼 LaTeX 원문을 보존한다. Word 네이티브 수식 개체로 변환하는 기능은 이번 수정에 포함하지 않는다. `\[C\]` 같은 이스케이프 단위 표기는 수식으로 강제 변환하지 않는다.
