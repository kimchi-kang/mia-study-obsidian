## 발견·수정한 결함 6개

1. **학습일 DST 경계 오류**: 없는 02시가 03시로 정규화된 값을 전날에도 적용하여 당일 학습을 interday로 오분류. cap 0에서 제외 가능. 설정 시각 복원 및 건너뛴 civil date 처리. 독립 시간대 회귀와 실제 앱 제어 시간 재검증 통과.
2. **긴 단계 예약 상한 초과**: 1584분의 scheduled_days=1만 보고 실제 26시간24분 due를 허용. 실제 due 차이도 상한 검사. 1일=1440분 실제 앱 통과.
3. **표시와 실제 예약 불일치**: 열린 평가 버튼이 UTC 날짜 전환 후 13일 표시로 18일을 저장. 간격 표시가 달라지면 저장·전진 없이 새 표시 후 재평가. 첫 클릭 불변/두 번째 1회 저장 통과.
4. **시각 역행 상세 평가**: 같은 UTC일의 과거 평가를 상세 경로가 허용. 공유 rate 경계에서 last_review 이전 거부. 원본 기록 불변 통과.
5. **이력 시각 오표시**: upstream ReviewLog.due는 계산 기준(last_review 또는 due). ‘당시 예정’을 ‘계산 기준’으로 정정. 실제 상세 UI 확인.
6. **작업 공간 재실행 상태 손실**: setState가 요약만 복원해 scroll/concepts/skip/seed 누락. 건너뛴 Learning이 같은 세션에 재삽입됨. 동일 큐의 첫 복원에 영구 resume을 반영. 처음 후보의 index 존재 필터도 실제 재실행에서 빈 초기 인덱스 때문에 skip을 제거해 실패했으므로 제거하고, ready 이후 기존 큐 정리에 맡김. 수정 전 동작 회귀 2실패, 초기 인덱스 조건 추가 1실패 확보. 최종 실제 재실행 후 2/2 완료, 동일 세션 재삽입 없음/새 시작 재포함/평가 1회/읽기 유지 통과.

다른 큐의 읽기 상태와 이미 저장된 평가로 전진한 이전 문제의 위치는 복원하지 않습니다. 스키마·FSRS 5.4.1·동기화 병합 정책 변경 없음. [출제 경로·제외 사유·시간 경계·독립 기대값·5건의 상세 원인](../1.3.10/README.md)은 이전 단계의 날짜별 기록으로 보존합니다.

## 자동 검사와 실제 증거의 구분

최종 **76파일·1372검사, 실패/생략 0**, 타입 검사·프로덕션 빌드 통과 (`npm run verify:full`, `artifacts/verification/run-YakfHZ/summary.json`). 1.3.10 전체 1368, 최초 1.3.11 전체 1371은 중간 결과입니다. 현재 검사 수는1372입니다.

실제 시각 경과는 `07-real-minute-observation.json`; UTC/DST는 실제 앱의 제어 Date/렌더러 시간대, 다른 due-only fixtures와 Learning 인공 상태는 각각 job에 명시합니다. 공식 Electron [Debugger API](https://www.electronjs.org/docs/latest/api/debugger)를 통한 렌더러 시간대 조작은 finally에서 해제했고, Mac 시각/시간대는 변경하지 않았습니다.

초기 1.3.9의 +36ms 관찰 뒤 기록이 되돌아온 모호한 결과는 과거 보고서에 그대로 남깁니다. 현재 판정은 새 1.3.10 실시간 루프와 이후 디스크/재로드 보존 증거를 따릅니다. 포커스된 취소에 Enter가 전달됐을 가능성은 확정 원인이 아닙니다.

화면 도구의 비활성 창 ScreenCaptureKit 오류, 키 입력 누락, 자동화의 HTML 목록 번호/스크롤 전 버튼 가시성/존재하지 않는 완료 버튼 가정은 제품 결함과 구분했습니다. 현재 창 재선택·전면 복귀 후 최신 접근성 상태로 조작했고, 성공한 저장은 디스크 확인 후 재클릭하지 않았습니다. 자동화의 숨김 rAF 대기는 시간 제한으로 바로잡았습니다. 수정 초기 후보의 skip 재등장은 제품 결함으로 기록하고 추가 수정했습니다.
