# MIA Study 1.0.0 정식 릴리즈 검증

1.0.0은 검증된 0.10.6의 같은 제품 코드를 정식 버전으로 승격한 릴리즈다. manifest·package 버전과 업데이트 매핑을 올렸으며 플러그인 ID, 학습 데이터 형식, CSS는 유지한다.

1.0.0 패키지에서 기본 자동 검사 1,003개 통과, 조건부 2개는 별도 1,000문제 더미 보관함에서 30초 제한으로 실행해 통과했다. 두 실행의 고유 합계는 1,005개다. 타입 검사·production 빌드도 통과했다. 재빌드 main.js와 styles.css가 0.10.6 배포본과 바이트 단위로 동일함을 확인했다.

[1.0.0 검사 결과](verification.json)

기준 검증의 단일 파일 1,000문제 왕복 변환은 기본 5초 제한에서 약 6.3초가 걸려 시간 초과된 이력이 있다. 해당 추가 검사만 30초 제한을 적용하며 대용량 처리 지연이 사라졌다는 의미는 아니다.

[동일 실행 코드의 실제 Mac·모바일 모의환경 검증](../0.10.6/README.md) · [상세 측정값](../0.10.6/verification.json)

이전 검증: Mac 실제 앱 24개, 모바일 모의환경 6조건·평가/취소 24쌍·추가 16개. 실제 휴대폰·IME·WebView·클라우드 동기화는 미검증이다. 대용량 처리 지연 등 기존 제약과 검사 한계는 위 기록을 따른다.
