# 1.4.2 모바일 화면 모의 검증 · 2026-11-07 KST

기준 소스는 깨끗한 **1.4.1 (`f2842d1`)**, 수정·재검증 빌드는 **1.4.2**다. 실제 플러그인 코드와 CSS로 재현한 UI 결함 3건을 수정했다. 학습 알고리즘, 저장 정책, 설정의 기본값과 의미는 그대로다. 사용자 설치는 디스크 기준 1.3.11이었다. 이번 작업은 소스와 격리 브라우저만 다뤘다.

## 검증 환경과 재현

- 설치된 Xcode/Android 시뮬레이터나 실제 모바일 Obsidian에 접근하지 못했다. 기존 QA 웹 환경을 재사용했다. Obsidian API와 보관함 저장소를 브라우저에서 대체하고 실제 빌드의 JS와 CSS가 제품 화면을 그리게 했다. 데이터는 브라우저의 합성 보관함에만 저장했다. 기존 예제 5개, 실제 화면에서 등록한 긴 문제 1개, 별도 65문제 목록·충돌 사본을 사용했다.
- **Chrome 모바일 에뮬레이션 / 1.4.1**: coarse pointer, hover 없음, 터치 포인트 1. 실제 브라우저 탭 조작에서 `pointerType=touch`, `isTrusted=true`를 관찰했다. 390×844에서 설정 입력·저장과 합성 문제 등록을 수행했다. 후속 Chrome 창 선택이 사용자 창을 가리켜, 수정 전후 비교와 최종 조작은 **앱 내 브라우저**에서 수행했다. 후자는 모바일 플러그인 경로와 가용 크기를 재현했으며 입력은 기본 브라우저 포인터·키보드다. 최종 빌드에서 터치 전용 동작을 다시 확인하지는 못했다.
- 창의 **실제 가용 높이**를 예: 280×653 → 280×343, 390×844 → 390×534로 줄였다. 플러그인의 높이 측정과 브라우저 `resize`·`visualViewport.resize`를 관찰했다. 오프셋은 0이었으며, OS 키보드 화면이나 비영점 오프셋은 검증하지 않았다. 안전 영역 위 24 / 아래 34px와 0, 글자 크기 100/125/150%는 브라우저의 합성 조건이다. 일부 호스트 글꼴이 대체 글꼴로 표시됐다.
- 같은 컴퓨터의 원본 환경은 저장소 아래 `artifacts/mobile-simulation-2026-11-07/site/`에 보존했다. 이 디렉터리에서 `python3 -m http.server 8767 --bind 127.0.0.1`을 실행하고, `compare-before.html?build=before&device=phone&scenario=review-before&fixture=stress`와 `compare-after.html?device=phone&scenario=review-after&fixture=stress`를 연다. 각 시나리오 이름을 새로 쓰면 이전 브라우저 저장값의 영향을 피할 수 있다. `검증 조건`에서 테마·글자·안전 영역·분할을 선택한 뒤 패널을 접고 제품을 조작한다. 코드/스타일 교체 없이 다양한 크기를 적용할 수 있다. 65개는 최종 앱의 `scenario=many`, 충돌은 새 시나리오에 `conflict=1`을 사용한다.

## 자동 검사와 남은 범위

- 짧은 창에서 버튼 영역을 본문과 같이 스크롤하고, 일반 높이로 복구하며, 입력과 초점을 유지하는 회귀 검사 2개는 수정 전 실패했다. 수정 뒤 관련 검사 82개, `npm run verify:full` 76파일·1,395개 검사(실패/생략 0), 타입 검사와 배포 빌드가 통과했다.
- 실제 Obsidian 모바일·OS 키보드·안전 영역·회전, 최종 빌드의 터치 제스처와 스크롤 관성, 실제 앱의 팝업 초점, 비영점 visual viewport 오프셋, 두 기기 동기화는 미검증이다. 사용 흐름의 모든 글자·테마·화면 크기 조합, 모든 평가와 삭제 확정도 전수하지 않았다. 데스크톱 확인 역시 이번에는 웹 호스트다. 마우스 휠을 초점이 있는 숫자 입력에 놓으면 브라우저가 숫자를 바꾼다. 의도한 92.3 저장은 해당 휠 조작 없이 별도로 확인했다.
- 사용자 플러그인 파일 세 개와 학습 `data.json`은 시작/종료 SHA-256이 동일했다. 사용자 앱의 `ui-state.json` 해시는 관찰 사이 달라졌다. 이 작업은 사용자 보관함에 쓰거나 Obsidian을 조작하지 않았으며, 해당 파일이 바뀐 원인은 확인하지 않았다. 원격 전송·릴리스 없음.
- 추가 화면·합성 저장 상태·터치 이벤트·브라우저 호스트는 로컬 `artifacts/mobile-simulation-2026-11-07/`에 있다. [후보 변경 내역](../../releases/1.4.2.md) · [이전 실제 데스크톱 검증](../1.4.1-ui/README.md)
