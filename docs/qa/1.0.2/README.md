# 1.0.2 — 이어하기 및 수식 제목 표시 수정

- 1.0.1에서 빠진 대시보드 이어하기 카드·이어볼 문제 버튼 제목을 수정했다. 본문과 제목이 다른 질문의 학습·미리보기 제목도 수식 렌더링을 거친다.
- 문제 목록·등록 후보·취약 문제·키워드 연결 질문·상세 제목/관련 질문·연결 관리·학습 정보·질문 편집의 연결 선택 제목에도 같은 처리 함수를 적용했다. 편집 입력란·검색용 원문·접근성 라벨은 원문을 보존한다.
- 일반 제목은 기존 텍스트 표시를 유지하고, 수식이 있는 번호 제목이 Markdown 목록으로 바뀌지 않도록 한다. `$$`만 있는 기존 제목은 ‘수식 질문’으로 표시한다.
- 질문 생성·수정 시 수식 제목에서 `_`·`*` 문자가 제거되거나 긴 식이 90자로 잘리던 문제를 수정했다. 개인 문제은행을 일괄 재작성하지 않으며, 이미 손상된 저장 제목의 자동 복원은 포함하지 않는다. 질문을 다시 저장하면 새 제목 생성 규칙이 적용된다.
- 기본 자동 검사 1,024개, 별도 1,000문제 조건부 검사 2개(30초 제한), 타입 검사·production 빌드 통과. 회귀 검사는 이어하기 카드→진입, 추천 버튼→미리보기 동작, 제목 번호·TeX 보존을 포함한다.
- 브라우저 모의환경에서 실제 이어하기 버튼을 눌러 저장 카드의 수식 1개, 진입한 질문 제목 1개, 추천 제목 1개와 클릭 후 미리보기 제목 1개의 MathJax 렌더링을 확인했다. 호스트 수집 오류는 없었다. 설치된 Obsidian 1.14.5 MathJax 엔진과 대체 파일·설정·Markdown API를 사용했다. 전체 편집 화면은 자동 검사 및 호출부 검토 범위이며 각각의 실기기 UI 검증을 주장하지 않는다.
- 실제 Mac Obsidian 더미 보관함에 수정본을 설치했으나 제어 연결의 입력/창 전환 실패로 이어하기 동작 검증은 완료하지 못했다. 실제 휴대폰·클라우드 동기화도 이번 패치에서 검증하지 않았다.
- Word 출력의 LaTeX 원문 보존, 기존 과목 요약은 동기화 후 재생성하는 방식은 유지한다. [1.0.1 검증](../1.0.1/README.md).
