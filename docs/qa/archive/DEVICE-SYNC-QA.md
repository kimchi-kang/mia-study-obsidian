# 1.2.3 기기 간 기록 갱신

2026-10-26. 기존 복습 기록·학습 설정은 data.json, 이어하기는 ui-state.json으로 보관함과 함께 전달되며, 보기 설정은 기기별 로컬 저장소를 사용한다. 이 버전은 파일 전송 서비스를 추가하지 않는다.

## 변경

- 시작 화면에 기록 새로고침 버튼과 같은 보관함을 사용하는 조건을 안내한다. 성공 메시지는 보관함에 도착한 기록 확인을 뜻하며 원격 전송 완료를 뜻하지 않는다.
- 열린 대시보드·학습현황의 기존 30초 갱신에서 메모리만 다시 그리던 대신, 복습 기록과 이어하기 파일을 다시 읽는다. 앱이 숨겨졌거나 평가 저장 중이면 주기 확인을 건너뛴다. 앱 복귀 시 확인과 기존 충돌·취소 보호는 유지한다.

## 검증

- 별도 로컬 체크포인트를 가진 두 가상 기기에서 복습 평가, 하루 새 문제 7, 이어하기의 정답 상태가 새로고침 후 함께 반영되고 보기 설정이 유지되는 통합 검사를 추가했다. 읽기 실패 후 기존 상태 유지와 재시도도 확인했다.
- 브라우저 320px 합성 환경에서 앱이 열린 후 다른 기기의 파일이 늦게 도착하는 상황을 재현했다. 초기 학습량 3·이어하기 1/9에서 원격 파일만 바꾸고 기다리자, 버튼을 누르지 않아도 학습량 5·이어하기 2/9로 표시됐다. 오류 목록은 비어 있었다.
- 전체 검사 1,058개 통과, 기존 조건부 검사 2개 제외. 타입 검사·배포 빌드·diff 검사 통과.
- 사용자 보관함에 설치 후 실제 Mac Obsidian을 정상 재실행해 1.2.3과 기록 새로고침 버튼·성공 안내를 확인했다. 설치 전후와 화면 점검 후 data.json/ui-state.json 해시 일치. 사용자 평가를 추가하지 않았다.

## 제한

맥의 보관함이 iCloud 폴더에 있는 것을 확인했지만 다른 실기기의 보관함 선택·동기화 설정·iCloud 파일 전송 완료는 확인하지 않았다. 실제 iPhone·iPad·Android·다른 컴퓨터로의 전송 검증을 의미하지 않는다. 동일한 보관함의 문제 파일과 플러그인 data.json/ui-state.json이 양쪽에서 동기화되어야 한다. 첫 화면에 오래 열어 둔 기기가 다른 기기의 진행 중 세션을 강제로 바꾸지 않으며, 새 위치는 이어하기에서 선택한다. 동시 쓰기의 원자성이나 클라우드 전달 시점은 보장하지 않는다.
