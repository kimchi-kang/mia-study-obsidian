# 1.3.3 학습 본문 표시 변경

- 시험·암기 모드에서 답안의 독립된 ‘원문: 링크’ 출처 행을 표시하지 않고 ‘원문 열기’ 버튼을 제거했다. 저장된 답안과 원본 노트는 수정하지 않는다. 코드 예제·문장 속 ‘원문’ 표현·답안 링크는 보존한다.
- 질문/답안, 이어볼 문제, 평가 영역의 장식 박스·그림자와 질문/답안 사이 구분선을 제거했다. 평가 버튼·문제 이동 기능과 본문 표·수식은 보존한다.
- 원문 출처 블록에 맞닿은 구분선도 함께 숨기며, 답안의 다른 구분선은 보존한다.
- 원문 행 판별은 Word 내보내기와 같은 공용 규칙을 사용한다.
- 모바일 브라우저의 시험·암기 화면, 데스크톱 밝은 테마에서 시각 확인했다. 해당 네 영역의 계산된 테두리 0px·그림자 none, 원문 버튼 0개·평가 버튼 4개 확인.
- 원문 행 숨김·코드/표/수식 보존·두 모드의 저장된 답안 불변 검사 포함, 전체 1,087개 검사 통과(기존 조건부 검사 2개 제외). 타입/배포 빌드·CSS 구문·diff 검사 통과.
- 스크린샷: 작업 폴더 옆 source-free-study-ui-2026-10-26 폴더의 mobile-browse-answer.jpg, mobile-recall-answer.jpg, desktop-browse-light.jpg.
- 1.3.3 설치 중 data.json/ui-state.json 파일 해시가 유지됐고 설치된 세 파일이 최종 빌드와 동일함을 확인했다. 이전 1.3.2 배포 파일과 1.3.3 설치 ZIP을 보존했다.
- 실제 Mac에서 앱 재시작 후 1.3.3 및 동일 암기 문제의 원문 링크·열기 버튼 제거를 확인했다. mac-1.3.3.jpg에 실제 화면을 저장했다.

## 2026-10-27 출처 표시 누락 경로 수정

- `원문: [[회로이론 면접 154]] · <09. 정현파와 페이저>`처럼 단원명이 붙은 출처도 화면에서 숨긴다. 이전에는 링크만 있는 행을 인식해 이 형식이 남았다.
- 시험·암기 모드, 문제 목록의 질문 본문, 이어볼 문제 미리보기와 전체 상세의 질문·답안에 같은 규칙을 적용했다. 상세 창의 원문 버튼도 제거했다.
- 문장 속 설명·코드 블록·일반 답안 링크와 저장된 Markdown은 유지한다. 문제 위치 확인/미등록 후보 관리 같은 진단 기능은 변경하지 않았다.
- 사용자 스크린샷의 문구로 회귀 검사를 추가했다. 타입 검사·프로덕션 빌드와 관련 4개 테스트 파일 154개가 통과했다. 이번 변경의 실제 Obsidian 화면 재확인은 수행하지 않았다. 기존 1.3.5 최종 검증 ZIP은 변경하지 않았으며 현재 소스·main.js에는 이후 수정이 포함된다.

### 실제 저장 형식 재확인 및 적용

실제 문제은행의 단원 괄호가 `&lt;단원명&gt;`으로 저장되어 있어 앞선 리터럴 `<단원명>` 검사만으로는 누락됐다. 비교 단계에서만 HTML 괄호 엔티티를 정규화하도록 수정하고 명명/10진수/16진수 표기를 검사했다. 관련 4개 파일 157개 테스트와 타입 검사·빌드가 통과했다. 로컬 설치 파일을 갱신하면서 설정·복습·활성화와 대상 문제은행·과목 노트 등 7개 파일의 해시가 유지됨을 확인했다.

실제 Obsidian 1.14.5에서 보관함을 닫았다 다시 열어 기존 Q104의 암기 모드 1/364 위치와 답안 표시가 복원됐고, 원문 출처 행·인접 구분선이 사라짐을 확인했다. 평가 버튼을 누르거나 복습 기록을 추가하지 않았다. 실제 사용자 화면은 공개 저장소에 포함하지 않았다.
