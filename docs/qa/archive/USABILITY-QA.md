# 1.2.0 설정 사용성 점검

2026-10-26. 실제 Mac의 기존 보기 설정과, 합성 문제 12개를 사용하는 브라우저 점검 환경을 확인했다. 사용자 본 보관함에는 시험 평가를 만들지 않았다.

## 관찰과 수정

- 실제 Mac의 기존 보기 설정에서 집중 모드와 쓸어서 뒤로가기가 켜져 있었다. 열기만 해서 값이 바뀌는 현상은 재현하지 못했다. 기존 값과 새 변경을 구분하기 어려운 문제를 줄이기 위해 저장·취소를 추가했다. 창을 열 때 첫 조작 항목 대신 대화상자에 포커스를 두고, 켜짐·꺼짐과 기본값을 글자로 표시한다. 기존 값을 임의로 초기화하지 않았다.
- 학습 간격을 문자열로 입력하는 대신 숫자와 분·시간·일 선택, 단계 추가·삭제, 자동 계산으로 변경했다. 매일 사용하는 학습량·간격은 첫 화면에 표시하고, 출제 순서와 FSRS 가중치는 펼치는 세부 설정으로 옮겼다.
- 기본값 불러오기는 저장 전 초안에만 적용한다. 잘못된 값은 저장을 막고 해당 입력으로 이동하며, 오류가 세부 설정 안에 있으면 펼친다.
- 작은 화면에서 상태 글자를 추가한 토글의 오른쪽 잘림, 자동 간격 모드에서도 단계 추가 버튼이 보이던 스타일 충돌을 발견해 수정했다. 두 간격 결정 선택 항목의 접근성 이름도 구분했다.
- 30초 자동 갱신에서 입력이나 스크롤 위치가 사라지는 현상은 재현하지 못했다. 입력 유지 회귀 검사는 유지한다.

## 수행한 검증

- 브라우저 320×667과 768×1024의 학습 설정에서 가로 넘침과 44px 미만 조작 요소가 없었다. 390px 첫 화면도 확인했다. 작은 화면의 보기 설정은 수정 전후 스크린샷으로 비교했다.
- 하루 새 문제 2개 저장·다시 열기, 1.5시간을 90분으로 저장, 틀린 문제 자동 간격 저장, 0분 입력 차단, 기본값 불러오기만으로 저장되지 않음을 확인했다.
- 합성 문제를 시험 모드로 시작해 2문제 큐와 기본 1분/10분 평가 간격을 확인했다. 두 문제를 평가한 뒤 오늘 학습 완료와 새 시험 시작 비활성화를 확인했다.
- 보기 설정의 변경 전 저장값 유지, 취소 후 복원, 저장 후 다시 열기 및 재시작 유지 확인. 자동 검사는 7개 보기 항목의 일괄 저장과 저장 실패 후 초안 보존·재시도도 검증한다.
- 전체 자동 검사 1,052개 통과, 기존 조건부 검사 2개 제외. TypeScript 검사·배포 빌드·diff 공백 검사 통과.
- 실제 사용자 보관함의 플러그인 세 파일을 백업한 뒤 1.2.0 설치. 설치 직전·직후 data.json 및 ui-state.json SHA-256 일치 확인.

## 제한

1.2.0 설치 후 Mac 화면 검증 시 Mac이 잠겨 있어 재실행과 최종 화면 확인은 대기 중이다. 이전 Mac 실사용 결과는 MAC-QA.md에 따로 기록했다. 모바일은 브라우저 크기 점검이며 실제 iPhone/iPad, 시스템 키보드, VoiceOver, 장기 동기화 검증은 아니다. 스크린샷은 로컬 ui-use-audit-2026-10-26/screenshots에 보관했다.


# 1.2.1 기능 중심 추가 점검

추가 승인이 필요한 작업은 진행하지 않는다는 사용자 지시에 따라, 접근 가능한 브라우저와 로컬 자동 검사에서 검증했다.

- 1.2.0 Obsidian 설정 경로에서 학습 설정의 다시 그리기가 전체 컨테이너를 지워 문제 폴더·목표 기억률·최대 간격을 없애는 회귀를 발견했다. 기본값 불러오기에서는 아래 고정 간격·키워드 폴더도 사라졌다. 학습 설정 전용 컨테이너로 범위를 제한했다.
- 같은 경로의 저장 실패가 전체 화면을 다시 만들어 입력을 잃게 하는 문제를 수정했다. 두 회귀 검사는 수정 전 실패, 수정 후 통과를 확인했다.
- 브라우저에서 저장을 일부러 실패시켜 하루 새 문제 9와 저장 전 고정 간격 12 입력이 보존됨을 확인했다. 저장된 학습량은 실패 전 2로 남고, 재시도 후 9로 저장되고 닫았다 열어도 9가 유지됐다.
- 기본값 불러오기 후에도 기존 문제 폴더·기억률·최대 간격·키워드 폴더·평가별 간격이 남고, 다른 항목의 입력도 유지됨을 확인했다.
- 세부 설정의 하루 시작 시각, 새 문제 상한 예외, 세 가지 순서, 복습일 분산을 변경하고 저장값 일치 확인. 잘못된 가중치 2개 입력 시 전체 저장을 막고 접힌 세부 설정을 펼쳐 오류 위치를 보여줬다.
- 못 암기 고정 간격 12분 저장 후 실제 시험의 해당 평가 버튼이 12분을 표시함을 확인했다. 평가는 합성 문제만 사용했다.
- 좁은 Obsidian 설정 창에서는 대시보드와 다른 너비 경계로 인해 간격 입력이 넘치는 문제도 발견해 수정했다. 최종 320×667 설정 화면에서 가로 넘침·44px 미만 조작 요소 미발견.
- 전체 자동 검사 1,054개 통과, 기존 조건부 검사 2개 제외. 타입 검사·배포 빌드·diff 검사 통과. 검사 중 Mac 절전으로 인한 타임아웃이 있었고, 정상 실행에서 전체 통과를 다시 확인했다.
- 사용자 보관함에 1.2.1 파일 설치, 설치 전후 data.json/ui-state.json 해시 일치 확인. 1.2.1 설치 후 Mac 실제 화면은 잠금 때문에 확인하지 않았다. 모바일 실기기 검증도 수행하지 않았다.


## Mac 잠금 해제 후 최종 확인

사용자 진행 지시에 따라 실제 Obsidian을 정상 종료·재실행해 1.2.1과 첫 화면 학습 설정 표시를 확인했다. 보기 설정의 변경·취소·다시 열기에서 기존 값이 유지되고, Obsidian 설정의 기본값 불러오기 후에도 기존 항목이 남았다. 음수 학습량 저장은 차단됐다. data.json과 ui-state.json의 점검 전후 해시가 동일했다. 이전에 기록한 Mac 화면 확인 대기 상태는 해소됐다. 상세 범위는 MAC-QA.md의 1.2.1 절에 기록했다.


# 1.2.2 학습 설정 대화상자

사용자 요청에 따라 첫 화면의 전체 학습 설정 폼을 제거하고 보기 설정 옆에 학습 설정 버튼을 추가했다. 같은 입력·검증·저장 기능을 대화상자와 Obsidian 설정에서 공유한다. 대화상자는 저장 성공 후 닫히고 취소·닫기는 미저장 변경을 버린다. 저장 실패는 입력을 보존한다. 기존 대시보드 폼 보관 코드와 관련 스타일을 제거했다.

- 자동 검사 1,056개 통과, 기존 조건부 검사 2개 제외. 타입 검사·배포 빌드·diff 검사 통과.
- 320×667 브라우저에서 설정 창 너비 296px, 입력·선택·버튼의 가로 넘침 미발견. 하루 새 문제 9에서 3으로 바꾼 뒤 취소하면 다시 9. 저장을 의도적으로 실패시키면 창이 남고 입력 3·저장값 9가 유지된다. 재시도 성공 후 창이 닫히고 저장값 3을 확인했다. 이 값은 합성 환경에만 적용했다.
- 실제 사용자 Mac에서 정상 종료·재실행 후 1.2.2, 학습 설정/보기 설정 버튼, 인라인 폼이 제거된 첫 화면과 별도 학습 설정 창을 확인했다. 취소하면 첫 화면으로 돌아왔다.
- 설치 전후 및 Mac 확인 후 data.json과 ui-state.json 해시 일치. 사용자 설정이나 평가 이력은 바꾸지 않았다. 화면은 로컬 ui-use-audit-2026-10-26/modal-1.2.2에 보관했다. 모바일 실기기는 이번 검증에 포함하지 않았다.
