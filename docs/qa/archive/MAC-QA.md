# 1.2.1 Mac 최종 화면 점검

2026-10-26. 실제 사용자 다용도 보관함, macOS Obsidian 1.14.5에서 확인했다.

- 앱 메뉴로 정상 종료 후 재실행해 실행 버전 1.2.1을 확인했다. 첫 화면에 학습 설정과 숫자·단위 간격 편집기가 표시되고 등록 문제 364개를 불러왔다.
- 보기 설정은 처음 열면 저장 버튼이 비활성이고 포커스가 대화상자에 있었다. 집중 모드와 쓸어서 뒤로가기의 기존 켜짐 상태가 유지됐다. 집중 모드를 변경하면 저장 필요 상태가 되고, 취소 후 다시 열면 기존 켜짐 상태와 비활성 저장 버튼으로 돌아왔다. 실제 저장값은 바꾸지 않았다.
- Obsidian 설정 → MIA Study에서 문제 폴더·목표 기억률·최대 복습 간격과 학습 설정이 함께 표시됐다. 기본값 불러오기 후에도 이 항목들과 평가별 간격·키워드 폴더가 남았다.
- 하루 새 문제에 음수 입력 후 저장 시도는 오류 안내와 해당 입력으로 포커스 이동으로 차단됐다. 설정 창을 닫으면 미저장 입력이 버려지고 첫 화면의 저장값 20이 유지됐다.
- 평가를 만들거나 정상 설정 저장을 실행하지 않았다. 점검 전후 data.json과 ui-state.json SHA-256이 모두 일치했다. 실제 저장·저장 실패 후 재시도·간격 반영은 USABILITY-QA.md의 별도 합성 환경 검사 결과를 참고한다.
- 스크린샷과 전후 해시는 로컬 ui-use-audit-2026-10-26/mac-final에 보관했다. 앞서 잠금 때문에 대기했던 설치 후 화면 확인을 완료했다. 실제 모바일 기기와 장기 동기화 검증은 포함하지 않는다.

# 1.1.2 Mac 실사용 점검

2026-10-25. macOS의 실제 Obsidian 1.14.5에서 MIA-Release-QA 검증용 보관함을 사용했다. 사용자 본 보관함에는 평가를 만들지 않았다.

1. 시작·설정: 실제 실행 버전 1.1.1/1.1.2 표시 확인. 음수 일일 상한 저장 차단, 하루 새 문제 2개 설정, 앱 완전 종료/재실행 후 2개 유지와 2문제 시험 큐 확인.
2. 학습·키보드: 시험 정답 숨김, Space 정답 공개, 숫자 1(못 암기)/4(너무 쉬움) 평가, U 직전 평가 취소 실행. 저장 파일에서 첫 문제의 Again 이력 1개 유지와 두 번째 Easy 이력 제거를 확인했다. 수식과 표가 실제 Obsidian 렌더러로 표시됐다.
3. 반복·복원: 1분 학습 단계의 문제가 같은 세션에서 새 출제로 삽입되고 정답을 가리는 상태를 확인했다. 취소 후 재시작에서 두 번째 문제와 정답 공개 상태가 복원됐다.
4. 창 크기: 큰 창과 macOS 왼쪽 절반 창에서 점검했다. 축소 직후 캡처에 이전 큰 레이아웃이 남아 해당 캡처는 시각 검증 근거로 제외했다. 좁은 창에서 다시 실행한 캡처는 메뉴 줄바꿈, 질문 줄바꿈과 평가 2×2 배치를 확인했다. 실행 중 크기 변경 직후의 지속적인 재배치는 이번 도구 결과만으로 확정하지 않았다.
5. 암기 모드: 시작 뒤 ui-state.json에 sessionMode=browse, answerVisible=true가 저장됨을 확인했다. 도구의 화면·접근성 상태가 최신 저장 상태와 어긋나 이 경로의 최종 화면 검증은 보류했다.

## 발견·수정

학습 단계 입력이 소수를 허용하지만 ts-fsrs 5.x는 단위 앞 숫자에 parseInt를 사용한다. 실제 Mac에서 0.1m/1m 저장 후 못 암기 간격이 1일로 표시됐다. 단계 입력을 정수 분으로 검증하고, 1.5h처럼 정확히 표현되는 소수 시간/일은 90m 같은 정수 분으로 정규화했다. 1분 미만이나 소수 분은 저장을 차단한다. 저장된 설정도 같은 파서를 사용한다. 기존에 잘못 저장된 단계 배열은 기본 단계로 복구된다.

수정 후 실제 Mac UI에서 0.1m 저장 차단, 1.5h 저장 성공과 파일의 learningSteps=["90m"], 1m/1m 설정의 못 암기 1분 표시를 확인했다. 분수 시간/일 보존과 미리보기/실제 간격 일치 회귀 검사를 추가했다.
