# 1.3.0 범용 기기 동기화 검증

2026-10-26. Windows·Android 등에서도 숨김 설정 폴더를 별도로 전송하지 않고 일반 노트와 함께 학습 데이터를 전달할 수 있도록 선택 모드를 추가했다. 운영체제별 계정 연결이나 파일 전송 도구를 구현한 것은 아니다.

## 저장·전환

- 기존 모드는 그대로 유지한다. 학습 설정 창 또는 Obsidian 설정의 내 기기 간 동기화에서 범용 모드를 명시적으로 선택한다.
- `MIA Study Sync/study-data.md`, `study-resume.md`, `sync-mode.md`에 버전이 있는 관리용 JSON을 Markdown 코드 블록으로 저장한다. 세 파일을 일반 노트와 함께 전달한다.
- 준비할 때 기존 데이터와 공유 파일을 검증·병합하고 저장 결과를 다시 읽는다. 데이터·이어하기를 먼저 복사하고 모드 파일을 마지막에 게시한다. 기존 data.json과 ui-state.json은 지우지 않는다.
- 실행 중 저장소를 새 파일로 전환한다. 다른 기기는 폴더 전체를 받은 뒤 재시작하면 공유 모드를 인식한다. 이미 사용한 기기에서 모드 파일이 사라지거나 일부 파일이 누락되면 오래된 플러그인 파일로 조용히 되돌아가지 않는다.
- 기기별 보기 설정과 중단 시 로컬 이어하기 체크포인트의 키를 유지한다. 기존 문제별 수정 번호·충돌 보관·평가 취소 보호를 그대로 사용한다.

## 검증 결과

- 추가 저장소 검사 15개: 기존 모드 무변경, 기존 기록·설정·이어하기 복사와 원본 보존, Markdown 파일만 전달하는 두 장치의 왕복 평가·취소, 기존 원격 기록 병합과 최신 이어하기 선택, 로컬 보기·체크포인트 유지, 손상 파일 2종 보존, 복사 실패와 재시도, 누락 파일 및 미래 버전 차단, 저장 결과 불일치, 준비 중 외부 파일·모드 변경, 세션 종료 시각 유지, 미래 복습 데이터가 이전 복구 사본으로 대체되지 않음을 검사했다.
- 새 모드 탐지 중 플러그인 해제 시 초기화를 중단하는 검사도 추가했다. 기존 보기 설정 테스트의 호스트 경계를 새 저장소 인터페이스에 맞췄다.
- 전체 자동 검사 1,074개 통과, 기존 조건부 보관함 검사 2개 제외. TypeScript 검사·프로덕션 빌드·diff 검사 통과.
- 합성 브라우저에서 실제 플러그인으로 범용 모드 활성화, 세 Markdown 파일 생성, 하루 학습량 6 저장, 재시작 후 모드·설정·보기 유지, 새 문제 평가 1회 저장과 재시작 후 복원을 확인했다. 320px에서 동기화 안내·버튼에 접근할 수 있었다.
- 실제 Mac에 1.3.0 설치·재실행과 새 설정 항목을 확인했다. 사용자에게 이미 동작하는 iCloud 경로는 전환하지 않았다. 설치·화면 확인 전후 data.json 및 ui-state.json 해시 일치.
- 잠금 파일에서 source-map-js의 표기 버전이 기존 배포 URL과 달랐던 항목을 원래 배포 버전 1.2.2로 바로잡았다. 새 의존성은 추가하지 않았다.
- 배포 ZIP은 main.js/styles.css/manifest.json 세 파일만 포함하며 빌드와 일치함을 확인했다. 로컬 화면은 ui-use-audit-2026-10-26/portable-sync-1.3.0에 보관한다.

## 범위와 제한

Windows·Android 실기기 또는 실제 Remotely Save/Obsidian Sync 계정 간 전송은 검사하지 않았다. 복사·갱신 검사는 장치 경계를 흉내 낸 독립 저장소와 실제 브라우저 플러그인을 사용했다. 동기화 도구가 이 폴더를 제외하거나 파일 크기를 제한하면 그 설정도 확인해야 한다. 모든 기기에서 1.3.0 이상을 사용하고 같은 문제 노트와 폴더 전체를 동기화해야 한다.

세 파일은 하나의 원자적 트랜잭션으로 전송되지 않는다. 파일별 도착 순서·클라우드 충돌 병합·동시 쓰기 전체를 잠그지 않으며, 파서와 기존 충돌 보존으로 잘못된 데이터를 덮어쓰는 위험을 줄인다. 범용 모드 이후의 최신 기록은 일반 폴더에 있으므로 구버전으로 내릴 때 과거 플러그인 파일을 최신 기록으로 착각해서는 안 된다. 기존 모드로 돌아오는 버튼은 이번 범위에 포함하지 않았다.
