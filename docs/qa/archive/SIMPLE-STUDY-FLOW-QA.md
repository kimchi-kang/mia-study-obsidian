## 기대값과 실제 결과

기본 공유 상한 정책에서 새 문제도 복습 상한을 사용한다. 아래 표는 **최초 합성 데이터**에서의 결과다. 일반 복습과 짧은 반복을 구분했다.

| 선택 | 저장되는 새 문제/복습 상한 | 예상 새 문제 | 예상 일반 복습 | 예상 짧은 반복 | 자동화 실제 결과 |
|---|---:|---:|---:|---:|---|
| 가볍게 | 10 / 100 | 0 | 90 | 1 | 모두 일치 |
| 보통 | 20 / 200 | 17 | 120 | 1 | 모두 일치 |
| 많이 | 40 / 400 | 37 | 120 | 1 | 모두 일치 |
| 직접 입력 | 7 / 200 | 4 | 120 | 1 | 모바일 화면에서도 일치 |
| 직접 입력 | 0 / 0 | 0 | 0 | 1 | 모바일 화면에서도 일치 |

- 새 문제만 있는 범위에서도 당일 기록은 전체 과목에서 차감된다. 각 프리셋은 7 / 17 / 37개를 출제했다.
- 일반 복습 450개가 밀린 별도 자동화 시나리오에서 90 / 190 / 390개를 출제해 각 복습 상한도 실제로 검증했다.
- 독립 상한을 켜고 5 / 10으로 지정하면 새 문제 2개·일반 복습 3개·짧은 반복 1개다. 새 문제와 일반 복습을 각각 1개 평가한 뒤 저장소를 다시 로드해도 남은 수량은 1개·2개다.
- 자정 및 다음 날 03:59:59에는 예산이 새로 생기지 않는다. 설정된 기본 경계인 04:00에서 갱신된다. 전날의 짧은 반복은 다음 학습일에 일반 예산을 사용한다.
- 0 / 0이어도 짧은 반복은 남으며, 이를 평가한 뒤에는 자동 시험 시작이 비활성화되고 대기 문제 및 학습량 확인 안내가 나온다.
- 문제 2개만 있으면 2개만 출제하고, 빈 문제은행은 첫 질문 추가 안내를 표시한다. 미래 복습 문제는 출제되지 않는다.
- 허용 범위 0–9999 정수: 음수·빈 값·10000·소수는 저장하지 않고, 0과 9999는 저장한다.

## 발견·수정 사항

1. 간편 화면이 잘못된 고급 기억률을 이전의 정상 프리셋으로 표시했다. 잘못된 초안이면 사용자 지정과 복구 안내를 표시하고 저장을 차단한다.
2. 사용자 지정 표시를 직접 선택하면 실제 값은 프리셋인데 표시만 사용자 지정이 될 수 있었다. 별도 동작을 만들지 않고 실제 값으로 표시를 즉시 복원한다.
3. 저장 중 선택을 계속 바꿀 수 있어 완료 시 나중 선택이 사라졌다. 저장 동안 해당 폼의 입력/버튼을 잠그고 실패하면 원래 편집 상태로 복원한다.
4. 공통 `updateSettings`는 디스크 저장 뒤 불필요한 문제 재검색을 수행했다. 검색 실패 시 저장이 적용됐는데 실패처럼 표시되는 기존 공통 경로 문제였다. 학습 설정은 스케줄러만 갱신하고, 자료 경로 관련 변경 때만 재검색한다.
5. 하루 경계·0·공유 상한·짧은 반복 예외·실제 출제가 상한보다 적을 수 있다는 안내를 보강했다. 자동 출제 기준과 기존 세션/직접 추가/자유 암기 범위를 명시했다.
6. 일부 복습만 제한될 때 제외 사실이 명확하지 않았다. 제외된 복습 수와 문제·복습일 보존 안내를 표시한다.
7. 변경 범위의 기억률 표시가 0.923을 92%로 반올림했다. 92.3% → 95%처럼 실제 소수 값에 맞게 표시한다.

## 유지한 기존 정책과 남은 검증 범위

- FSRS와 출제 순서·예산 계산 알고리즘은 바꾸지 않았다.
- 기본적으로 새 문제와 일반 복습이 복습 상한을 공유한다. 복습이 밀렸을 때 새 문제가 0개인 것은 새 프리셋 버그가 아니다.
- 상한은 새 시험의 자동 목록 구성에 적용한다. 이어하기는 기존 목록을 유지하고, 사용자가 추천 문제를 직접 추가하면 자동 출제 상한을 넘을 수 있다. 기존 동작을 회귀 테스트로 고정하고 안내에 범위를 명시했다. 엄격한 실시간 총 풀이 차단 기능으로 바꾸지 않았다.
- ‘오늘 평가’ 통계는 자정 기준의 문제 수이고, 일일 예산은 기본 04:00 기준이며 짧은 반복과 새 문제의 집계 규칙도 다르다. 기존 통계 정책의 차이로, 코드 검토로 확인했으며 통계 알고리즘은 수정하지 않았다.
- 실제 날짜를 넘기거나 운영체제 시간을 바꾸는 실앱 검증, 물리 Android/iOS·폴드 기기, 소프트 키보드·터치 조작은 실행하지 않았다. 날짜는 통제된 시계 자동화로, 좁은 화면은 브라우저로 검증했다.
- 원격 동기화 서비스/네트워크 지연과 여러 기기의 동시 학습은 이번 실제 화면 검증 범위에 포함하지 않았다.
