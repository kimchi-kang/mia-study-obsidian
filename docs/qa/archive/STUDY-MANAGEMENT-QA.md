# 1.1.0 학습관리 검증

- 변경 전 소스는 `d5495f1`로 main에 커밋·푸시했다.
- Anki 공식 Deck Options 설명과 공식 소스의 기본값을 확인했다. 새 문제 20개, 복습 200회, 학습 1m/10m, 재학습 10m, 새 문제와 복습 섞기, 복습일 순서를 사용한다.
- TypeScript 검사와 프로덕션 빌드 성공. 전체 자동 검사 1,036개 통과, 기존 조건부 보관함 검사 2개 제외. 마지막 기본 순서 조정 후 관련 102개 검사도 통과했다.
- 검증용 MIA-Release-QA 보관함에서 v1.1.0 설정 화면을 열고 새 문제 상한 0 저장 → Obsidian 종료/재실행 → 설정 0 유지와 전역/과목 시험 버튼 비활성화, 암기 버튼 활성화를 확인했다. 기본값 복원도 확인했다. 실제 문제 평가를 만들지 않았다.
- 일일 상한의 새 문제 중복 계산, 전역 과목 합산, 당일 학습 예외, 날짜를 넘긴 학습, 새 문제의 복습 상한 무시, 단계 변경, 미리보기/실제 평가 일치, 고정 간격 우선, 저장/재시작과 기존 리뷰 보존을 자동 검사했다.
- 기존 이어하기는 선택한 큐를 유지한다. 새 상한과 정렬은 새 세션부터 적용한다. 여러 기기의 동시 세션 전체를 잠그는 분산 상한은 제공하지 않는다.
- MIA에 없는 Anki의 덱별 프리셋·형제 카드·오디오·타이머·자동 넘김·쉬운 요일·반복 실패 관리·최적화·SM-2는 이식하지 않았다. 날짜 경계를 넘기는 단계도 실제 예약 시각을 사용한다. 이 차이는 설정 UI와 README에 적었다.
- 모바일 실기기는 검사하지 않았다.
