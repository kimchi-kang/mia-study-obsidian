# 1.0.3 — 실행 중인 버전 표시

- 화면 좌측 상단 Major Study 바로 옆에 작은 `v1.0.3` 형식으로 현재 로드된 플러그인의 manifest 버전을 표시한다. 대시보드·학습 및 각 경로에서 같은 헤더를 사용한다. 버전은 하드코딩하지 않는다.
- 원문 `vC(t) = Vs(1 - e^(-t/RC))`는 일반 텍스트다. 수식으로 표시하려면 `$v_C(t)=V_s(1-e^{-t/(RC)})$`처럼 명시적인 수식 구분자와 TeX 문법이 필요하다. 이번 플러그인 릴리스는 임의의 일반 문장을 자동 변환하지 않는다. 이전 1.0.1·1.0.2의 수식 제목·블록 보존 수정은 유지한다.
- 기본 검사 1,025개 + 별도 조건부 2개(1,000문제, 30초 제한), 타입 검사·production 빌드 통과. 로드된 버전을 바꿔 대시보드와 학습 양쪽 헤더에 반영되는 것을 검사한다.
- 브라우저 모의환경에서 1280×900·768×1024 태블릿, 390×844·320×568 휴대폰 크기 확인. 각 화면에서 버전 표시, RC 합성 예제 수식 6개, MathJax 오류 0·수집된 호스트 오류 0·문서 가로 넘침 없음. [측정값](browser-results.json).
- 설치된 Obsidian 1.14.5의 MathJax 엔진과 대체 Obsidian 파일·설정·Markdown API를 사용한 합성 예제다. 실제 iPad·iPhone·Android 앱 및 클라우드 전파 완료를 검증한 결과가 아니다. 개인 보관함·문제은행·스크린샷은 배포에 포함하지 않는다.
