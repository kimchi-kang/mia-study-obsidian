# MIA Study 1.4.3 통합 검증 및 사용자 설치 · 2026-11-07 KST

시작은 깨끗한 로컬 main `51be477` (1.4.2), 사용자 설치는 1.3.11이었다. 1.3.11 일정·예약·세션 복원 수정 위에 1.4.0 Anki 스타일 설정, 1.4.1 입력 오류·초점 수정, 1.4.2 모바일 UI 수정이 모두 포함됐다. 1.4.3은 이 조합을 검증하고 사용자 설치를 구분하기 위한 버전이다. 실행 JS와 CSS는 1.4.2와 바이트 단위로 일치했다.
