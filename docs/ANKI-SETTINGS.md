# Anki 25.09.4 사용자를 위한 MIA 학습 설정

2026-11-06. 실제 설치/실행 **Anki25.09.4(d52ca669)**, Python3.13.5·Qt6.9.1·Chromium122. 런처 plist25.09와 실행 버전을 구분했습니다. MIA 작업 기반은1.3.11 `35d1723`, 이번 **로컬 개발 버전1.4.0**입니다. 사용자 설치를 직접 교체하거나 원격 게시하지 않았습니다.

## 먼저 알아둘 차이

MIA는 전체 과목 공통 설정과 FSRS-6을 사용합니다. Anki의 덱 계층·노트/형제 카드·SM-2·최적화 엔진은 없습니다. 같은 FSRS-6 가중치를 사용하더라도 예약·학습일·반복 단계·난수·학습량을 계산하는 모든 규칙이 같지는 않습니다.

실제 설치 엔진의 별도 합성 컬렉션과 잠금 ts-fsrs5.4.1을 비교했습니다. 기본 가중치21개는 같지만 `1m 10m` 첫 Again/Hard/Good은 Anki60/330/600초, MIA60/360/600초입니다. Anki는 첫 Hard를 화면에서약6분으로 표시해도 실제330초이고, 다음 단계의 Hard는600초였습니다. MIA는 해당 단계 구성에서 Hard를360초로 계산합니다. 이 차이를 상세 설정의 펼침 안내에도 표시합니다. Anki 분산은 켜져 있으므로 서로 다른 Easy 날짜를 버그나 정확한 동등성 증거로 사용하지 않았습니다.

MIA는 **정확한 분 단위 입력**을 유지하며 초 단계를 새로 흉내 내지 않습니다. 하루 경계를 넘긴 Anki 단계의 날짜 단위 변환과 달리 MIA는 절대 예약 시각을 유지합니다. 24시간 이상 단계가 평가로 선택되면 ts-fsrs5.4.1에서 정규 복습 상태로 전환됩니다. 고정 평가 간격이 있으면 새 문제/학습/재학습/복습 모두에서 그 버튼에 우선하며 최대 간격으로 제한합니다. 이것은 Anki의 졸업/Easy 간격과 다른 MIA 정책입니다.

**복습 기한(1.4.6부터)**: 정규 복습은 Anki처럼 하루 시작 시각부터 그날이 기한인 문제를 모두 출제합니다. 학습·재학습 단계와 하루 미만 고정 간격만 정확한 예약 시각을 따릅니다. [정책과 근거](SCHEDULER-POLICIES.md)

## 사용법과 적용 시점

1. `학습 설정`의 간편 화면은 유지했습니다. 상세 화면은 기존 `고급 설정` 버튼에서 **일일 한도 → 새 카드·실패(재학습) → 표시 순서 → FSRS → 고급/MIA 정책**으로 엽니다.
2. 기억률은 `목표 기억률(%)`에92.3처럼 입력합니다. 기존 MIA 비율0.923 입력도 펼침 영역에 남아 있고 같은 초안을 사용합니다. 개인 Anki 값은 자동 적용하지 않습니다.
3. 단계는 기존 숫자/분·시간·일 행 또는 `Anki 형식` 공백 입력을 사용합니다. `1 10 1.5h`는 `1m 10m 90m`입니다. 빈 공백 입력은 고정 단계 없이 자동 계산이며0·음수·분 미만 나머지는 거부합니다.
4. 최대 복습주기와 평가 버튼별 고정 간격도 이 화면의 **학습 설정 저장**으로 함께 저장합니다. Obsidian 설정 탭의 최대 간격 즉시 저장과 별도 고정 간격 저장 버튼을 제거해 같은 초안/검증/충돌 처리를 사용합니다. 기존 고정 간격의 분/시간/일 입력은 유지합니다.
5. 현재 저장 상태·미저장 상태·변경 요약과 범위를 확인합니다. 닫기/취소/탭 전환만으로 저장하지 않습니다. 기본값 버튼은 이름에 표시된 범위만 준비합니다. 공부량·빈도 기본값은20/200/90%만 바꾸며 단계와 고급 값은 유지합니다.
6. 하루 한도·표시 순서는 **다음 시험 세션 시작**에서 선택 대상에 적용됩니다. 현재 이어하기 큐를 재정렬하지 않습니다. 같은 날 짧은 학습 반복은 먼저 나오고, 날짜를 넘긴 단계는 복습 예산을 사용합니다. 새 옵션의 `학습카드 먼저/복습카드 먼저`는 그 예산을 선택하기 전에 순서를 정합니다. 기본 `섞기`는 기존 MIA 동작을 유지합니다.
7. 단계·기억률·가중치·분산·최대 간격·고정 간격은 **저장 후 다음 평가**부터 계산에 사용합니다. 이미 저장된 예약을 일괄 재계산하지 않습니다. 새 한도나 필터로 제외된 문제도 정상 새 세션에서 다시 선택할 수 있습니다.
8. 저장 실패 시 입력을 보존합니다. 미완료 사본이 생긴 경우 설정 저장을 반복하지 말고 취소 → 대시보드 → 미완료 저장 확인 → 최신 파일과 확인 후 저장 재시도로 진행합니다. 이미 계산한 평가를 다시 계산하지 않습니다. 충돌은 현재 값과 입력 사본을 함께 보관합니다.

내 설정은 기존 **다섯 항목**(새 문제/복습 상한·학습/재학습 단계·기억률)의 복사본입니다. Anki처럼 모든 옵션을 묶어 여러 덱에 연결하는 활성 프리셋이 아닙니다. 불러오기는 초안이고 저장해야 적용됩니다. 이름 변경/삭제도 저장 전에는 보관 목록에 반영되지 않으며 현재 학습값을 바꾸지 않습니다. 고급 순서·상한·고정 평가 간격은 불러올 때 유지합니다.

## 기본값과 현재 사용자 값의 구분

Anki의 개인 프리셋 화면/읽기 전용 사본에서 새 카드999·복습9990, 학습30m·재학습20m, 새/복습과 interday는 복습 후, 타이머7초·표시 켜짐, FSRS켜짐을 관찰했습니다. 이는 **사용자 값**입니다. 새 합성 컬렉션의 기본값은20/200,1m10m/10m, 혼합, 타이머60초·표시 꺼짐, FSRS꺼짐이었습니다. 어떤 개인 값도 MIA 기본값으로 복사하지 않았습니다. 기본 기억률90%·최대36500일·같은 기본 가중치는 설치 엔진에서 확인했습니다.

## 데이터 이행과 근거

새 필드가 없는 기존 설정과 충돌 사본은 `interdayLearningOrder=mix`로 읽어 기존 정책을 유지합니다. 사본 ID/계보/다른 필드를 삭제하거나 손상된 명시 값을 기본값으로 숨기지 않습니다. 읽기만 할 때 쓰지 않는 회귀 검사도 있습니다. 기존 문제/이력/예약/기기 보기/이어하기 형식은 바꾸지 않았습니다. 설정 저장은 예약 전체를 재계산하지 않습니다. 여러 기기에는 같은1.4.0빌드로 맞춘 뒤 새 설정을 사용해야 합니다. 이전 버전은 새 옵션/새 설정 사본을 해석하지 못할 수 있습니다.

Anki개인 프리셋/카드/이력은 읽기만 했고 자동 가져오기·변환·적용은 없습니다. 별도 합성 컬렉션은 설치된 Python/백엔드만 사용하는 진단 자료이며 실제 Anki GUI 학습으로 세지 않습니다.
